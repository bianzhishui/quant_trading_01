# 最终策略规格 — 全市场 R5（行业中性化版）

> 定稿于 2026-09-04（Round 8 实盘化验证通过后）。本文是唯一权威规格，合并各轮预注册
> 方案的最终结论。验证链：docs/factor_round5~8_*_plan.md。

---

## 1. 策略一句话

**"买冷门且有中期动量的股票（行业内比较），等权拿满前 20%，月度调仓，满仓不择时"**——
Amihud（非流动性）+ 中期动量双因子，行业内百分位等权打分，取全市场合成分前 20% 等权持有。

## 2. 为什么是这个（策略逻辑）

- **Amihud**：流动性溢价——冷门股（交易额小、价格冲击大）有系统性超额。
  因子值 = mean(|日收益| / 日成交额)×1e6，21 日滚动。值越大越冷门 → 值大加分。
- **中期动量**：剔除最近 1 个月的 6~12 月收益（close[−21]/close[−250] − 1）——趋势延续。
  两者 IC 负相关（−0.43，Round 3）：冷门股里挑有动量的、动量股里挑冷门的，互补。
- **行业内比较**（Round 5）：信号换成行业内百分位后超额仍 +5.7pp（全局版 +9.7pp 中
  约 4pp 是行业 beta）——行业内选股 alpha 真实，且去掉行业集中风险。
- **扩池验证**（Round 7）：扩到 3194 只全市场，超额只从 +5.7 降到 +4.6pp——
  幸存者偏差贡献仅 1.1pp，超额真实、泛化成立。
- **实盘化验证**（Round 8）：真实成本（流动性依赖）下 +2.56pp、可交易性极佳、
  阻塞影响 0.18pp → 可执行。

## 3. 可执行规格（规则链）

### 3.1 股票池（每月信号日 T 计算）
- 全市场**主连 + 中小板**（sh.60x / sz.00x），非 300/688/北交
- `tradestatus==1`、`isST==0`、上市 ≥375 个交易日（close 非空累计）
- 当日未涨停（qfq 涨幅 < 9.8%）——涨停买不进，剔除
- 行业过滤：证监会行业大类 **≥5 只**在该月有效（保证行业内排名有意义）；
  不足 5 只的小行业整月剔除（基准与组合同池，归因干净）
- 信号日池内月均约 **2279 只**

### 3.2 因子
| 因子 | 公式 | 方向 |
|---|---|---|
| Amihud | mean(|ret|/amount)×1e6, 21日, min_periods=15 | 值大 → 加分（买冷门） |
| 中期动量 | close.shift(21)/close.shift(250) − 1 | 值大 → 加分（买趋势） |

### 3.3 打分与组合
- 每个因子在**中性化池内按行业分组做百分位排名**（每只股得行业内分位 0~1）
- 合成分 = 两因子行业内百分位**等权平均**
- 持仓 = 合成分 **前 20%**（全市场下约 **575 只**）**等权**

### 3.4 调仓与执行
- **信号日 T** = 月末最后一个交易日收盘；**执行日 T+1**（下一交易日）
- 执行日收益按**旧持仓**计算，新持仓**次日**生效（收盘执行、不追当日涨跌）
- 无风控叠加：**满仓**（Round 4 四轮证明任何回撤风控都是负和，回撤是市场 beta）
- 换手成本按**比例**口径：每换手 1 元持仓付 c_i = 15bp + s×Amihud百分位_i（s=0 基准）

### 3.5 业绩（2014-01 ~ 2026-09，141 期，基准 = 同池等权 +7.5%/年）

| 口径 | 超额 | 说明 |
|---|---|---|
| 15bp 平成本 | **+4.61pp** | 研究基准口径 |
| 35bp 平成本 | +2.9pp | 旧压测（Round 7） |
| 真实成本 s=40bp（平均≈35bp） | **+2.56pp** | 实盘化口径（Round 8） |
| flat 70bp（极端） | +0.09pp | 贴线——成本红线 |

其他：年换手 **3.7**（单边）、夏普 0.58、最大回撤 **−54.6%**（2015-06~09）、
分段超额 **+8.0 / +2.7 / +3.9**（2014-17 / 2018-21 / 2022-26，三段全正）。

## 4. 已知边界（诚实清单）

1. **回撤 −54.6% 是市场级**（2015 股灾），选股层/风控层均治不了（Round 4 全部证伪）；
   这是本策略的固有特征，不是缺陷但必须知情
2. **夏普仅 0.58**——高超额 + 高波动型策略，不是稳健型
3. **成本敏感**：flat70bp 贴零线 → 执行必须控成本（限价单、POV 拆单、不追涨停）
4. **39% 持仓是最冷门 20% 分位股**（2026-09 快照）——执行需耐心
5. **残余偏差**：全市场 = 当前上市的主连+中小板，未含完全退市股票（偏差残余但远小于
   原 800 池）；小市值因子仍不可测（无历史市值源）
6. 单因子判定（Round 2）是 800 池内结论，扩池后未逐因子复测

## 5. 实盘执行指引

- **资金规模**：审计显示 AUM 5000 万时单票占日成交 p95 <1%——资金容量远超 5000 万，
  流动性不是瓶颈；建议从 1000 万起步验证
- **下单**：限价单为主；冷门股（Amihud 百分位 >0.8）按 POV 拆分 2-3 日成交
- **调仓时点**：月末最后交易日收盘出信号，次一交易日执行，不追涨停买入
- **监控**：月度记录真实成交成本（滑点），1-2 个季度后回填验证成本模型
