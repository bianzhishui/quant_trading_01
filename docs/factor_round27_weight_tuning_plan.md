### 0.3 诚实解读（含判据修正记录）

1. **单调递增是真趋势**：超额 +4.04 → +7.04pp 随 Amihud 权重上升，三段也整体同步改善——
   确认 Round 26"Amihud 是超额主源、动量稀释项"；
2. **但无高原 = 不能选权重**：0.55~0.80 全程上升沿，没有"平顶区"——双侧高原判据
   诚实拦截了所有候选（包括端点 0.80 的伪通过）；
3. **端点 0.80 是数据挖掘陷阱**：超额最高但单侧邻域无法确认"0.85 后是否回落"——
   若顺延推荐就是过拟合；④ 双侧判据修正（初版端点单侧自动过 → 修正为双侧必需）正是防此；
4. **过程修正记录**：初版 ④ 用 `abs(x-w)<=0.05` 有浮点精度 bug（0.70−0.65=0.04999…）
   致邻域漏点/端点伪通过——已修（1e-9 容差 + 双侧必需），结果以修正版为准；
5. **维持 0.5 是纪律选择**：等权简单可复现、历史验证充分；调整需更充分证据。

### 0.4 决策点（供用户）

- **维持 0.5**（推荐，本结论）：接受"非最优但有验证+简单"；
- **继续探索**：扩展扫描 0.85~1.00（动量权重逼近 0）+ **滚动/样本外验证**（2014-2021 定权、
  2022-2026 验证）——需另开预注册（Round 28），且明确这是"阿米哈德单因子化"方向
  （动量从 R5 中淡出），属重大策略语义变化。

## 1. 规则（定死）

- **打分**：`sc = w × rank行业内(Amihud) + (1−w) × rank行业内(动量)`，前 20% 等权；
- **细扫**：`w ∈ {0.55, 0.60, 0.65, 0.70, 0.75, 0.80}`（6 组，Round 26 高区加密）；
- **固定**：全市场池/行业内百分位/前 20% 等权/15bp/月频/阻塞引擎（生产口径）/300万/141 期；
- **每权重输出**：全区间超额 + **ERAS 三段（2014-17/18-21/22-26）超额 + 回撤 + 换手**。

## 2. 判定（定死，防过拟合核心）

| # | 判据 | 条件 |
|---|---|---|
| ① 改善显著 | 候选 w* 的全区间超额 − 0.5 超额 | **≥ +1pp** |
| ② 三段一致 | w* 的**每一段**超额 ≥ 0.5 的对应段超额 | **三段全部不劣化**（防"只有某段好"） |
| ③ 代价可控 | w* 回撤 − 0.5 回撤 ≤ +5pp；换手如实报告 | ≤ +5pp |
| ④ 高原稳健 | w* 及其邻域（w*±0.05 落在扫描内）超额波动 | **< 0.5pp**（防选在针尖） |

**推荐权重 = 满足①②③④ 的最高 w***（Amihud 单调，高 w 超额高，但须在高原内）。
若无 w 满足全部四项 → **维持 0.5**（诚实：调整不可靠）。

**最终改生产**：推荐 w* 后仍需**用户单独批准**（R5 冻结，任何变更需用户点头）。

## 3. 诚实风险

1. **数据挖掘/过拟合是头号风险**：细扫 6 点更容易过拟合——用 ②三段一致 + ④高原稳健
   双重过滤；选权原则是"高原内保守最高"，不是"全局最高"；
2. **动量弱化代价**：w 提高 → 动量贡献降低——round1 显示动量"IC 弱但右尾有效"，
   高权重下右尾价值是否丢失需看三段表现（② 会暴露）；
3. **风格更极端**：Amihud 权重高 → 组合更偏"冷门小盘流动性"，回撤可能加深（③ 把关）；
4. **不改变已运营账本**（探索结论 → 用户批准 → 才考虑是否切换，账本重建另行决策）；
5. 结果依赖历史区间，未来市场结构变化可能使 w* 失效（敏感性本身是静态检验）。
