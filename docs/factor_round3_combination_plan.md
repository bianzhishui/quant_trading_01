- **G1 组合不劣于最优单因子**：C 超额 +9.8% vs A +7.0% → **通过，增益 +2.8pp = 明显增益**

### 归因读数

1. **组合增益来源 = 动态互补兑现**：IC 序列相关 Amihud×动量 −0.43（复现 Round 2 的 −0.42），
   两因子错峰发力：动量在 2018-2021 段 +8.7pp（单因子最强段）、Amihud 全程稳定
   （三段 +8.6/+6.9/+6.4 最均衡）。组合三段 +7.7/+15.7/+8.5——2018-2021 段叠加出 15.7pp，
   远超任一单因子；其余两段不低于 Amihud 单因子。**1+1>2 成立**。
2. **成本几乎零损耗**：C 换手 2.9（介于两单因子之间，未放大），35bp 仍 +8.4pp——
   与反转的 8.4 倍换手形成鲜明对比，这就是"可交易因子"与"方向正确但不可交易因子"的差别。
3. **D 臂（+反转）结论：反转仍是负资产**。虽然三臂合成分 IC 最高（+0.056），
   但换手被拉到 6.6（反转自身 8.4 倍换手污染），超额从 C 的 +9.8% 掉到 +7.2%
   （回到 A 单因子水平），35bp 只剩 +4.1%。**反转的方向性收益被成本完全抵消，
   在组合里也不值得救**——Round 1 反转未通过的判定得到组合层面的再次确认。
4. **回撤警示**：四臂最大回撤均 ≈ −48~−54%（C −53.9%），远深于沪深300 常规回撤。
   本池"高 Amihud=冷门股"集中暴露了流动性风险与风格风险，2024-02 微盘踩踏一类的
   极端行情对 C 臂冲击最大。**这是组合确认成立后的第一风险，必须在风控层处理**
   （如：Amihud 分位不取最极端档、行业/市值中性化、回撤熔断），而非在因子层掩盖。

## 1. 目的

回答 Round 2 遗留的核心问题：**两个有信号的因子等权打分组合，能否优于最优单因子（Amihud）**，
从而为"组合才是策略"定下实证基线。Amihud（IC 序列相关与动量 −0.42 的动态互补）+ 中期动量
是本项目目前证据最强的组合。另设 +反转 第三臂，检验"方向真实但单独不可交易"的反转
是否能在组合里被救活。

## 2. 数据与口径（沿用前两轮，零改动）

- 股票池：build_pool 同 Round 1/2（≥375 日、非 ST、非创业/科创/北交、未涨停）
- 调仓：月末信号 → 次月首个交易日执行，月度完全等权
- 收益：前复权 pct_change；停牌 NaN 视为 0
- 成本：15bp/单边基础，多头另报 25/35bp（多空毛仅示意）
- 区间：2014-01 ~ 2026-09；分段 2014-2017 / 2018-2021 / 2022-2026
- 基准：同池等权（与各臂同一池子 ∩ 因子非 NaN）

## 3. 规则（定死）

### 3.1 因子（与 Round 2 定义完全一致）

| 因子 | 计算 | 方向 |
|---|---|---|
| Amihud | mean(\|日收益\|/日成交额, 21d) × 1e6 | 高→买（+1） |
| 中期动量 | close(T−21)/close(T−250) − 1 | 高→买（+1） |
| 反转 | close(T)/close(T−21) − 1 | 低→买（−1） |

### 3.2 打分合成（等权）

每月对池内每只股票：
1. 各因子做**截面百分位排名** p ∈ [0,1]（rank 除零安全）
2. 方向调整：dir=+1 保持 p，dir=−1 用 1−p
3. 合成分 = 各因子调整后百分位的**简单平均**
4. 多头组 = 合成分最高的 **Q5（五等分）**

### 3.3 检验臂

| 臂 | 内容 | 角色 |
|---|---|---|
| A | Amihud 单因子 | 最优单因子基线（Round 2 复现） |
| B | 中期动量单因子 | 单因子对比 |
| **C** | **Amihud + 动量 等权打分** | **主假设** |
| D | Amihud + 动量 + 反转 等权打分 | 探索：反转能否在组合中被救 |

## 4. 预注册判定标准（主看 C 臂）

| 门 | 标准 | 含义 |
|---|---|---|
| G1 | C 15bp 超额 ≥ A 15bp 超额 | 组合不劣于最优单因子（A≈+7.3pp）；C−A ≥ +1pp 记"明显增益" |
| G2 | C 35bp 超额 > 0 | 成本稳健（换手没失控） |
| G3 | C 三段超额 ≥2 段为正 | 分年代稳定 |
| G4 | C 年换手 ≤ 6 | 可交易性（避免重蹈反转覆辙） |

C 臂判定 = 通过(4/4) → 组合确立为策略主体；部分通过(3/4)；未通过(≤2)。
D 臂**不参与判定**，单独报告——它的结论只有两种："反转在组合里救活了（换手可控、超额增益）"
或 "反转仍是负资产（组合被拖累）"，都如实归档。

失败协议：如实归档；禁止回头改打分权重/分位/池口径重跑。
