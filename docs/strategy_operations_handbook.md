## 1. 策略总览

**一句话**：每月末，在"可交易小盘池"内按 **Amihud 流动性 + 中期动量** 两个因子做行业内百分位打分，等权买入得分最高的前 20%（约 575 只），月度调仓，全费用全税口径长期持有。

**特征速览（300万 账户，历史全口径）**：

| 指标 | 数值 |
|---|---|
| 年化收益 | **11.9%**（基准 7.5%） |
| 全口径超额 | **+4.43pp/年** |
| 夏普 | 0.60 |
| 最大回撤 | −49.2% |
| 费用 | 1.32%/年 |
| 期末净值（12.7年） | 4.43× |
| 12.7 年累计利润 | +1029 万（本金 300万） |
| 年度区间 | −0.5% ~ +34.1% |

**核心结论（必须先读）**：
1. 策略靠"小盘冷门 + 中期动量"赚钱，**大年 +25~37%、弱年 ±0、股灾年 −0.5%**，均值可观但波动剧烈；
2. **满仓无对冲**，单年最大回撤可达 −30%（2024 年初微盘股灾），必须能拿住；
3. **资金门槛 ≈ 300万**：低于此值策略退化（买不全、现金拖累、费率暴涨），详见 §6。

## 2. 策略定义（信号逻辑）

### 2.1 可交易池（逐日过滤，全部满足才入池）

| 过滤条件 | 规则 | 目的 |
|---|---|---|
| 上市时长 | ≥ 375 个交易日（seasoning） | 剔除次新股 |
| 交易状态 | 正常交易（tradestatus=1） | 剔除停牌 |
| ST | 非 ST | 剔除风险股 |
| 板块 | 排除创业板（300）、科创板（688）、北交所（bj.） | 聚焦主板 |
| 涨停 | 当日涨幅 < 9.8%（前复权近似阈值） | 买入日涨停买不进 |
| 价格 | 有收盘价 | 数据完整 |

### 2.2 两个因子（信号日 T 计算）

**因子 A —— Amihud 非流动性（越低越好）**
```
Amihud = |当日收益率| ÷ 当日成交额 × 1e6
因子A   = Amihud 的 21 日滚动均值（min_periods=15）
```
含义：每 1 元成交额撬动的价格变动——**成交越清淡（低流动性）的股票得分越高**，是小盘冷门溢价的主要来源。

**因子 B —— 中期动量（越高越好）**
```
因子B = 收盘价[T-21] ÷ 收盘价[T-250] − 1
```
含义：剔除最近一个月（防短期反转噪声），看过去约一年（250 日）的相对动量——**中期趋势向上的股票得分越高**。

### 2.3 打分与选股（行业内百分位）

```
① 行业过滤：剔除行业内股票数 < 5 只的行业（MIN_IND=5）
② 可买池总数 < 50 只 → 跳过该月（MIN_N=50，历史仅早期个别月）
③ 因子A 行业内百分位 rank(pct=True)   → pa
   因子B 行业内百分位 rank(pct=True)   → pm
④ 综合分 = (pa + pm) / 2
⑤ 按综合分行业内排序，qcut 分 5 档（quintile），取最高档 q==4（前 20%）
→ 目标组合：约 575 只（随池子大小浮动 550~590）
```

**为什么行业内百分位**：消除行业中性（任何行业只选头部 20%），避免因子被单一行业（如医药、半导体）整体带偏；两个因子等权，A 贡献小盘溢价、B 贡献趋势，互不相关时分散最好。

### 2.4 参数表（已冻结，改动需重新预注册+回测）

| 参数 | 值 | 说明 |
|---|---|---|
| 因子A窗口 | 21 日 | Amihud 滚动均值 |
| 因子B窗口 | 21→250 日 | 动量跨度 |
| 选股比例 | 前 20%（5 档取顶档） | 组合规模 |
| 行业最小数 | 5 | MIN_IND |
| 池最小数 | 50 | MIN_N |
| 信号日 | 每月最后一个交易日 T | 月末收盘数据 |
| 执行日 | T+1 交易日收盘 | 防止未来函数 |

## 3. 组合构建与调仓

### 3.1 建仓（等权 + 1手约束）

```
每只目标股数 = int(预算 ÷ 股价 ÷ 100) × 100    （100 股 = 1 手，整数倍）
预算 = 账户总净值 ÷ 575                        （等权 575）
```
- **预算随账户资金缩放**：300万 → 5212元/只；600万 → 10430元/只；60万 → 1043元/只；
- **买不起 1 手的高价股自动跳过**（不是错误，是 1 手约束的结果）；
- 现金不足时按现金约束缩量买入，**不借钱、不满仓强买**。

### 3.2 月度调仓（每次执行日重复）

```
① 重算信号 → 新目标集合（约 575 只，每月微调）
② 卖出：上月持有、本月不在目标 → 全部卖出（可卖零股）
③ 调整：仍在目标 → |目标股数 − 当前| ≥ 1 手才动（1手无交易带）
④ 买入：新进目标 → 按等权目标买入（受现金约束）
⑤ 停牌/涨停当日不成交，按最后价计值，下月自然处理
```

### 3.3 执行纪律（不可违反）

| 规则 | 原因 |
|---|---|
| **只在 T+1 执行日收盘价成交** | 信号不可用当日数据 |
| **不择时**：每月照常调仓，不因涨跌跳过 | 等权纪律是超额来源 |
| **不干预个股**：组合内股票不做主观加减仓 | 破坏已验证权重 |
| **等权目标不动摇**：不因某月行情改预算 | 参数冻结 |

## 4. 成本与费用模型（全口径，回测已含）

| 项目 | 费率 | 说明 |
|---|---|---|
| 佣金 | 万 1.5，**单笔最低 5 元** | 双边收 |
| 印花税 | 万 5 | 仅卖出 |
| 过户费 | 万 0.1 | 双边收 |
| 红利税 | 10%（保守按 1 个月~1 年持仓口径） | 分红扣税后入账 |
| 现金 | 无息 | 闲置现金 0 收益 |
| 公司行为 | 复权因子事件补回除权缺口 | 分红/送转价值精确计入 |

> **费用是规模敏感项**：小账户每笔金额小、5 元最低佣金占比高 → 年费用率 3.17%（60万）vs 0.95%（600万），差 3.3 倍。这是"小资金不适合"的核心原因之一（§6）。

## 5. 历史验证结果（2014-2026 全口径，含全部费用税）

### 5.1 四账户全口径对比（本金 60/100/300/600万）

|---|---|---|---|---|

| 资金使用率 | 37% | 56% | 85% | 93% |
| 年化 | 8.7% | 10.4% | **11.9%** | **12.2%** |
| 全口径超额 | +1.23pp | +2.95pp | **+4.43pp** | **+4.72pp** |
| 夏普 | 0.54 | 0.57 | 0.60 | 0.61 |
| 最大回撤 | −43.5% | −47.1% | −49.2% | −49.4% |
| 费用/年 | 3.17% | 2.45% | 1.32% | 0.95% |

| 累计分红(税后) | 31.4万 | 82.7万 | 340.5万 | 715.7万 |

### 5.2 年度收益分布（300万 口径，年初建仓场景）

| 年份 | 全年 | 形态 | 最大回撤 |
|---|---|---|---|
| 2020 | +15.3% | 疫情坑后大反弹 | −12.7% |
| 2021 | +24.9% | 小盘动量大年 | −9.8% |
| 2022 | +4.4% | 4月深坑后修复 | −19.0% |
| 2023 | +10.6% | 温和上行 | −9.2% |
| 2024 | **−0.5%** | 年初微盘股灾，年底回本 | **−30.1%** |
| 2025 | **+34.1%** | 单边大年 | −13.7% |
| 2026至今 | +1.5% | 弱势横盘 | −19.9% |

### 5.3 与基准的关系

- 基准 = **同池等权 + 15bp**（与选股池相同的股票、等权、月频换手成本假设）；
- 超额 +4.43pp 是**扣掉全部费用税后**、相对"同样买这批股票但等权持有"的纯 alpha；
- 策略超额的主要来源是 **Amihud 因子**（重仓低流动性冷门股）+ 行业内百分位的行业中性设计。

### 5.4 关键结论（回测纪律）

1. **回测含全部费用税**（佣金/印花/过户/红利税/1手取整/停牌跳过），非"15bp 简化口径"；
2. **可复现**：`python research/paper_trade.py` 主程序可重跑，结果与本文一致；
3. **未做参数搜索**：所有参数 2013 年起冻结，无过拟合（多轮实验按预注册文档逐一验证）。

## 6. 账户资金规模指南（重要）

### 6.1 效率阶梯

| 档位 | 定位 | 证据 |
|---|---|---|
| **<100万** | ❌ 不适合 | 60万：超额仅 +1.23pp（策略的 1/4）、费用 3.17%/年、63% 现金闲置 |
| **100万** | ⚠️ 勉强 | 超额 +2.95pp，仍被现金拖累（44%）+ 费用偏高（2.45%） |
| **≥300万** | ✅ **最优起点** | 551/575 只、使用率 85%、费用 1.32%、超额 +4.43pp（600万 的 94%，资金一半） |
| **600万** | ✅ 效率饱和 | 575/575 全买、费用 0.95% 最低，再往上边际递减（超额只多 0.3pp） |

### 6.2 为什么 60万 不适合（机制）

1. **现金拖累**：预算 1043元/只 → 只买得起 267 只，62.7% 资金闲置零收益，好年景收益被稀释（2025：60万 +13.1% vs 600万 +36.9%）；
2. **样本缩水**：只能持有 46% 的选股，分散度与跟踪精度下降；
3. **费用侵蚀**：5 元最低佣金在千元级订单上占比极高 → 3.17%/年，复利吃掉大部分超额；
4. 唯一优点：现金缓冲使回撤更浅（2024：−15.3% vs −31.8%）——但那是"少赚换少亏"。

### 6.3 建议

- **300万 起投**：效率与资金的最优平衡点；
- **600万 上限**：超过后加钱边际收益很小，多余资金可考虑其他资产；
- **小资金（<100万）**：要么接受退化版（年化 ~8.7%，仍跑赢基准），要么改用需重新验证的集中版（如前 200 只，预算加大）——**不能直接套用 575 只验证结论**。

## 7. 风险画像与心理预期

### 7.1 必须接受的波动

- **单年可能 −0.5% 到 +34%**，年化 12% 是跨年平均，不是每年稳定 12%；
- **最大回撤 −49%（全历史）**，2024 年初微盘股灾单年 −30%；
- 回撤几乎都来自**年初小微盘踩踏 / 系统性急跌**（2022-04、2024-01~02、2026-06~07），其余时段策略自身回撤通常 <10%；
- **满仓 + 小盘 + 无对冲** = 高波动是策略定价的一部分。

### 7.2 风格周期（重要认知）

| 风格期 | 表现 | 典型年份 |
|---|---|---|
| 小盘/微盘动量年 | 大爆发 +25~37% | 2021、2025 |
| 中性震荡年 | +4~15% | 2020、2022、2023 |
| 小微盘踩踏年 | ±0 或小亏 | 2024、2026 |
| 大盘蓝筹独涨年 | 策略跑输基准 | 未出现（2013 以来样本内） |

**持有纪律**：弱势年（2024/2026）不意味着策略失效，是风格不在；**撤资/停止调仓是最差的应对**——2024 年底回本、2025 大年都在证明"拿住"的价值。

### 7.3 风险监控阈值

| 指标 | 正常区间 | 需警惕 | 行动 |
|---|---|---|---|
| 年超额 | +2~+5pp | < +1pp 持续 2 年 | 检查因子是否失效（§9） |
| 单月回撤 | < 8% | > 15% | 复核调仓是否有 bug |
| 年费用率 | 1~1.5%（300万+） | > 2% | 检查佣金/换手异常 |
| 持仓只数 | 500~590 | < 400 | 检查数据完整性 |

## 9. 监控与对账（每次 step 后必做）

### 9.1 三个对账不变量（程序已验证，用户可用 Excel 抽查）

```
① 期末净值 = 期末现金 + 期末持仓
② 期末净值 ≈ 期初净值 − 本次费用（差额 <1%，来自取整/滑点）
③ 月涨幅连乘 = 期末/期初（12 个月连乘 ≈ 全年涨幅）
```
任何一条对不上 → 账本有问题，先别继续跑。

### 9.2 月度资金变动表（output/monthly_funds_aum*.csv）

| 列 | 含义 |
|---|---|
| date | 调仓执行日 |
| pre_nav / post_nav | 下单前/后账户总值（同一天收盘价） |
| 月涨幅% | 本月净值变动（本次/上次调仓后净值 − 1） |
| 买入额 / 卖出额 | 本次调仓成交金额 |
| 换手率% | 单边换手 = (买+卖)/2 ÷ 期初净值 |
| 费用 | 佣金+印花税+过户费 |
| 分红入账 | 税后分红 |
| 期末现金 / 期末持仓 | 调仓后仓位状态 |
| **较本金盈亏** | **期末净值 − 账户本金（赚/亏了多少钱）** |

### 9.3 每日涨幅表（output/daily_nav_aum*.csv）

```
每日涨幅% = 当天收盘 NAV ÷ 前一天收盘 NAV − 1
较本金盈亏 = NAV − 账户本金
```
每天收盘后跑 `mark` 即可刷新当日涨幅。

### 9.4 预警清单

- `step` 输出"待处理 N 个月"且 N>1 → 检查是否漏跑多月；
- `mark` 警告"账本落后" → 先 `step` 再 `mark`；
- 换手率 > 50% 或费用率跳升 → 检查数据或调仓异常；
- 持仓只数骤降 → 检查行业/池过滤是否正常。

## 10. 边界与已知结论（决策记录）

### 10.1 已测试并否决的变体

**Round 11 全选满仓（预算 = 最高价×100）**：隐含资金 ~530万，年化 13.0%、超额 +5.46pp（因无意中更重仓小盘冷门）——但**费用 2.09%/年（2.2 倍）**、回撤 −50.2%、规则脆弱（一只高价股价格跳动带崩全组合预算）→ **不采纳**，600万 等权仍是稳健执行口径。

### 10.2 明确不适用场景

| 场景 | 原因 |
|---|---|
| 资金 <100万 | 策略退化（§6），效率仅为满配的 1/4 |
| 需要每年稳定收益 | 波动剧烈，弱年可能 ±0 |
| 无法承受 −30% 回撤 | 满仓小盘无对冲 |
| 频繁进出/择时 | 等权纪律被破坏，超额消失 |
| 追求大盘蓝筹风格 | 因子设计是小盘冷门+动量 |

### 10.3 待验证（未来可选）

- 因子失效检测（RankIC 滚动监控）；
- 回撤控制版（如 5% 止损线 / 等权+现金缓冲）——需预注册+回测，**当前版本不加入**。
