# 基本面数据管线 + 高股息因子实验 — 实施方案

> 状态：**待实施** ｜ v1.0 ｜ 2026-08-28
> 目标：打通 A 股基本面数据管线，使《年化30%大市值高股息轮动》帖的
> A/B/C/D 对照实验可执行，并为后续多因子研究铺路。

---

## 1. 数据能力盘点（2026-08-28 实测 baostock）

| 需求 | 接口 | 实测结果 |
|---|---|---|
| 时点股票池 | `query_all_stock(day)` | ✓ 支持历史日期，5638 行（含指数，需用 stock_basic 过滤）|
| 上市日期/类型/状态 | `query_stock_basic` | ✓ ipoDate/type/status |
| 日线 + 市净率 + ST + 停牌 | `query_history_k_data_plus` | ✓ 一次调用带 `close,pbMRQ,tradestatus,isST` |
| 现金分红 | `query_dividend_data` | ✓ `dividCashPsBeforeTax`（每股税前）；**注意：一年可能多条记录，需按年求和** |
| 净利润/总股本 | `query_profit_data` | ✓ netProfit/totalShare |
| 净利润同比 | `query_growth_data` | ✓ YOYNI |

## 2. 范围裁剪（v1 工程决策）

完整复刻帖子四层筛选需要每季度调用盈利/成长接口（800股×52季≈4万次调用，
数十小时）。v1 裁剪为：

- **纳入 v1**：PB<1（日线自带）、三年累计每股分红/现价（分红接口）、
  上市满375日/非ST/正常交易（日线+basic）→ 约占原筛选 80% 信息量
- **推迟到 Phase 2**：净利润>0、YOYNI>0、经营现金流为正（季度接口，
  只对通过初筛的 ~200 只股票补抓，量可控）
- **已知偏差（记录在案）**：baostock 无历史成分股，v1 用"当前沪深300+中证500
  成分（800只）"回测历史 → 幸存者偏差使收益**偏高**。缓解：叠加时点
  `query_all_stock` 快照剔除后来上市的股票；结论只做**相对比较**
  （A/B/C/D 之间），不做绝对收益宣称

## 3. 架构

```
src/fundamental.py        # 数据层：登录、下载、校验、parquet 存储、断点续传
  - universe()            #   时点股票池(all_stock × stock_basic 过滤)
  - download_daily()      #   800股 × 1次全历史日线(含pbMRQ/isST/tradestatus)
  - download_dividends()  #   800股 × 14年分红(按年求和)
  - 状态文件 download_state.json + data/fundamental/*.parquet

research/dividend_factor.py  # 实验层(Phase 2, 数据就绪后另行预注册细节)
  - 因子: divyield3y = 近3个日历年每股分红合计 / 当日收盘
  - 月度调仓回测(向量化, 复用 momentum 实验的框架)
```

**下载量估算**：~12,000 次 API 调用，后台 1~2 小时，断点可续传。

## 4. 实验设计（对齐高股息帖的四组对照）

| 版本 | 改动 | 验证什么 |
|---|---|---|
| A | PB<1 + divyield前50% + 爱我中华名称过滤 | 复现"原版"逻辑 |
| B | A − 名称过滤 | "中/华/爱/我"贡献（玄学 or 央企代理）|
| C | B + 滑点 10/20/30bp | 执行摩擦敏感度 |
| D | B + 严格等权 + 单票上限10% | 权重漂移贡献 |

统一设置：月度调仓（月末信号、次月首个交易日执行）、等权、成本5bp基准、
区间 2014-01 ~ 2026-08（分红数据完整覆盖）。

**预注册判定**（回测前写死，沿用四层框架）：
- ② 月超额 vs 沪深300 等权 p<0.05
- ③ 分年代（2014-17 / 2018-21 / 2022-26）每段夏普>0.3 且跑赢基准
- ④ 30bp 滑点下仍保持正向超额
- **重点读数不是绝对收益，而是 B−A（名称过滤贡献）与 D−B（漂移贡献）**
  ——如果 B−A 占大头，证明"爱国过滤器"实为央企行情代理；如果 D−B 占
  大头，证明帖子 322% 主要靠赢家漂移。
