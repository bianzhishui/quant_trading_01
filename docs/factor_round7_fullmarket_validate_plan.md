## 0. 实施结果归档（2026-09-04）

| 池 | 候选/月 | 基准年化 | 超额15bp | 超额35bp | 年换手 | 夏普 | 最大回撤 | 三段超额 |

### 判定（全市场 R5 vs 800池 R5）

- V1 超额 ≥ +3.0pp：**通过**（+4.6%）
- V2 35bp 超额 > 0：**通过**（+2.9%）
- V3 三段 ≥2 正：**通过**（3/3）
- V4 超额衰减 < 3.0pp：**通过**（5.7 − 4.6 = **+1.1pp**）
- **全市场 R5 判定：通过(4/4)** → 策略泛化成立、超额真实，**全市场 R5 定为最终策略**

### 归因读数（诚实记录）

1. **幸存者偏差贡献仅 ~1.1pp**：扩到 3194 只全市场（含被指数剔除的股票）后，
   R5 超额从 +5.7% 降到 +4.6%——之前担心的"超额大半是偏差造出来的"不成立，
   **Amihud+动量的行业内 alpha 是真实的**，约 80% 超额在扩池后保留。
2. **夏普 0.80 → 0.58 是重要代价**：全市场基准年化仅 +7.5%（800 池 +11.2%），
   且全市场等权波动更大 → 策略绝对波动上升、夏普下降。这是"去偏差"的代价：
   800 池的高夏普部分是池子更小更干净 + 基准更高收益给的，不具代表性。
3. **分段结构变化值得记录**：800 池的强段是 2018-2021（+10.7），扩池后该段只剩 +2.7；
   而 2014-2017 段反而 +8.0。说明 **800 池 2018-2021 的超额有相当部分来自中大票池环境**
   （2019-2020 大白马行情里流动性溢价/动量在大票更有效）——不是纯因子，是池子与
   行情的交互。全市场视角下三段分布更均衡（+8.0/+2.7/+3.9）。
4. **回撤 −54.6%**：全市场小票波动更大，2015 等市场级回撤略深；不改变 Round 4
   "回撤是市场 beta、选股层改不动"的结论。
5. **残余偏差**：仍含"当前上市"主连+中小板（未含完全退市股票），偏差残余但更小；
   小市值因子仍不可测（无历史市值源）。

### 结论归档

- **最终策略 = 全市场 R5**：Amihud+中期动量**行业内**百分位等权打分 → 全市场（主连+
  中小板，非 300/688/北交、非 ST、≥375 日）前 20% 等权，月度调仓，满仓。
  2014-2026：**超额 +4.6pp（35bp +2.9pp）**、换手 3.7、三段全正（+8.0/+2.7/+3.9）、
  回撤 −54.6%、夏普 0.58。
- **800 池 R5 降为"参照"**：夏普更高但池子有指数成分偏差、2018-2021 段含池子交互，
  不作为最终口径。
- 单因子判定不受影响（各轮已如实标注池边界）；本回只重估"结论可信度"——
  **可信度确认：超额真实、泛化成立**。研究主线（因子→组合→风控→中性化→扩池验证）
  至此闭环。
- 实盘化前置提醒：全市场 R5 换手 3.7、持仓含小票，实际执行成本可能高于 35bp 压测，
  若要实盘需模拟盘 + 滑点建模验证（下一步可选方向）。

## 2. 已知边界（诚实声明）

- **残余偏差**：全市场仍是"当前上市"的主连+中小板（query_stock_basic status==1），
  未含 2012 后完全退市的股票——指数成分偏差已消除，完全退市偏差残余（更小）
- **小市值仍不可测**：无历史市值源（东财/雪球被阻断），本轮专注 R5 泛化
- 中性化池=全市场 ∩ 行业≥5 只；月均持仓约 600+ 只候选、前 20% ≈ 120+ 只
