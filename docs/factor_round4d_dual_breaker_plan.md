### 归因读数（核心机制发现：两套信号在恢复期互相钳制）

1. **双熔断确实同时治住了两类回撤源**：2015 急跌 → −27.3%（4b 空仓）；
   2022/2024 阴跌 → −13.7%/−12.4%（4c 均线）。叠加本身"能覆盖两类回撤"成立。
2. **但 2015-2016 的恢复期暴露致命副作用——互相钳制**：
   - 2016 年沪深300 有 **62% 时间在 MA200 下方** → 4c 一直压半仓；
   - 同时 4b 因净值未回前高（dd 未恢复至 −15% 内）也卡在半仓；
   - **两个信号用不同基准（自身净值峰值 vs 指数趋势），股灾后净值修复慢于指数，
     导致 f=min 长期卡在 0.5**，2016-2017 的反弹（2017 指数 +20.6%）大半被踏空
3. **踏空 → 净值基数低 → 2018/2019 回撤被放大**：−36.5%/−36.8% 不是风控失效，
   而是"从被压低的基数算的百分比"——绝对亏损并不比 C 的 2018 段更深，但相对峰值
   的回撤数字更大。这解释了为什么 L1 反而比 4b 的 −41% 好看但仍不过 −30%。
4. **防守过度的代价：超额 9.8% → 3.7%（−6.1pp），满仓时间仅 47%**。用 6pp/年超额
   换"回撤从 54% 降到 37%"并不划算——尤其是 2016-2017 的踏空换来的改善很有限。

### 结论归档

- **R4d 未通过：双熔断叠加是"防守过度"，不是改进**。两套正交信号单独都有价值，
  但简单取 min 叠加在股灾恢复期互相钳制、踏空反弹，净效果为负。
- **风控层四轮实验的最终结论**：
  - C 满仓 = 最高超额（+9.8pp）、最高回撤（−54%）
  - 4b 回撤熔断 = 治急跌、夏普最高（0.98）、超额 −4.1pp
  - 4c 均线择时 = 治阴跌、超额代价更小（−3.3pp）
  - 4d 双熔断 = 叠加失败（互相钳制）
  - **没有任何风控把回撤压进 −30% 内还保住 ≥4pp 超额**——回撤管理的本质是
    "用 beta 收益换 beta 风险"的定价，在本池/本回测口径下交易不划算
- **最终策略主体 = 满仓 C**（Amihud+中期动量前 20% 等权，超额 +9.8pp、夏普 0.91、
  换手 2.9、三段全正）；风控层结论归档为"已知边界"：若实盘强烈偏好低回撤，
  可选 4c（均线择时，超额 −3.3pp 换阴跌回撤减半），不推荐 4d
- **风控层研究到此收束**（4b/4c/4d 三连已把机制摸清）；下一步若继续，
  方向是**扩大股票池/换池**（当前 800 只中大票池对因子苛刻是最大结构性约束，
  见 Round 1/2 结论）或**行业/风格中性化**（降单边波动），而非再调风控参数

## 1. 机制（定死）

- **仓位 f_4d(t) = min( f_4b(t), f_4c(t) )**
  - f_4b：回撤熔断状态机（满仓 1.0 / 半仓 0.5 / 空仓 0.0，阈值 −20%/−30%，含迟滞）——同 4b
  - f_4c：均线择时（满仓 1.0 / 半仓 0.5，沪深300 vs MA200，2% 迟滞带）——同 4c
  - 两者都"点头"（都要求降仓）才降，任一要求降到最低档就取最低档
- **生效**：每日权重 = f_4d(t) × C 目标权重；降仓/回补按 15bp 单边计成本；现金收益 0（保守）
- 触发信号各自独立计算（4b 用自身净值峰值回撤、4c 用指数趋势），互不干扰

## 2. 口径（除叠加外与 C/4b/4c 完全一致）

- 池/因子/打分/多头组/月度调仓：同 C；成本 15bp 基础 + 25/35bp 压测；基准=公共池等权

而不是硬调参数。

## 5. 预期管理

- 预期 f_4d 大部分时间 ≤ 两者中较低者 → 净值日"满仓"占比会更低（可能 <50%），
  意味着更少的市场暴露、更低的收益、更低的回撤——L2 就是判断这个取舍是否值得的边界
- 2015 段：4b 的空仓信号 + 4c 的滞后半仓 → 空仓应如期触发，回撤由 4b 主导压到 ~−27%
- 2018 段：4c 的均线半仓主导 → 回撤 ~−22%
- 若 L1 过但 L2 不过：双风控回撤达标但收益代价过大 → 结论"防守过度"，
  需在 C（满仓）与 4d（重防守）之间按风险偏好选档，如实归档两者全貌
