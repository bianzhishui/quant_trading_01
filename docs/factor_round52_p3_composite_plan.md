# Round 52 预注册：P3 池内多因子合成打分（低波 × 低PB × 低MAX）

状态：**⏸ 预注册（用户已批准"多因子合成验证"方向）**｜对象：P3 低价股策略｜基准：P3 现冻结参数（P0）

## §1 问题

R51 证明 **A1 低波60 是唯一通过预注册判据的变体**（回撤 −25.0%→−21.6%、年化 +18.2%→+19.8%、
夏普 0.91→1.03），并超过 X0 集中度对照；同时 B1 低PB（年化 +1.9pp、夏普 +0.099）与
A3 低MAX20（年化 +20.1%、全样本 +23.1%）各自只差一丝或只缺一个维度。

本轮问**新问题**：把 R51 中最优/近失因子做**池内百分位等权合成**后取前 N%，
能否**同时**（a）超过 P0 的收益与回撤，（b）**超过单因子 A1**？——即"合成"是否比"单因子低波"更强。

**P3 至今没有任何打分/排序机制**（只有过滤 + 全取等权），本轮首次引入池内打分。

- **低波与低IVOL 秩相关 0.917 → 在 P3 池内实质是同一因子**（该池对中证1000 的 R² 仅约 0.18），
  因此"低波+低IVOL"合成预期≈低波单因子，合成增量只能来自**独立性更高的低PB（0.26-0.31）**
  与部分独立的低MAX（0.57-0.58）
- 非对角平均秩相关 0.474 → 合成空间存在但有限

## §2 变体定义（规则定死，不试参）

**基底**：`build_sets(data, None, sub_price=(3.0,4.0), n_years=3)` → 各信号日 T 的 P3 合格池 B[T]；
信号月末 T 收盘 → T+1 收盘执行；窗口 2014-01 起；成本 15/45/60bp；全部因子用 T 及之前数据。

**合成规则（冻结）**：
1. 池内对每个因子取**百分位排名**（0–1，**越大越好**，方向已统一为"低值优先"）；
2. **等权平均**（不设差异化权重，避免权重过拟合）；
3. 缺失值记最差（百分位 0）；
4. 按合成分降序取**前 KEEP 比例**（默认 70%，与 R51 截断口径一致）；
5. 选中者**等权**持有（权重方式不变）。

## §3 判定标准（预注册）

**主判对象 = Z1**（最优先验）；Z2-Z4 用同一判据，若多个通过则取"相对 A1 更优"者。

通过需**全部满足**：

1. 验证段（2021-2026）最大回撤改善 **≥ 3pp**（相对 P0）
2. 年化 ≥ P0 + 2pp **或** 夏普 ≥ P0 + 0.10
3. 45bp 年化 ≥ P0₄₅
4. **不劣于单因子 A1**：年化 ≥ A1 − 0.5pp **且** 回撤不深于 A1 1pp 以上
5. 分年度 ≥ 半数年份不差于 P0
6. 若改善幅度 ≤ X0 的改善幅度 → 判"不可区分于纯集中度效应"，不采纳

Z5 额外要求：报告持仓数，若近年持仓 < 30 只则直接判失败（分散度下限）。
统一直报：60bp 极端成本、Calmar、月均/近年持仓、三段（2014-17/2018-21/2022-26）年化与回撤。

## §5 诚实风险（预注册时已知）

1. **vol/ivol 相关 0.917** → Z2/Z4 很可能≈Z1，合成的真实增量可能只来自 PB 一个维度
   （即"低波+低PB"的两因子效果可能被 PB 单因子部分解释——但 R51 的 B1 低PB 单因子未达标，
   说明 PB 单独不够、低波单独够，两者合成仍需实测）
2. **A1 的近年依赖会传导**：R51 显示低波增益集中在 2022-26、2014-17 跑输 1.7pp/年
   （2015 单年差 26pp）；合成版大概率继承该特征
3. **首次引入打分机制** = 策略复杂度与过拟合面上升：百分位、等权、70% 均为固定选择，
   但仍是为同一 2014-2026 样本第 12 轮挖掘
4. **持仓数下降**（61→43，近年 51→36）：单票风险上升，小账户 1 手退化加重；50% 档（Z5）
   持仓≈30 只接近下限
5. **PB 的价值陷阱**：破净股常伴基本面瑕疵（P3 已有扣非为正+低负债部分缓解）
6. **合成可能两头不到**：低波提"稳定性"、低PB提"估值修复"，但两者可能在不同年份兑现，
   导致回撤或收益被中和
