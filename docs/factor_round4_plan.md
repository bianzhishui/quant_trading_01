### 判定（R4a vs C）

### 归因读数（重要负结果）

1. **最大回撤区间两臂完全相同：2015-06-12 ~ 2015-09-15**——这正是 2015 年股灾
   （6 月中见顶、三轮千股跌停、8 月底部）。**剔除冷门股极端档对回撤几乎没有改善**，
   因为 −54% 的回撤是**市场级 beta** 造成的，不是持仓中个别冷门股的踩踏。
   2015 股灾里所有 A 股（含本池 800 只中大票）都跌，冷门不冷门区别不大。
2. **剔除极端档反而损收益**：超额从 +9.8% 掉到 +7.7%（损失 2.2pp），换手从 2.9 升到 4.7
   （窗口收窄导致边界股票月月进出）。说明合成分最极端 5% 里**确实有正 alpha**
   （冷门+高动量双高股反而更便宜），剔除是"用真收益换几乎不存在的回撤改善"。
3. **结构性结论**：Amihud 因子的冷门暴露带来的是**稳健的流动性溢价**（三段全正），
   不是可被尾部剔除规避的踩踏风险。回撤必须用**风控层手段**（回撤熔断/仓位管理/对冲）
   去管，而不是在因子/选股层回避冷门股——那会把 alpha 一起丢掉。
4. **口径校正**：C 臂实际平均持股 103 只（非 Round 3 归档误写的 ≈40 只）；
   Round 3 归档中该处表述有误，此处正式更正。

### 结论归档

- **R4a 淘汰**：尾部剔除既不改善回撤又损超额，禁止调窗口数字重跑
- **下一步 Round 4b（预注册）**：**回撤熔断/仓位管理**（风控层）——在 C 基线上叠加
  回撤触阈值降仓（如最大回撤 > 20% → 仓位 ×0.5；> 30% → 空仓观望，回稳后再进），
  目标把 2015 股灾段的 −54% 压到可承受区间。**风控层不触碰因子/选股逻辑**，
  与 R4a 的选股层改动形成对照，归因干净
- 备注：行业中性化（优先级 #2）仍有价值（降低风格集中），但因回撤主因是市场级，
  优先级让位于熔断；若后续要降单边波动，再做行业中性

## 1. 假设

C 臂最大回撤 −54% 的一个可能来源：**合成分最极端档（冷门+高动量）的股票在极端行情
（如 2024-02 微盘踩踏）中集中崩盘**。通过把多头组从合成分百分位 80-100 收窄到 80-95
（剔除最极端 5%），应能在几乎不牺牲超额的前提下显著改善回撤。

## 2. 口径（与 Round 3 C 臂完全一致，除标注的单一改动）

- 股票池：build_pool（≥375 日、非 ST、非创业/科创/北交、未涨停）∩ 两因子非 NaN
- 因子：Amihud = mean(|ret|/amount, 21d)×1e6；中期动量 = close(T−21)/close(T−250)−1
- 打分：截面百分位 + 方向调整 → 合成分 = 两因子百分位等权平均
- 调仓：月末信号 → 次月首个交易日执行；月度完全等权
- 收益：前复权 pct_change；停牌 NaN=0；成本 15bp 基础 + 25/35bp 压测
- 区间 2014-01~2026-09；分段 2014-2017 / 2018-2021 / 2022-2026；基准=公共池等权
- **校正**：Round 3 归档"多头 ≈40 只"有误——本池月均可投约 700 只，Q5(20%) 实为
  **≈120-140 只**。本文档如实报告各臂实际平均持股数，不沿用错误口径

## 3. 规则（定死）

## 4. 预注册判定标准（看 R4a vs C）

| 门 | 标准 | 含义 |
|---|---|---|
| H1 | R4a 最大回撤 < C 最大回撤 − 3pp | 回撤实质改善（主目标） |
| H2 | R4a 15bp 超额 ≥ C 15bp 超额 − 1.5pp | 超额损失可接受（不砍掉太多 alpha） |
| H3 | R4a 35bp 超额 > 0 | 成本稳健 |
| H4 | R4a 三段超额 ≥2 段为正 | 分年代稳定 |

判定 = 通过(4/4) → 采纳 R4a 为策略主体；部分通过(3/4) → 视 H1 是否过（H1 是主目标）；
未通过(≤2) → 保留 C，**结论如实归档**，Round 4b 换另一项改动（行业中性化或回撤熔断），
禁止回头改本项参数重跑。

失败协议：如实归档；禁止调参重跑；若 R4a 无法改善回撤，正确结论是
"极端档不是回撤主因，冷门暴露是全局性的"，而不是强行换一个窗口数字凑出改善。
