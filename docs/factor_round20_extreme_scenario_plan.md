### 0.2 运营实操指南（结论）

1. **极端段单账户最大回撤区间**（满配 600万）：S1 股灾 **−50%**、S2 熊市 −33%、
   S3 微盘 −32%、S4 熊市 −20%——与风控五轮"−50% 级回撤是市场定价"完全一致；
2. **"扛住不割肉"的量化后果**：
   - S4（2022）：谷底后 **31~41 个交易日恢复**，全年区间收益 **+4~6%**（沪深300 −21% 未恢复）；
   - S1（股灾）：扛一年，60万 几乎回本（−0.8%）、满配 −20%，但相对沪深300 超额 **+17.5pp**；
   - S2/S3：区间内未恢复——需要更长持有期（月频等权摊薄了反弹，慢变量）。
3. **60万 现金缓冲的实测保护**：S1 回撤 −32% vs 满配 −50%（**差 18pp**）、S3 −15% vs −32%
   （**差 17pp**）——1手约束的"副作用"恰是极端段天然的减震器，小账户抗跌约一半；
4. **与风控五轮一致性确认**：熔断/均线/双熔断/拥挤度择时均被否决、扛住+深坑不割肉
   是唯一验证可行的应对——本演练给出具体数字支撑（S4 扛住即恢复盈利；S1 扛住一年
   满配回撤减半于大盘超额 17.5pp）；
5. **沪深300 对照**：S1/S4 大幅跑赢大盘；S2 相当；**S3 微盘危机跑输**（结构性冲击
   小盘冷门，但 60万 缓冲后 −8.6% 接近大盘）——极端段不是"全部躺赢"，微盘危机最危险。

## 1. 背景与动机

风控五轮结论：`−50% 级回撤是 Amihud+满仓小盘的市场定价，扛住+深坑不割肉是唯一验证
可行的应对`。本演练把这一结论**量化落地**：用现有回放引擎，让四账户从历史极端行情
起点建仓，观察实际回撤、谷底、恢复路径，输出运营手册的实操指南（"极端段会发生什么、
扛住多久能回来"）。

## 3. 规则（定死）

- **引擎**：`scenario_ytd` 同款回放（R5 等权575 + 全口径成本：佣金万1.5最低5元/印花万5/
  过户万0.1/1手取整/现金无息/分红税10%），仅建仓起点 = 场景区间起点（信号 T 后首个执行日）；
- **四账户**：60万/100万/300万/600万（1手约束自然体现，60万 现金缓冲最厚）；
- **重构**：`scenario_ytd.py` 核心抽成 `run_scenario(start, end, out_prefix=None)` 函数
  （main 壳行为不变），新脚本导入复用（AGENTS.md §5.6 导入约定）；
- **大盘对照**：沪深300 同期（`data/idx000300_daily_20130601_20260904.csv`，最新数据文件）。

## 4. 统计口径（定死）

每场景 × 每账户（及沪深300）：
- 区间最大回撤（区间内峰值→谷底 %）、**谷底日期**、峰值→谷底天数；
- **恢复天数**（谷底后回到峰值所需交易日，区间内未恢复标"未恢复（至区间末 −x%）"）；
- 区间末相对建仓本金累计收益；
- **四账户对比行**：60万 vs 600万 的回撤差（现金缓冲效果量化）。

## 6. 诚实风险

1. 回放是"按场景起点重新建仓"的**假设场景**，非运营账户真实轨迹（运营从 2026-09 才建仓）；
2. 历史极端行情不预示未来，演练目的是"纪律教育+心理准备"，不是预测；
3. 2015-06 建仓点在 R5 回测区间内（2014-01 起），数据完备；
4. 沪深300 对照仅作大盘背景，非同池等权基准（避免误读超额）。
