## 1. 成本模型（定死，2026-09 已联网核实）

| 项 | 费率 | 说明 |
|---|---|---|
| 佣金 | 万1.5（0.00015），**单笔最低 5 元** | 双边；监管底线不可免 |
| 印花税 | 万5（0.0005） | 仅卖出 |
| 过户费 | 万0.1（0.00001） | 双边，中国结算 |
| 滑点 | **默认 0**（限价单），`--slip` 参数可加 | 保守假设限价单无滑点 |
| 1 手 | 买入 100 股整数倍取整；卖出允许零股清仓 | A 股规则 |
| 现金 | 不产生收益 | 1 手取整的现金拖累如实计入 |

- **调仓口径**：每月向目标等权再平衡，仅当 |目标−当前| ≥1 手才交易
  （1 手约束下自然退化为"进出为主 + 大漂移校正"，符合 §5 执行设计）
- **执行时点**：月末 T 信号 → T+1 按**执行日收盘价**成交；停牌股跳过（不交易、按最后价计值）
- 净值 = 现金 + Σ股数×价格（逐日盯市），与收益复利法不同但更贴近真实账户

## 3. 判定（对比理想化回测 +4.6pp@15bp / +2.56pp@s40）

无通过/不通过门，如实报告**全口径超额**与"真实执行代价"（= 理想化超额 − 全口径超额）：
- 真实执行代价 = 佣金/印花/过户 + 5 元最低佣金 + 1 手取整现金拖累 + 停牌跳过
- 若全口径超额仍 ≥ +2.0pp → 结论：真实可执行，费率税后仍显著为正
- 若 1.0~2.0pp → 结论：勉强为正，执行质量（限价/拆单）决定成败
- 若 <1.0pp → 结论：费率税与 1 手约束吃掉大部分超额，策略在真实执行下优势微弱
- S4（10 万）预期展示不可行（多数标的 0 手）——如实呈现，不改任何参数
