## 0. 实施结果归档（2026-09-03）

### C_base vs R5 对照（2014-01 ~ 2026-09，140 期，扣 15bp，中性化池月均 460 只，基准年化 11.2%）

| 臂 | 打分 | 超额15bp | 超额35bp | 年换手 | 夏普 | 最大回撤 | 三段超额 |
|---|---|---|---|---|---|---|---|
| C_base | 全局百分位 | +9.7% | +8.2% | 3.0 | 0.90 | −53.8% | +5.7/+17.0/+8.9 |
| **R5** | **行业内百分位** | **+5.7%** | **+4.1%** | 3.4 | 0.80 | −51.8% | +2.2/+10.7/+5.7 |

### 判定（R5 vs C_base，同一中性化池，仅"排名基准"不同）

- N1 超额 ≥ +4pp：通过（+5.7%）
- N2 35bp 超额 > 0：通过（+4.1%）
- N3 三段 ≥2 正：通过（3/3）
- N4 行业beta贡献 < 4pp：**压线通过**（+4.0pp）
- **R5 判定：通过(4/4)** → 采纳 R5（行业中性化）为默认策略

### 归因读数

1. **行业内 alpha 真实存在**：剔除行业排名差异后，R5 仍 +5.7pp 超额、三段全正、
   35bp 仍 +4.1pp——Amihud+动量的选股信号不依赖行业踩点，是**行业内**的。
2. **行业 beta 贡献 ≈ +4.0pp，正好压在 N4 的 4pp 门槛上**（±0.1pp 内）：
   C 的超额 +9.7pp 中约 **40% 来自行业暴露**（某些行业系统性更冷/更流动，
   全局排名自然超配它们），60% 来自行业内选股。这不是"免费午餐"——
   行业中性化用 4pp 超额换掉了行业集中风险。
3. **行业中性化的实际收益**：回撤 −53.8% → −51.8%（略改善）、持仓不再单押冷门行业
   （结构上更分散、风格风险更低）。但注意：**回撤主因仍是市场级（2015），
   行业中性化不解决 2015 型回撤**（与 Round 4 结论一致）。
4. **N4 压线的诚实警示**：行业 beta 贡献 4.0pp 若未来放大（某行业持续走强），
   中性化版的相对价值会更高；反之若行业 alpha 增强，C 满仓版会重新占优。
   两条路径都记录在案，不预判。

### 结论归档

- **默认策略升级为 R5（行业中性化版）**：Amihud+中期动量**行业内**百分位等权打分，
  合成分前 20% 等权，月度调仓。2014-2026：超额 +5.7pp（35bp +4.1pp）、换手 3.4、
  三段全正（+2.2/+10.7/+5.7）、回撤 −51.8%。
- **对比记录**：原 C（全局排名）超额 +9.7pp 更高但含 ~4pp 行业 beta（集中风险）；
  R5 是"去行业风险后的诚实 alpha"版，作为默认。
- 中性化池月均 460 只（剔除 <5 只/月的行业），基准与两臂共用，归因干净
- 下一步候选：① 把 R5 与"可选风控 4c 均线择时"叠加（去行业 + 防阴跌，两层正交）；
  ② 行业 beta 显式预算（允许一定行业偏离但设上限，取 C 与 R5 的折中）；
  ③ 扩池（结构性，见 Round 1/2 结论）

## 1. 机制（定死）

- **行业分类**：baostock 证监会行业大类（`query_stock_industry`，如 C39 计算机通信电子），
  静态映射，已存 data/round2/industry.parquet
- **中性化池**：每月股票池 ∩（该行业当月 ≥5 只有效）——剔除小行业（<5 只），
  保证行业内排名有统计意义。**基准与两臂共用同一中性化池**
- **中性化方式**：每个因子先在**行业内**做百分位排名（每行业内最好的给 1.0），
  合成分 = 两个行业内百分位的等权平均，多头 = 合成分前 20%
- **对照设计（关键）**：
  | 臂 | 打分 | 池 |
  |---|---|---|
  | C_base | 全局百分位（原始 C 方式） | 中性化池（与 R5 相同，隔离"池变小"的混淆） |
  | **R5** | 行业内百分位 | 中性化池 |
  - 两臂差异**只有"行业内 vs 全局排名"**，池/基准/成本完全一致 → 归因干净
- 调仓/成本/区间/分段同 Round 3（15bp 基础 + 25/35bp；2014-2026；三段）

## 2. 预注册判定标准（看 R5 vs C_base）

| 门 | 标准 | 含义 |
|---|---|---|
| N1 | R5 15bp 超额 ≥ +4.0pp | 行业内 alpha 仍有实质超额 |
| N2 | R5 35bp 超额 > 0 | 成本稳健 |
| N3 | R5 三段超额 ≥2 段为正 | 分年代稳定 |
| N4 | 行业beta贡献 = C_base超额 − R5超额 < +4pp | 行业 beta 不是超额主因（若贡献 >4pp 说明原超额半壁是行业） |

判定 = 通过(4/4) → **采纳 R5（行业中性化）为默认策略**（去行业风险且 alpha 基本保留）；
部分通过(3/4)；未通过(≤2) → 保留 C，如实记录"C 的超额主要来自行业 beta"。

## 3. 预期管理

- 若 N1 塌掉（R5 超额 ≤2pp）：结论 = **Amihud 的流动性溢价是"跨行业"的**——
  "买冷门"本质是"买冷门行业"，行业内冷门无超额 → 中性化后的诚实 alpha 很弱
- 若 N4 不过：行业 beta 贡献 >4pp → 需要把"行业暴露"作为**显式风险预算**管理
  （允许行业偏离但设上限），而非完全中性化
- 若 N1~N4 全过：行业内 alpha 真实存在，中性化是免费的去风险升级，直接采用
