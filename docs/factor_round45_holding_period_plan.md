# Round 45 持有期敏感性（买入长期持有 vs 月频调仓）—— 预注册计划 v1.0

日期：2026-09-22 ｜ 状态：**待批准** ｜ 触发：用户指出 R41-44 实为月频轮动，非"长期持有"

## 0. 研究问题

用户原意"入手一只 2 元股长期持有"，而 R41-44 实现为**月频调仓**（每月换血）。
本 Round 用**同一选股规则**对比不同持有/换仓频率，回答：
1. **买入持有（1/3/5 年不动）vs 月频轮动**：收益/回撤谁优？
2. **滚动买入持有的结果分布**（任意时点买入持 3/5 年：胜率、中位年化、最差结局）——
   直接回答"拿着不动行不行"。

## 1. 预注册规则（定死）

### 1.1 选股规则（固定 = Round 44 V1，不再变）
- 真实价 ∈ [2.3, 3.2)；上市 ≥375 天；非ST；近 3 年报扣非均为正（严格口径）；
  负债率<70%；20 日均额 ≥500 万；近 3 年有分红；等权；15bp/45bp；退市归零（敏感性：最后价清算）

### 1.2 换仓频率变体
| 变体 | 重选频率 | 说明 |
|---|---|---|
| **M 月频** | 每月（基准，= R44 V1） | 现有 |
| **Y 年频** | 每 12 个月重选 | 近似"年度买入持有" |
| **H3 三年持有** | 买入后 36 个月不动 | 严格长期持有 |
| **H5 五年持有** | 买入后 60 个月不动 | 严格长期持有 |

信号/执行：重选日 = 该频率的月末最后交易日（T+1 收盘执行）；持有期间不调仓。

### 1.3 判定（预注册）
| # | 标准 | 通过条件 |
|---|---|---|
| ① | 持有期 vs 月频（验证段 2021-2026 年化差） | H3/H5 年化 **≥ 月频 − 2pp**（长期持有不显著更差） |
| ② | 持有期最大回撤 | H3/H5 **≤ 月频 + 5pp**（可接受） |
| ③ | 滚动买入持有 3 年胜率（全样本任意月末起点） | **≥ 60%** 正收益 |
| ④ | 各持有期 vs 全市场 | H3/H5 跑赢同段全市场（年化） |
| ⑤ | 可交易性 | 45bp 下 H3/H5 年化 ≥ 全市场（换手低，应易过） |

①-⑤ 全过 = 通过（长期持有可行）；否则未达标（如实归档）。
**附加报告**（不判定）：滚动持有 3/5 年的年化分布（中位/最差/最好）、月度换手实际值、
"长期持有 vs 月频"的收益来源拆解（换血价值 vs 持有完整命运）。

## 2. 诚实风险
1. **起点依赖**：买入持有结果强烈依赖买入时点——用全样本所有月末起点滚动平滑，
   但起点数有限（~150 个），最差/最好端受少数起点影响
2. **持有期内无换血**：池子劣化时（如 2026）3/5 年持有会持有变坏的股票（这正是对比意义）
3. **退市归零**：持有期内退市股按归零处理（敏感性：最后价清算）
4. **权重简化**：滚动持有用等权日收益（无权重漂移再平衡），与月频 W 固定口径一致
5. 沿用已知局限（涨跌停未建模、财务重述残余）
