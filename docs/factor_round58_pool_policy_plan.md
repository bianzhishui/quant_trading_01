### §0.2 空池月的权威口径（X3，核心结论）

全区间**恰好 5 个空池月：2015-04-01 / 05-04 / 06-01 / 07-01 / 08-03**（P0 与 A1 完全相同；

| 口径 | 空池处理 | 全样本 | 2014-17 | 2018-21 | 2022-26 |
|---|---|---|---|---|---|
| P0 | `cash`（旧报告） | +15.73% / −45.61% | +26.72% / −34.52% | +8.81% / −36.99% | +14.43% / −25.00% |
| P0 | **`hold`（=生产）** | **+16.53% / −65.52%** | **+29.67% / −58.49%** | +8.81% / −36.99% | +14.43% / −25.00% |

| A1 | **`hold`（=生产）** | **+17.68% / −64.60%** | **+32.75% / −58.85%** | +7.75% / −34.86% | +16.22% / −21.70% |

**结论**：空池月让年化略升（+0.8pp P0 / +1.4pp A1），但**回撤骤深约 20pp**（−45.6%→−65.5%）——

### §0.4 我自己的判据/假设错误（如实记录，不改阈值）

1. **Y2 判据设计有误（作废）**：把「新开窗口起跑」当成「延续序列」比。空池月起跑的
   `run_scenario_p3(2015-04-01,…)` 首月目标即空池 → 全程空仓 → 0.00%，与"已持仓再经历空池月"
   完全不是一回事。
   **补充测量（不重判）**：在**同一延续序列**上比 2015-05~08（4 个月）：等权 `hold` **−16.34%**
   vs 份额级 **−11.27%**（差 **5.07pp**）、等权 `cash` 0.00%（差 11.27pp）→
   **hold 口径把失真减半，但仍非逐位一致**；故权威口径仍是份额级，等权只作趋势参考。
2. **Y7-X6 的 R5 部分非等价（按预注册回退）**：统一 helper 写法 vs R5 现行约定
   （`reindex(idx).ffill().bfill()`）在 2013-06~2014-12 有 **194,710 个 stock-days 差异**
   （1,376 只；比率中位 0.9847、p10 0.6254）→ 不是等价重构，若强改会动 R5 早年历史数字。
   按 §4-2「有差异则回退、不做」**未改 R5 两处**；差异已写成测试断言，防止后人静默统一。
   → R5 面板口径彻底统一留作 R59+（须 R5 侧预注册 + 回归）。
3. **Y6 未达标**：残差 4.83pp 超出我预设的 2pp。诚实说明：等权与份额级的差异不止我列的
   三项——还有整手权重漂移、无法完全按目标权重成交、现金拖累、分红税 10%（前复权收益隐含
   红利再投但未扣税）等；这些量级在别的年份是 ±1.5~1.9pp，2014（+105% 年）被放大到 4.8pp
   **量级上可理解，但未被我预注册的三项解释** → 记为待查，不再追（避免事后改判据）。

### §0.5 面板体检门（X2，新增防线）

`tests/test_data_panel.py`（默认 4s，`pytest -m slow` 加跑全市场层 19s）：

| 检查 | 内容 | 判别力 |
|---|---|---|
| **I1** | 面板因子在 t 必须等于「t 时点生效的记录值」（无更早记录→最早一条）——期望值由**独立 numpy searchsorted** 给出，不调用被测函数 | 旧写法实测数千处违规 → 必失败 ✅ |
| **I2** | 因子只允许在**记录日**当天跳变 | 同上 |
| **I3** | `real × factor == close`（相对 1e-8） | 构造性恒等 |
| **I4** | 非记录日 `\|Δreal\| > 12%` 占比 ≤ 0.1%（比 R57-W3 的 shift 掩码更严） | 辅助 |
| **I5** | **判别力自证**：旧写法必须 ≥1 违规、helper 必须 0 违规；R5 约定差异 >0 违规（固定记录） | 防"橡皮图章" ✅ |
