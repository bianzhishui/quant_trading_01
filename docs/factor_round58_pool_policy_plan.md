## §2 改动（规则定死）

**X1（研究工具，1 行）**：`scripts/factor_round41_low_price.py` 的 `ew_nav(ret, sets, cost)`
→ 增参 `empty_mode: str = "cash"`：
- `"cash"`（**默认，保持现状**）：`S` 为空 → 权重置零（持币）；
- `"hold"`：`S` 为空 → **不重设权重**（沿用上月持仓）= 与 `PaperPortfolio`/生产一致。
默认值不变 → 所有既有引用逐位回归。

**X2（新增测试）**：`tests/test_data_panel.py`（新文件，**只读**，不写任何真实数据文件）：
1. **T1 恒等式**：对每只有因子记录的股票，在其首条索引内记录之后的日期上
   `|real × factor − close| ≤ 1e-8`（相对）；
2. **T2 涨跌停不变式**：全区间、**非因子变动日**，`|Δreal| > 12%` 的 stock-days 占比 ≤ 0.1%；
3. **T3 静默兜底哨兵**：任一股票"索引内首条因子记录之前"的 `real` 不得整段等于 `close`
   （即不得出现因子回落 1.0）——正是 R41 bug 的签名。
> 数据来源：`data/round2/adjust_factor.parquet` + `data/fundamental/full_daily/*.parquet`（只读）；
> 测试对 `load_data()` 做一次 session 级缓存以控制耗时。

**X3（研究口径重算）**：等权 P0 与 A1，用 `empty_mode="hold"` 重算
**全样本（索引起~2026-09-28）+ 三段（2014-17 / 2018-21 / 2022-26）**，与 `"cash"` 口径并列成表。

**X4（R50 复核）**：`run_scenario_p3(..., block=True/False)`，600万 S0，两窗口
（验证段 2021-01-04→2026-09-28、全样本 2014-02-10→2026-09-28），给出修正后的

**X5（2014 残差归因）**：对 2014 年，分别给出 (a) 建仓日错位（份额级 2014-03-03 起 vs 等权从 01 起）、

**若 X6 涉及 R5 生产文件**，只做等价替换并以「R5 运营窗口 + pytest」回归证明零差异。

## §4 诚实风险

1. **hold 口径会把历史回撤推得更深**（预期全样本 DD 从 −45.6% 向 −69% 靠拢）→ 必须如实披露，
   不得因为"数字变难看"而改判据或回避；
2. **X6 触碰 R5 生产文件**（`paper_trade.py`/`paper_live.py`）→ 属等价重构，须以回归证明零差异；
   若回归有任何差异则**回退、不做**；
3. **X4 可能推翻手册现有结论**（R50 的 +7.4pp/年）→ 如实改写；
4. **T1/T2 依赖"因子变动日"掩码的准确性**：掩码本身用同一份因子表构造，属同源验证
   → 故 T1（恒等式，独立于掩码）与 T3（bug 签名）为主判据，T2 为辅；
5. **不重新抓取数据**（若因子表本身缺 2013-2015 记录，残差无法恢复，只能披露）；
6. 运行时：1 次数据加载 + 等权重算（秒级）+ 份额级约 10 次回放（≈15-20 分钟）→ 后台单次跑完；
   **先 `git add` 新脚本再归档**（R57 教训：归档器回滚会删未入库文件）。
