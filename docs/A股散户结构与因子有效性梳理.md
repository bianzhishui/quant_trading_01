# A股散户结构与因子有效性梳理

> 面向量化研究的参考笔记。数据为公开口径约数，时效截至 2025 年中前后；
> 涉及具体数字请在实盘前用中国结算/交易所年鉴最新一期核实。

---

## 1. 市场微观结构：谁在交易 A 股

### 1.1 数量与占比

| 维度 | 数据（约数） | 来源口径 |
|---|---|---|
| 投资者总数 | 2 亿+（2023-02 首次突破 2 亿） | 中国结算 |
| 自然人账户占比 | ≈ 99% | 中国结算 |
| 单户规模 | 过半账户市值 < 10 万；绝大多数 < 50 万 | 交易所年鉴 |
| 交易额占比（自然人） | 长期 70%–85%，近年约七成 | 上交所/深交所统计年鉴 |
| 流通市值占比（自然人） | ≈ 20%–25% | 交易所年鉴 |
| 一般法人持股市值占比 | ≈ 55%–65%（多为产业资本/大股东） | 交易所年鉴 |
| 专业机构持股市值占比 | ≈ 15%–20% 且持续上升 | 交易所年鉴 |

**核心结论：A 股是"散户定交易、法人定筹码、机构在中间"的结构。**
散户人数压倒性多数、贡献大部分成交额，但持有流通盘不足三成；
大量筹码锁定在一般法人手里，天然流动性差。

### 1.2 与成熟市场对比

- 美股：机构持股 60%+，散户交易占比约 20%–25%（2020–2021 散户热潮期一度冲到 30%–40%）。
- 港股：成交以机构与做市为主，散户占比远低于 A 股。
- 因此很多美股/全球市场的因子规律（动量、低频基本面）搬到 A 股会变形，**微观结构不同的市场，alpha 的来源不同**。

## 2. 散户行为特征（学术证据）

| 行为 | 代表文献 | A 股表现 |
|---|---|---|
| 处置效应（赢小亏大，急于卖盈持亏） | Feng & Seasholes (2005, JF) | 中国券商账户数据证实，散户强于机构 |
| 注意力驱动买入（买"抢眼"的票） | Barber & Odean (2008, RFS) | A 股涨停板、龙虎榜、股吧热度 = 注意力代理变量 |
| 彩票偏好（偏好高偏度/暴涨标的） | Bali, Cakici & Whitelaw (2011, JFE) 的 MAX 因子 | A 股显著强于美股 |
| 正反馈交易（追涨杀跌） | 大量国内研究 | 短期过度反应 → 反转效应强 |
| 壳价值投机（买小票赌借壳） | Liu, Stambaugh & Yuan (2019, JFE) 讨论 | IPO 管制时代特有，注册制后弱化 |

这些行为直接映射为可交易的横截面规律，见下一节。

## 3. 因子逐个梳理

有效性评级（A 股长期历史口径）：★★★ 很强 / ★★ 中等 / ★ 弱或失效。
"现状"指 2021 年以后机构化、量化拥挤背景下的变化。

### 3.1 短期反转（1 个月）★★★

- **现象**：过去 1 个月跌幅最大的组，未来 1 个月显著跑赢涨幅最大的组。A 股最稳健的量价因子之一。
- **解释**：散户追涨杀跌造成短期过度反应；涨跌停板阻断流动性、放大错杀。
- **注意**：多头端天然聚集高波动小票，需叠加流动性/退市风险过滤；近年因量化普遍使用，月频纯反转衰减，但日频/周频变体与"跌停打开、错杀修复"类信号仍有产出。

### 3.2 动量（12-1 月）★

- **现象**：美股最强的因子之一，在 A 股月频上不显著甚至为负（动量变反转）。
- **解释**：散户正反馈 + 题材轮动极快 + 涨跌停打断趋势；Chui, Titman & Wei (2010) 认为个人主义文化/散户占比高的市场动量弱。
- **例外**：基本面动量（盈余动量、业绩预告后漂移）和 3–12 个月中期动量在特定时期（白马行情）有效，但依赖行情结构，不稳。

### 3.3 小市值 ★★★（带重大结构性风险）

A 股最著名也最危险的因子，历史分四段：

| 阶段 | 表现 | 驱动逻辑 |
|---|---|---|
| 2007–2016 | 极强（微盘股年化超额巨大） | 壳价值：IPO 管制 → 借壳需求 → 小市值本身值钱 |
| 2017–2018 | 大幅回撤 | IPO 常态化 + 并购新规 + 外资流入 + 白马行情，壳价值坍塌 |
| 2019–2023 | 再度极强 | 微盘/中证2000/北交所行情 + 量化资金抱团小票 |
| 2024-01–02 | 崩溃（微盘股指数数周回撤 40% 级别） | 雪球产品敲入 → 中证500/1000 贴水扩大 → DMA 杠杆去化 → 微盘流动性危机，量化超额集体回撤 |

- **学术处理**：Liu, Stambaugh & Yuan (2019) 构造中国三因子（CH-3）时**剔除市值最小的 30%**，因为这部分收益被壳价值污染，不是真实的 size 溢价；剔除后 size 仍有效但大幅缩水。
- **长期判断**：全面注册制 + 退市常态化后，壳逻辑永久性弱化。小市值今后应作为**风格暴露/容量受限的增强项**管理，而非无脑躺赢的 alpha；必须监控拥挤度和流动性尾部。

### 3.4 价值（EP > BP）★★

- LSY (2019)：**EP（盈利市值比）显著，BP 较弱**——A 股的"价值"更认盈利而不是账面净资产（会计质量与亏损股 BP 失真）。
- 长期有效但周期性极强：2019–2021 成长牛市失效，2022–2024 价值风格回归。
- 实操：EP/CFP 类比 BP 更稳；叠加质量过滤（剔除亏损、ST）。

### 3.5 低换手率 / 异常换手率 ★★★

- 换手率与未来收益显著负相关，A 股非常显著。
- 解释：散户+彩票偏好把成交集中推向高换手小票；高换手 = 高关注度 = 高估。
- 与 3.7 的 MAX、低波动因子高度相关，本质是同一批行为偏好。

### 3.6 低波动 / 低特质波动 ★★★

- 低波动股票未来收益更高，A 股比美股更显著。
- 解释同上：散户资金追逐"上蹿下跳"的票，把高波动票买贵。

### 3.7 彩票偏好（MAX）★★★

- 过去一个月最大单日涨幅越高，未来收益越低；A 股显著强于美股。
- 涨停板制度放大了该效应（打板、妖股文化）。

### 3.8 A 股特色异象

| 异象 | 状态 |
|---|---|
| 壳价值 | 注册制+退市常态化后永久性弱化 |
| 高送转（填权行情） | 监管问询压制后大幅衰减 |
| 涨停板/打板 | 散户注意力驱动，仍有微观结构 alpha，但容量小、竞争激烈 |
| ST/退市博弈 | 剩纯粹彩票属性，退市新规下风险收益恶化 |
| PEAD（盈余公告后漂移） | 存在但弱于美股——散户对基本面反应慢，反而留出扩散期；景气度跟踪类策略可用 |
| 股东户数变化（筹码集中度） | 户数下降=筹码集中=机构吸筹，散户行为代理，有一定预测力 |
| 两融余额/融资买入占比 | 情绪与杠杆代理，情绪高点反转概率高 |

### 3.9 基本面质量类 ★★

- ROE、盈利质量、低应计在 A 股长期有效，但近年在机构中过度拥挤，衰减明显。
- 特点：有效性依赖风格周期，与量价因子互补性较好。

## 4. 时代演变：alpha 从哪来、往哪去

| 阶段 | 市场特征 | 好用的 alpha |
|---|---|---|
| ~2005–2016 | 散户绝对主导，量化极少 | 小市值 + 反转 + 任何量价，"散户对手方红利"丰厚 |
| 2017–2020 | 外资流入（MSCI 2018 纳入）、核心资产行情 | 基本面/质量/龙头逻辑，小市值失效期 |
| 2021–2025 | 量化私募扩到 1.5 万亿+ 量级，量价同质化 | 量价 alpha 快速衰减，拥挤度成为核心变量；2024-02 与 2024 下半年两次集体超额回撤；监管跟进（程序化交易管理规定、高频认定、融券收紧） |
| 2024– | ETF 大扩容（含国家队宽基买入）、指数化 | 成分股流动性结构改变；指增/红利/低波等"机构审美"因子获得资金面加持 |

**核心趋势：对手方从"散户"慢慢换成"量化同行"，散户红利递减，但散户仍是边际定价者——行为类因子（反转、低换手、低波动、MAX）的长期逻辑没有被推翻，只是开采难度上升。**

## 5. 对量化策略的实操启示

### 5.1 结构性约束（先于因子）

1. **做空基本不可行**：融券券源少、2024 年融券进一步收紧，多空因子组合难以落地 → 主要做多头超额/指增。
2. **成本不可忽视**：印花税（卖出 0.05%，2023-08 调降后）+ 佣金 + 冲击成本；反转/小市值多头端流动性差，回测必须含 realistic 成本。
3. **政策是最大尾部**：印花税调整、IPO 节奏、国家队入场、量化新规——A 股的"制度性断点"比波动率模型里的任何跳变都大。

### 5.2 回测检查清单（A 股特有）

- [ ] 涨跌停（主板 ±10%，创业板/科创板 ±20%，ST ±5%）：涨停买入/跌停卖出的成交应剔除
- [ ] 一字板、停牌复牌连续涨跌停的处理
- [ ] ST/*ST 与退市股保留（否则存活偏差高估 size/反转因子）
- [ ] 新股上市初期（前 5 日/前 20 日）剔除
- [ ] T+1 约束：当日买入不可卖
- [ ] 壳价值敏感性：按 LSY 做法剔除最小 30%，看结论是否稳
- [ ] 印花税/佣金/滑点计入后是否仍为正
- [ ] 分年度看因子表现，尤其 2017、2021、2024-02 三个断点

### 5.3 可挖掘的散户行为数据（alpha 代理变量）

- 龙虎榜（营业部席位：散户大本营 vs 机构席位）
- 两融余额与融资买入占比（杠杆情绪）
- 股东户数/户均持股变化（筹码集中）
- 筹码分布/获利盘比例（成本分布）
- 大宗交易折溢价
- 股吧/雪球讨论热度、东方财富关注度
- 涨停板连板高度、开板次数（打板生态监测）

### 5.4 组合构建建议

- 底仓逻辑：反转 + 低换手 + 低波动 + EP，去相关后组合，本质都是"卖散户偏好给散户"。
- 小市值作为可调风格暴露，配拥挤度指标（因子多头端换手/估值分位、同业超额相关性）动态控制。
- 拥挤度监控做成一级风控：2024-02 那类回撤不是因子失效，是所有人同时踩踏离场。

## 7. 一句话总结

**A 股散户人数多、交易占比高、单户资金小、行为高度同质（追涨杀跌+彩票偏好），这支撑了反转、低换手、低波动、小市值等"行为类因子"的长期有效性；但机构化与量化拥挤正在把这块红利逐步磨薄，2017 与 2024 两次小市值危机说明：在 A 股做因子，拥挤度和政策尾部与因子本身同等重要。**
