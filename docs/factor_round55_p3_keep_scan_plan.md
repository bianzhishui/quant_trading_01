# Round 55 预注册：P3 低波截断比例（70%）**平台性敏感性验证**

状态：**⏸ 预注册（用户已批准做敏感性验证）**｜对象：P3 生产参数 `p3.low_vol_keep = 0.70`（R54 已上线）

## §1 问题（为什么要做）

- R54 把 A1「池内 vol60 升序保留前 **70%**」推上生产。**这个 70% 是 R51 预注册时直接拍定的固定值**
  （R51 plan §2 标题即"规则定死，不试参"），**全仓从未做过截断比例扫描**。
- 已知的间接证据只有两条：① R51 的 X0 中性截断对照（同规模无因子截断）只带来 +0.2pp 年化/
  +0.7pp 回撤，而 A1 是 +1.6pp/+3.4pp → A1 的改善**不是**"持仓变少"的混淆；
  ② R52 的 Z5（把 Z1 结果再取 50%）回撤更好（−19.3%）但年化回落到 +18.5%、持仓仅 26 只。
- **缺的是平台性**：70% 是不是幸运值？落在悬崖边还是平台上？截断越狠（0.4/0.5）会怎样？
  0.8/0.9（更温和）会不会更好？——**本轮回答这个**，据此决定维持 / 建议改档 / 判定不可靠。

## §2 方法（规则定死，一次跑完）

**脚本**：`scripts/factor_round55_p3_keep_scan.py`
**引擎口径**：完全照搬 R51 归档实现（同数据、同池、同成本、同阶跃权重语义），仅把
`rank_keep` 的 KEEP 从硬编码 0.70 改为**参数**：
- `load_data` / `build_sets(sub_price=(3.0,4.0), n_years=3)` / `ret_matrix(...,"zero")` 复用
  `scripts.factor_round41_low_price`；`metrics` 复用 `quant_trading_01.dividend_factor`；
- 本地实现（逐行照搬 R51，**含 `sorted(S)` 防哈希抖动**）：
  `rank_keep(S, vals, keep)`（NaN 记最差，`ceil(keep×n)`）、`equal_W`（NaN 帧 + 信号日重置 +
  `ffill().fillna(0)`）、`w_nav`（`turn=|ΔW|`、`gross=W.shift(1)×ret`、`(1+gross−turn×cost).cumprod()`）、
  `val_seg`、`yearly_ret`、`calmar`；
- 因子：`vol60 = close.pct_change().rolling(60).std()`（T 及时点，前复权）。

**档位（7 档，一次性全部跑完并全部报告）**：`keep ∈ {0.40, 0.50, 0.60, 0.70, 0.80, 0.90, 1.00}`
（1.00 = 不截断 = P0 基准）

**自校验锚点（必须逐位复现，否则本轮作废）**：
1. `keep=1.00` ≡ R50 的 P0：验证段 2021-2026 = **+18.2% / 0.91 / −25.0%**；
2. `keep=0.70` ≡ R51 的 A1：验证段 2021-2026 = **+19.8% / 1.03 / −21.6%、45bp +17.1%**；
   且与 R51 的 A1 **净值序列一致**（不仅指标）。

**分段（判定用）**：
- **训练段（扫描）**：`2014-01-01 → 2021-12-31`
- **验证段（只确认）**：`2022-01-01 → 2026-12-31`
- 报告用（不参与判定）：R51 对齐窗 `2021-01-01→2026-12-31`、三段 2014-17/2018-21/2022-26、全样本

**成本**：15bp 主判 + 45bp/60bp 报告（与 R41-R54 一致）。

**每档必报**：年化/夏普/最大回撤/Calmar（训练段+验证段+R51 窗+全样本）、45bp/60bp、
分段与分年度、月均持仓与近 24 月持仓、**持仓 <30 只的月份数与占比**（分散度）。

## §3 判定标准（预注册，固定）

### A. 训练段（2014-2021）平台性
| # | 判据 |
|---|---|
| A1 | 训练段**最优档与次优档**年化差 < **1.0pp**（不存在孤立尖峰） |
| A2 | `keep=0.70` 训练段年化 ≥ 训练段最优档 − **1.0pp**（70% 落在平台内） |
| A3 | `keep∈[0.50,0.90]` 各档训练段**最大回撤极差 ≤ 3.0pp**（回撤亦成平台） |

### B. 验证段（2022-2026）确认
| # | 判据 |
|---|---|
| B1 | `keep=0.70` 验证段年化 ≥ `keep=1.00`(P0) − **0.5pp**，且回撤不深于 P0 |
| B2 | `keep=0.70` 验证段年化 ≥ 验证段最优档 − **1.5pp**（不落悬崖） |

### 结论形态（三选一，全部如实报告）
- ✅ **A1+A2+A3+B1+B2 全过** → 「70% 位于平台内，**维持现状**」
- 🟡 **A2 或 B2 不过**（70% 偏离平台）→ 「**建议改档**」（给出平台内推荐档），
  **本轮不改任何配置**，改档须另行预注册 + 用户批准
- ❌ **A1 不过**（无平台/孤立尖峰）→ 「该参数不可靠」→ 建议回到 `1.00`（不截断）
  并记录局限，**须用户批准**

## §4 防数据挖掘纪律（本轮硬约束）

1. 7 档**一次跑完、全部报告**，不挑最优、不补跑、不重复跑（脚本内固定循环，无 argparse 试参）；
2. 验证段**只用于 B1/B2 确认**，不用于选点；
3. 训练段选出的"平台内最稳档"仅为参考，**不得直接改生产参数**；
4. 若结论指向改档 → 重新预注册 + 用户批准后另轮实施；
5. **诚实边界**：70% 的原始选择参考过 2021-2026 段（含 2022-2026），故 B1/B2 **不是严格样本外**；
   本轮定位是**平台性/稳健性检验**，不宣称样本外验证。

## §5 诚实风险（预注册时已知）

1. **档间差异可能都小于噪声** → 结论可能是"无法区分"（这本身有价值：说明 70% 不必纠结）；
2. **0.40-0.60 档持仓会明显低于 30 只**（分散度恶化，R52 Z5 已示警 26 只）→ 须报告占比；
3. **训练段含 2015 泡沫与 2018 熊市**，回撤平台判据可能被极端年主导 → 附加分段数字供判断；
4. 7 档扫描本身增加数据挖掘暴露面 → 用 A/B 分段 + 全档报告 + 改档需批准三重约束；
5. 只测低波（vol60）一个因子的截断比例；其他因子（低 PB/IVOL）的比例敏感性不在本轮。
