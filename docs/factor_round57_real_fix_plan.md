## §1 问题（已定位到代码行，有实测证据）

`scripts/factor_round41_low_price.py` 的 `load_data()` 构造 P3「真实价」时：

```python
fac_ser = s.reindex(close.index).ffill().fillna(1.0)  # ← bug（第 84 行）
```

`close.index` 自 `cfg.r5.start = 2013-06-01` 起。**先 reindex 再 ffill** 会把「索引起点之前的
因子记录」直接丢弃，随后 ffill 无从向前取数 → **因子回落为 1.0** → `real = close`（**前复权价**，
不是真实价），直到该股**索引内第一条**因子记录出现才切换。

**精确的改动面（定义）**：设 `fr(code)` = 该股 **≥ 索引起点** 的首条因子记录日。则
- 对 `t ≥ fr(code)`：前/后口径**完全相同**；
- 对 `t < fr(code)`：修前 factor=1.0（错），修后 factor=该股此前最近的因子记录（正确）或
  最早记录（bfill）。

**实测后果**（`tmp/r57_probe.py`，2014-06-17 单日）：`sh.601377` `real` 由 3.03 变 **8.39**，
当日收益从 **+169.48% → −2.74%**；`sh.601199` 3.23 → **15.95**，+386.26% → −1.63%；
`sz.002107` 切换日 3.64 → **15.72**，+334.72% → +0.57%。修复前后一致（2015-06 后逐位相同）。
**±169%~±386% 的单日真实价变动不可能是行情**（主板 ±10% 限制）。

**已验证的修复方向**：`s.reindex(close.index.union(s.index)).ffill().reindex(close.index)`
`.bfill().fillna(1.0)` —— 先并集 ffill（保留索引起点前的记录）再 reindex 回交易日 ✅ 抽查三只
标的在 2014 年的日收益已全部落回 ±11% 内。

**统计规模**：改动 stock-days **807,102 / 11,048,569（7.31%）**，其中 2016-01-01 之后 **393,463**
（多为 2016 年后上市股票的第一年，因子接近 1，误差小）。因子表 3123 只中 **1563 只**首条记录晚于
2014-01-01。

## §2 改动（规则定死，最小化）

**唯一改动**：`scripts/factor_round41_low_price.py` 第 84 行 → 并集 ffill + bfill：

```python
u = close.index.union(s.index)
fac_ser = s.reindex(u).ffill().reindex(close.index).bfill().fillna(1.0)
```

- `bfill()` 处理「该股在整张因子表里都没有更早记录」的日期（无信息可取，用最早可得因子，
  并按 §3-W2/W3 报告受影响的 stock-days 与残留不确定性）；
- **不改** `fallback`（新浪不复权价）/`raw_close_delisted` 分支、不改 `build_sets`、不改
  `PaperPortfolio`、**不改任何策略参数与配置**；
- 本修复**只改数据构造口径** → 会改变 P3 的入池结果（2013-06~2015 为主），因此需要预注册+批准。

## §5 诚实风险（预注册时已知）

1. **bfill 是假设**：对「整表无更早因子记录」的日期（多为 2016 年后上市股票的第一年）用最早可得
   因子，若该股在此期间有分红/送转，仍会有小误差（比原来的错好得多）→ W1c/W3 量化残留；
2. **送转除权日 `real` 本来就会大跳**（10送10 → −50%），所以**不能**用「|Δ|>11%」直接判异常，
   必须排除因子变动日（W3 已如此定义）；
3. **重算会改动 P3 的历史年代数字**（2014-17 段）→ 手册与 README 中的相关引用须一并更正；
4. 本轮**不**重新抓取因子数据（若因子表本身缺 2013-2015 记录，修复只能恢复"可得的最优"）
   → 该项作为残留风险报告；
5. 运行时：1 次数据加载 + 等权重算（秒级）+ 份额级 16 次回放（≈20 分钟）→ 后台单次跑完，不重复。

### §0.4 我自己的判据设计错误（如实记录，不修改判据）

1. **W2 作废（判据错）**：我把"真实价变动"当成了"收益"。`fr` 当日**就是除权日**，
   10送10 让真实价当日腰斩（−50%）**完全正常**；真实收益 = 前复权 `close` 比值，
   与本次修复无关。故 `|Δreal|≤11%` 没有判别力 → 该判据作废（对照值：修后 85.78% vs 修前 26.26%）。
2. **W5 前提假设错**：我在 plan 里写"2021-2026 无 `real` 改动、应逐位一致"——**错**。
   改动不止 2013-2015：**2016 年后仍有 112,046 个 stock-days 被改**（2016 年后上市股票
   在"首条因子记录"之前的整段，因子≈1 但非 1）。故主窗口出现 **≤0.24pp** 的微动（年化与
   回撤符号、量级全部不变）→ 如实记为 ❌，并据此更正 §0.2 表述。
