## 0. 问题

R46 两个独立通过的改进方向（价位上移 P3 / ROE 门槛 Q2）尚未组合；价位上移的
**边界**（4-5 元还算不算低价？低价溢价止于何处？）未测。本 Round 组合 + 边界探索。

## 2. 判定（预注册，验证段 2021-2026，锚 = V1）

| # | 标准 | 通过条件 |
|---|---|---|
| ① | 年化 > V1 | 收益更大化延续 |
| ② | 回撤 ≤ V1 + 3pp | 不显著恶化 |
| ③ | 夏普 ≥ V1 | 风险调整不劣 |
| ④ | 45bp 超额 vs 全市场 ≥ +3pp | 可交易 |
| ⑤ | 分段（3段）全正 | 稳定 |

**判定**：①-⑤ 全过 = 通过；取**年化最高的通过者**为新候选；与 R46 最优 P3/Q2 比较——
若高于 P3（18.6%）则为新最优，否则 P3 保持。0 个通过 = 组合/边界无增益，P3 定稿。
**报告**：各变体 vs P3/Q2 的差值；B1/B2 回答"4-5 元是否仍低价溢价"。
