# Round 53 预注册：A1 低波60 在 P3 八账户的**份额级落地验证**（1 手约束 × 真实成本）

状态：**⏸ 预注册（用户已批准该方向）**｜对象：P3 低价股策略｜上位结论：R51（A1 唯一通过预注册判据）

## §1 问题

R51/R52 的结论基于**等权净值回测**（无资金约束）。但 P3 是 **1 手 = 100 股**的真实模拟盘
（八账户 3万~600万），小账户天然退化（现冻结参数下 3万账户只能买少数标的）。

A1 把目标持仓从 **61 → 43 只**（近年 51→36）。这会**放大** 1 手约束的伤害：
标的越少，每只应分配的资金越多，但低价股（3-4 元）1 手仅 300-400 元，小账户反而可能
"每只都买得起 1 手但买不满"，或"部分标的连 1 手都不够"。

**本轮问**：A1 在**真实份额级 + 1 手约束 + 真实成本 + 涨跌停阻塞**下，八个账户各自
还能不能保住 R51 看到的改善？小账户是否应当维持 P0？

## §2 方法（规则定死）

**引擎**：复用生产同款 `PaperPortfolio`（`scripts/r5/paper_trade.py`）与
`scripts/p3/scenario_ytd_p3.py` 的份额级回放（含 1 手取整、佣金/印花/过户/滑点 15bp、
除权事件补缺、涨跌停阻塞）。**不重新实现回放逻辑**（避免除权/阻塞细节二次实现出错）。

**生产脚本最小扩展（向后兼容）**：给 `run_scenario_p3` 增加可选参数
`target_fn: Callable[[pd.Timestamp, set], set] | None = None`：
- `None`（默认）= 现行行为，逐位不变；
- 给定则 `target = target_fn(rb["T"], rb["target"])`。
仅新增一个分支，不改任何默认路径。

**变体**：
| 编号 | 目标集合 |
|---|---|
| S0（基准） | `target_fn=None`（现冻结 P3，不截断） |
| S1（A1） | 池内 `vol60 = close.pct_change().rolling(60).std()`（信号日 T 数值），**NaN 记最差**，升序取前 **70%**（同 R51 A1 口径：`ceil(0.70×n)`） |

**账户**：八账户全部（3万/10万/20万/30万/60万/100万/300万/600万，`p3.aum_list`）。

**窗口**：
- 主窗口 = **验证段 2021-01-04 → 2026-09-28**（与 R51/R52 验证段一致，便于对照）；
- 稳健性窗口 = **全样本 2014-02-10 → 2026-09-28**（仅 S0/S1，八账户）。

**每账户指标（必须全部报告）**：
1. 期末 NAV、年化、最大回撤（份额级真实口径）
2. **实际平均持仓只数**（月末快照均值）与**目标只数**之差的缺口
3. 平均现金占比（1 手约束导致的拖累）
4. 累计费用占初始资金比
5. **"买不起 1 手"事件数**：调仓时目标标的按理论等权分配额 < 1 手价（100×价 + 费用）的次数
6. 相对基准 S0 的 年化差 / 回撤差（**同账户对比**，消除账户规模差异）

## §3 判定标准（预注册）

对每个账户规模分别判定（不做跨账户平均）：

**"A1 在该规模可用"需同时满足**：
1. 年化 ≥ S0 年化 − 0.5pp（不牺牲超过 0.5pp 收益）
2. 最大回撤 ≤ S0 最大回撤（不更深）
3. 实际平均持仓 ≥ **30 只**（沿用 R52 的分散度下限），且 ≥ 目标只数的 70%

**输出结论形态（无论通过与否）**：
- 给出 **"A1 可用门槛规模"**：从哪个账户规模起 A1 满足上述三条；
- 明确小账户（3万/10万/20万/30万）的处置建议（维持 P0 / 换用更低截断比例）；
- 若**任何**规模段出现"A1 回撤反而更深"或"年化差 > 1pp"，须如实标注为风险。

## §5 诚实风险（预注册时已知）

1. **份额级与等权口径的差异是系统性的**：P0 本身也有 1 手退化，因此**只能同账户相对比较**，
   不能把份额级年化与 R51 的等权年化直接对比；
2. **A1 的"43 只"是目标而非实际**：小账户实际可能只持 10-25 只，集中度更高 → 回撤模型外风险；
3. **窗口含 2021-2026 单一风格段**：若 A1 的优势本就集中在近年，份额级结论也只在近年成立；
4. **不重建账本**：本轮是历史回放验证，不动 `output/p3/ledger_p3_*.json`（生产记录保持连续）；
5. **未计换手/流动性冲击**：低价股 1 手小单，冲击可忽略，但未建模；
6. 若结果显示"仅 300万+ 可用"，则 A1 的适用范围显著小于 R51 的表面结论 —— 这是本轮最可能的
   有价值发现之一。
