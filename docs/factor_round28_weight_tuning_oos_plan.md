## 0. 实施结果归档（2026-09-10）

**判定：①顶点 ✅ ②样本外 ✅ ③全区间不劣化 ✅ ④高原 ✅ —— 四项全过，推荐 w\*=0.95。**
这是权重系列探索迄今最强的证据（样本外 +6.6pp），但仍需**用户最终批准**才改生产。

### 0.1 扩展扫描结果（300万 阻塞引擎，完整数据 09-09 补全）

| Amihud 权重 | 全区间超额 | 训练段(14-21) | 验证段(22-26) | 回撤 |
|---|---|---|---|---|

### 0.2 判定自查（方案 §2）

| # | 判据 | 结果 |
|---|---|---|
| ① 顶点可见 | 0.95 最高、1.00 回落（+7.17 < +7.32） | ✅ |
| ② 样本外 | w_train\*=0.95（训练段最高）→ 验证段 +10.10% vs 0.5 +3.53% | ✅ **差 +6.58pp** |
| ③ 全区间不劣化 | 0.95 全区间 +7.32% ≥ 0.5 +4.04% | ✅ |
| ④ 高原稳健 | 0.90~1.00 邻域波动 0.15pp < 0.5pp | ✅ |

**推荐 w\*=0.95**（Amihud 95% + 动量 5%），四项证据齐备。

### 0.3 关键解读（诚实）

1. **样本外是真验证**：训练段（2014-21）独立选权 0.95，验证段（2022-26）跑出 +10.1%、
   比 0.5 高 **6.6pp**——不是全区间挑最高，是"用前 8 年选、后 5 年验证"的真样本外，
   过拟合风险大幅降低；
2. **顶点在 0.95 而非 1.00**：1.00（纯 Amihud）略回落——动量保留 5% 还有边际价值
   （或 0.95 是统计最优），不是"越高越好"到极限；
3. **0.95 接近纯 Amihud**：动量从 50% → 5%，语义接近"Amihud 单因子化"（Round 2 的
   +7.3pp 全通过策略）——这是策略方向的重大变化，需用户明确接受；
4. **诚实局限**：验证段仅一段（2022-26，含 2024 微盘危机等），单段说服力有限但方向一致；
   未来 Amihud 若衰减，0.95 组合几乎无动量缓冲（动量的负相关分散在 5% 权重下名存实亡）。

### 0.4 决策点（需用户最终批准）

- **改生产 w=0.95**：改 `paper_trade.r5_rebalances` 打分（当前硬编码 `(pa+pm)/2`）→
  参数化 w=0.95；**同时需决策账本是否重建**（现有账本基于 0.5 建仓）；
- **维持 0.5**：拒绝证据（保守），接受"历史最优但非最优"；
- **折中**（可选）：采用中间值如 0.80~0.85（保留更多动量缓冲），牺牲部分样本外超额
  换取分散——需用户权衡"超额 vs 抗单一因子失效"。

## 1. 规则（定死）

### 1.1 扩展扫描（看顶点）

- `w ∈ {0.80, 0.85, 0.90, 0.95, 1.00}`（+ 0.5/0.7 对照），Amihud 权重；
- 每权重输出：全区间超额 + **训练段(2014-2021)超额 + 验证段(2022-2026)超额** + 回撤 + 换手；
- **顶点判断**：超额曲线是否出现"下降/平台"（若 1.00 仍最高 → 未到顶，趋势为纯 Amihud 单因子）。

### 1.2 样本外验证（防过拟合核心）

1. **训练段选权**：在 2014~2021 扫描全部 w，取训练段超额最高者 `w_train*`；
2. **验证段检验**：在 2022~2026（样本外）比较 `w_train*` vs `0.5` 的超额；
3. **判定**（方案 §2）。

## 2. 判定（定死）

| # | 判据 | 通过条件 |
|---|---|---|
| ① 顶点可见 | 扩展扫描超额曲线出现顶点/平台（非全程单调至 1.00） | 曲线回落或平 |
| ② 样本外成立 | `w_train*` 在验证段(2022-26)超额 − 0.5 验证段超额 | **≥ +1pp** |
| ③ 全区间不劣化 | `w_train*` 全区间超额 ≥ 0.5 全区间（且三段不劣化） | ≥ 0 且三段 ≥ |
| ④ 高原稳健 | `w_train*` 邻域(±0.05, 双侧) 超额波动 | **< 0.5pp**（同 Round 27） |

- **①②③④ 全过** → 推荐 `w_train*`（改生产需用户批准，账本重建另行决策）；
- ① 不通过（1.00 仍最高）→ **趋势到纯 Amihud 边界**，如实报告（w=1.0 = 去掉动量，
  回 Round 2 Amihud 单因子，重大语义变化，需用户明确决策）；
- ② 不通过（训练最优在样本外失灵）→ **过拟合证据**，维持 0.5（诚实）。

## 3. 诚实风险

1. **样本外只有一段（2022-26）**：统计说服力有限，但优于"全区间扫描挑最高"；
2. **训练段选权本身过拟合**：w_train* 是训练段内挑的最高——用样本外段检验其真伪
   （若样本外也成立，则是真趋势；否则是拟合）；
3. **w→1.0 语义重大**：= 完全去掉动量，回到 Amihud 单因子（Round 2 +7.3pp 全通过
   的策略）；动量的负相关分散（IC −0.43）在高权重下丧失，Amihud 未来衰减时无缓冲；
4. **不改变已运营账本**；改生产需用户批准 + 账本重建决策。
