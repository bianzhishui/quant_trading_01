    ——与该仓库既有结论一致（AGENTS.md §7：<20万 不可行）。

## §2 改动（三处代码/配置 + 文档 + 账本重建）

### 2.1 `config/default.yaml` `p3` 段（冻结参数变更）

- 3万 退役理由写入 YAML 注释（R53 数据）。

### 2.2 `scripts/factor_round41_low_price.py::build_sets`（KEEP 基座，向后兼容）

新增**可选**参数 `low_vol_keep: float | None = None`、`low_vol_window: int = 60`：
- `None`（默认）→ **行为逐位不变**（R41-R53 全部归档脚本默认调用不受影响）；
- 启用时，对每个信号日 T 的 B 集合（**质量筛选后的池**）：
  1. 预计算一次 `vol_panel = close.pct_change().rolling(low_vol_window).std()`；
  2. `v = vol_panel.loc[T].reindex(sorted(B_set)).replace([±inf], nan).fillna(np.inf)`
     （**NaN 记最差**；`sorted` 固定输入顺序以防 hash 序抖动 —— R51 §0.1 教训）；
  3. 升序取前 `ceil(low_vol_keep × len(v))` 个 → 新 B 集合（口径同 R51 A1）。

### 2.3 生产调用点接线（口径一致）

  `low_vol_window=_cfg().p3.low_vol_window`（**生产真值**）；

  使场景回放与生产一致；
- 两个脚本的 docstring 注明 **`target_fn`（R53 研究钩子）与 `low_vol_keep`（生产规则）
  不可同时使用**，避免双重截断。

## §4 诚实风险（预注册时已知）

1. **A1 的份额级增益不大**（600万 仅 +0.63pp 年化），落地后短期跟踪可能看不出差别；
   主要收益在回撤改善（+3.13pp）；
2. **10万/20万 仍受费用与 1 手约束拖累**（R53：10万 现金 6.0%、年化比 600万 低 3.9pp），
   与 §7 "<20万 不可行" 的既有结论一致——本轮不解决该问题；
3. **重建账本会重置 2026-09-01 以来七账户的模拟盘记录**（约 20 个交易日）；
   `mark` 只能按**新持仓**回补净值曲线，属"重建"而非"延续"；
4. **一次冻结参数变更 + 账本重建不可回退演练**：如需回退，须把 `low_vol_keep` 设为 null
   并重建账本（老账本可从 git 取回）；
5. A1 只影响 P3；**R5（生产 R5 等权575）完全不动**。
