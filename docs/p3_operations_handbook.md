# 策略运营手册 · P3 低价股（真实价 3.0-4.0 元 + 质量筛选 + 低波截断 等权月频）

日期：2026-09-29 ｜ 定稿：Round 41-47 预注册全链 ｜ **R54（2026-09-29）落地 A1 低波截断 + 3万退役** ｜ 账本：`output/p3/`

---

## 1. 策略总览

**P3** = 真实价 3.0-4.0 元 + 近 3 年扣非为正 + 负债率<70% + 流动性 + 分红
**+ 低波截断（池内 vol60 升序保留前 70%）** + 等权月频。

- 定位：**低价股深度价值**——"被市场抛弃但未到毁灭"的 2-3 元带上方（3-4 元），
  质量筛选剔除亏损/高负债/铁公鸡，赚"错杀修复 + 小盘低价溢价"，月频换血剔除变坏标的。
- 与 R5 的关系：同为小盘路线但暴露不同（P3 低价质量 vs R5 低流动性），相关 0.75（日），
  可组合降回撤（50/50 全样本 -52.6%→-42.0%）。
- 研究链：R41 发现（2-3 元甜蜜区）→ R42 验证（2-3 元+质量 通过）→ R43 样本外（通过，
  选择偏差减轻）→ R44 改进（区间上移 V1）→ R45 持有期（**月频换血是超额主来源**，
  买入持有远逊）→ R46/R47 收益更大化（**P3 = 3.0-4.0 元 收敛**）→ R50-R52 优化探索
  （除 A1 外全部未达标）→ **R53 份额级落地验证 → R54 落地 A1 低波截断**。

## 2. 策略定义（信号逻辑）

### 2.1 可交易池（逐日过滤，全部满足才入池）
- 主板（sh.60*/sz.00*，涨跌幅 10%）；非北交所/创业板/科创
- 上市 ≥ 375 天（`p3.seasoning`，按 ipoDate 计）
- 正常交易（tradestatus==1）；非 ST
- **真实价 ∈ [3.0, 4.0)**（`p3.price_lo/hi`）：在市 = 前复权价 ÷ 复权因子（71 只 fallback
  用新浪不复权价）；退市股 = 腾讯不复权价（raw_close_delisted）

### 2.2 质量筛选（全部用已披露报告期，防前视：年报滞后 120 天）
1. **近 3 年扣非净利润均为正**（`p3.n_years`，financial_quality 12-31 报告期）
2. 最新报告期资产负债率 < 70%（`p3.debt_max`）
3. 近 20 日均成交额 ≥ 500 万（`p3.liq_min`，剔除枯竭）
4. 近 3 年有分红记录（dividends）
5. 非 ST

### 2.2b 低波截断（**R54 新增，A1 口径**）
6. 质量筛选后的池内，按 **60 交易日收益波动率（vol60）升序保留前 70%**
   （`p3.low_vol_keep` / `p3.low_vol_window`；NaN 记最差；信号日 T 计算，无前视）
   - 依据：R51（等权口径：年化 +18.2%→+19.8%、回撤 −25.0%→−21.6%、Calmar 0.73→0.92，
     为 R50-R52 唯一通过全部预注册判据的变体）+ R53（份额级八账户验证，见 §3.1b）
   - 关闭方式：`low_vol_keep: null` → 回到 R47 原口径

### 2.3 组合与调仓
- 等权、**月频调仓**：信号 = 月末 T，执行 = T+1 收盘
- 持仓约 30-45 只（R54 前 50-60 只；A1 后月均约 43、近月 36）
- 退市股处理：持仓中退市按最后价清算（运营现实），回测口径为归零 + 敏感性

### 2.4 参数表（冻结在 `config/default.yaml` 的 `p3` 段，改动需预注册+用户批准）

| 参数 | 值 | 说明 |
|---|---|---|
| price_lo / price_hi | 3.0 / 4.0 | 真实价区间（R47 定稿） |
| n_years | 3 | 扣非为正年限 |
| debt_max | 0.70 | 负债率上限 |
| liq_min | 500 万 | 20 日均成交额下限 |
| seasoning | 375 | 上市天数下限 |
| disclose_lag | 120 | 年报披露滞后（防前视） |
| low_price | 5.0 | 低价研究总上限（R41-47 主口径） |
| **low_vol_keep** | **0.70** | **R54 A1 低波截断保留比例（null = 关闭）** |
| **low_vol_window** | **60** | **R54 vol 窗口（交易日）** |

### 3.1b A1 低波截断（R51 等权 + R53 份额级，2026-09-29）

### 3.2 诚实局限（必须了解）
1. **近年超额衰减**：2022-26 段年化约 11-15%（低于全样本 20.5%），2025 牛市跑输、
   2026 曾转负（归因：池子劣化——2-3 元"扣非为正"通过率 49%→36%、持仓收缩；风格依赖）
2. **-25%（验证段）~-46%（全样本）回撤**：仍是高回撤小盘策略，需高承受力
3. **边界已验证**：3-4 元是低价溢价峰值带（0.5 元滑动窗口单调升、**4 元是断崖**）；
   0-2 元是重灾区（85% 退市股 ≤2 元），质量筛选也救不了——**不要手动抄 2 元以下**
4. 涨跌停未建模（涨停买不进略高估）；财务同花顺快照有重述风险（已防时间滞后）
   - **R50 量化（2026-09-29）**：同引擎"含阻塞 vs 无阻塞"对照——**验证段 2021-2026 仅 −0.2pp/年
     （稳健）**；但**全样本 2014-2026 无阻塞口径高估 +1.8pp/年**，集中在 2014-17 高波动段
     （+7.4pp/年），2018 年后 ≤0.3pp。→ 引用全样本历史数字时须扣减该偏差
5. 买入持有远逊于月频换血（R45：3 年持有仅 2.2% vs 月频 16%）——**定期换血是纪律**

## 5. 风险画像与心理预期
- 必须接受：-25%（近期）~-46%（全区间）回撤；风格切换期（大盘/牛市）跑输
- 优势期：震荡/下跌年（2022/2024 大幅跑赢）；劣势期：大牛市（2025 -11pp）、小盘崩盘（2024-01）
- 对应策略：**满仓扛住 + 月频换血不择时**（同 R5 风控总收束）
- 监控：池子质量通过率（p3 段 low_price 主口径下扣非通过率）——**通过率持续下降=策略环境恶化信号**
- A1 低波截断（R54）**只降波动、不改方向**：份额级真实增益为回撤改善 +2.45~+3.13pp，
  年化增益 +0.63~+1.86pp（规模越大越小）——预期管理上不要按等权回测的 +1.6pp 设目标

## 6. 运营操作手册

### 6.1 环境与命令
```bash
.venv/bin/python scripts/p3/daily_update_p3.py              # 每日一键(补行情→mark→总表)
.venv/bin/python scripts/p3/daily_update_p3.py --chart       # 一键 + 出图
.venv/bin/python scripts/p3/daily_update_p3.py --table       # 只读总表
.venv/bin/python scripts/p3/paper_live_p3.py step            # 每月调仓(7账户)
.venv/bin/python scripts/p3/paper_live_p3.py report          # 账本报告
.venv/bin/python scripts/p3/plot_daily_gains_p3.py           # 每日图
```
产物：`output/p3/`（账本 ledger_p3_aum*.json 入库跟踪；每日/月度 CSV 与图不入库）

### 6.2 每日例行（收盘后一键）
`daily_update_p3.py`：自动判断交易日 → 补当日行情（fetch_daily_incremental，全市场约
20-30 分钟）→ 数据守卫 → 七账户 mark → 总表；`--chart` 出图。

### 6.3 每月例行（新数据到手后，5 分钟）
`paper_live_p3.py step`（自动推进错过月份调仓，含复权因子实时增量补除权缺口）→ `report`。
**对账不变量**：① 期末净值=现金+持仓；② 期末≈期初−费用(<1%)；③ 月涨幅连乘=累计。

### 6.4 数据维护节奏（重要，防止用旧数据选股）
| 数据 | 脚本 | 时机 |
|---|---|---|
| 日线行情 | daily_update_p3 自动（fetch_daily_incremental） | **每日** |
| 质量财务 | `scripts/fetch_financial_quality.py` | **季报/年报披露后**（否则月调仓用旧扣非） |
| 分红 | `scripts/fetch_dividends_backfill.py`（在市）+ `fetch_delisted_dividends.py`（退市） | **分红季后** |
| 复权因子实时 | step 内自动（_live_factors，baostock） | 每月 step 时 |
| 复权因子静态 | `scripts/fetch_corporate_actions.py` | 季度 |
| 宇宙清单 | `scripts/fetch_stock_basic.py` | 季度/半年 |

## 7. 与 R5 的关系
- **相关（日收益，F 实测 2026-09）**：
  - 全样本（2014-2026，3238 日）：**0.745**（确认 R46 数值）
  - **验证段（2021-2026）：0.909** —— 近年显著趋同
  - 模拟盘真实运行（600万，17 交易日初探）：**0.878**（与验证段一致）
  - 年度：2015 仅 0.35（风格分化年），2016-2026 在 0.84-0.98
- **含义（重要修正）**：组合 50/50 降回撤（全样本 -52.6%→-42.0%，降 10.6pp）**主要来自早期分化年**；
  **近年两策略高度同向（0.91）**，组合的分散边际价值显著下降——互补更多是"长期/极端风格年"
  的价值，日常近乎同涨同跌；组合≈增规模同波动，非减半回撤
- 若两者都运营，可作为双策略；但以近年相关性评估，组合不降低波动预期
