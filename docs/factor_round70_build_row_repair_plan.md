# Round 70 `monthly_funds` 建仓行重建（旧世代遗留快照）· 预注册

> 状态：**已预注册 2026-10-09 / 实施中**
> 触发：R69 前的调仓验证发现 `monthly_funds_*.csv` 首行与账本不一致（差 66.68~180.72 元）。
> 代码：`scripts/r5/paper_live.py`（`init_ledger` / `_seed_build_row`）

---

## 1. 问题（取证已闭环）

**step 前的账本完全自洽**（git `1a6e2a9`，600万）：

```
trades=566 | Σ费用=11,269.51 | total_fees=11,269.51  → 差 0.00
cash=399,300.23 | aum−Σbuy−Σ费用=399,300.75         → 差 0.52（1手取整残留）
aum−nav0=11,270.04 ≈ Σ费用+0.53
```

而**建仓行三者皆不符**：`post_nav=5,988,796.64`（≠ 账本 nav0 5,988,729.96）、
`cash=443,523.31`（≠ 399,300.23）、`fee=11,202.94`（≠ 11,269.51）。

→ **建仓行是更早的账本世代（R38 于 09-18 重建账本之前）写下的遗留快照**。

**根因**：`_seed_build_row` 第一句就是 `if p.exists(): return` ——
文件一旦存在就永不刷新，账本重建后首行保持旧世代值。

**影响**：入库跟踪的 `monthly_funds_*.csv` 首行与账本不一致（0.0011%~0.018%）；
不影响任何净值/收益计算（`step` 用的是账本 `nav_history`），但会污染
「累计费用 == 各期费用之和」这类跨表对账（`markets` 实测差 66.57~180.73 元）。

---

## 2. 规则（定死）

1. **`init_ledger` 存建仓快照**（新建账本即自带权威值）：

```python
"build": {"date": ..., "nav": nav, "cash": pf.cash, "buy": ..., "sell": ..., "fee": total_fees},
```

2. **`_seed_build_row` 改为"以快照为权威"**：
   - 账本无 `build` 字段（老账本）→ **保持旧行为**（不猜测、不擅自改写）；
   - 有快照 → 首行缺失则写；**与快照不一致则重建**（而非 return）；
3. **一次性迁移**：4 个 R5 账本（P3 视取证结果一并处理）从 git 的 **step 前版本**
   （`nav_history` 长度为 1 的那个版本）取建仓状态 → 写入 `led["build"]` → 重建首行；
4. 不改任何其它字段与计算。

---

## 3. 预注册判定标准

| 判据 | 标准 | 含义 |
|---|---|---|
| **P1 建仓行与账本一致** | `post_nav == nav_history[0].nav`（±0.01）；`现金+持仓 == post_nav`（±1）；`\|post−(aum−fee)\| ≤ 1 元`（1手残留） | 主目标 |
| **P2 费用对账归零** | `Σ(trades 费用) − Σ(monthly_funds 费用)` **== 0**（±0.01，原为 66~181 元） | 跨表一致性 |
| **P3 判别力自证** | 造一个"旧世代"首行 → `_seed_build_row` **必然把它重建**为快照值；**旧版（存在即 return）必然不动** → 断言旧行为违规 | R57/R58 教训 |
| **P4 正文零改动** | step 行（第 2 行起）逐位不变；`nav_history`/`cash`/`shares`/`trades`/`bench_base` 逐位不变 | 防迁移误伤 |
| **P5 质量门** | `ruff check .` 0 错误 + `pytest` 全过（默认 + `-m slow`） | 仓库硬性要求 |

---

## 4. 诚实风险

1. **老账本（无 `build`）保持旧行为**：本轮只修"有快照"的路径 + 一次性迁移这 4 个；
   若将来又出现旧世代账本，仍无法自动重建（如实记录，不静默猜测）；
2. **迁移依赖 git 中 step 前账本**：若某账户在 git 里找不到 `nav_history` 长度为 1 的版本，
   **跳过该账户并如实报告**（不伪造）；
3. **P3 的建仓行需单独取证**：P3 与 R5 共用同构逻辑但各自 `init_ledger`，
   本轮一并检查，若同样不一致则同样迁移。
