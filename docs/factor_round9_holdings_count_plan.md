### 0.3 判定（J1~J4）

- J1 前10%/前5% 超额@15bp ≥ 基线：**失败**（4.22/3.43 < 4.65——减少数量不增 alpha，反降）
- J2 前5% 回撤 ≤ 基线+5pp：通过（−61.0 vs −56.3 = 4.7pp，压线）
- J3 前5% 换手 ≤ 基线+2：通过（5.2 ≤ 5.7）
- J4 前5% 超额@s40 ≥ 基线−1pp：**失败**（+0.16 vs +2.61，差 2.45pp）
- **Round 9 判定：未通过(2/4) → 维持前 20%（575）为 alpha 最优**

### 0.4 归因读数（与直觉相反，数据很硬）

1. **减少持仓数不改善 alpha，反而恶化**：超额@15bp 4.65→4.22→3.43→0.90 单调下降。
   "更极端冷门+更高动量"不等于更好——极端 Amihud 尾部是低流动微盘股，流动性溢价被
   高特质波动/负偏抵消；80-95 分位的"中等冷门"才是 alpha 主体。
2. **真实成本下恶化更快**：减少持仓 = 冷门暴露 46%→71%，流动性依赖成本集中咬在
   冷门上 → 前2% 超额@s40 **−2.97%（负超额，亏穿）**。J4 的失败是决定性的。
3. **集中度代价**：回撤 −56.3→−65.3%、换手 3.7→6.0（小集合对排名变动更敏感）。
4. **减少持仓的唯一收益 = 手数可行性**：100 万资金下前 20% 不可行（1 手就超仓位），
   前 5% 才可行（~96 万）。但那是"勉强能跑但 alpha 已弱"的选项。
5. **自检**：前 20% 超额@15bp +4.65% ≈ Round 8 全市场 R5（+4.61%），
   截断(quantile) vs 分位(qcut) 差异 <0.1pp，口径一致。

### 0.5 结论归档（推荐逻辑）

- **alpha 层面：575（前20%）是优点，不是缺点。** 不要为"少买"而少买——
  数据明确惩罚更少的持仓。
- **实操层面：持仓数由资金量决定（1 手约束）**：
  | 资金 | 可行方案 | alpha 代价 |
  |---|---|---|
  | ≥300 万 | 满仓 575（前20%） | 最优 |
  | 100-300 万 | 前10%（~230 只, 最低~150万） | 真实成本 −1.1pp |
  | <100 万 | 前5%（~115 只, 最低~96万） | 真实成本 −2.4pp，alpha 已弱 |
- **明确警示**：<100 万资金下本策略难以健康运行——要么攒资金，要么接受前 5% 的弱化
  版本（超额@s40 仅 +0.16pp），这是资金规模的红线，不是参数问题
- 不改动 Round 7/8 定稿口径（前20%）；本回只回答"能否少买"= 能减，但代价明确且单向下行

## 1. 设计（定死）

- 同一全市场 R5 合成分（行业中性化百分位等权），只改**选股截断**：
  **前 20% / 10% / 5% / 2%**（等权、月度、保守执行口径、比例成本同 Round 8）
- 指标：超额@15bp、超额@s=40bp（流动性依赖成本）、夏普、回撤、年换手、平均持仓数、
  冷门暴露（Amihud百分位>0.8 占比）
- **手数可行性**：A 股 1 手=100 股；持仓可行条件 = AUM/N ≥ 100×股价。
  用 qfq 收盘价近似股价（红利调整会略偏，作量级参考）。对每个 N 算：
  使 p95 价格位持仓 ≥1 手的最低 AUM。
- 基线自检：前 20% 臂应复现 Round 8 全市场 R5（超额≈+4.6pp@15bp, +2.6pp@s=40bp）

## 2. 预期

- 前 5%/2% = 极端冷门+高动量，单票 alpha 更强但**更冷、执行成本更高、回撤更深**
- 超额@15bp 可能随 N 减少而**上升**，但超额@s=40bp 可能**下降**（冷门集中付更多成本）
- 换手可能随 N 减少上升（小集合对排名变动更敏感）
- 手数可行性随 N 减少大幅改善（100 万 AUM 下前 5% 约 140 只可行，前 20% 不可行）

## 3. 预注册判定（推荐逻辑）

| 门 | 标准 | 含义 |
|---|---|---|
| J1 | 前 10%、前 5% 超额@15bp ≥ 基线（前 20%） | 减少数量不损名义 alpha |
| J2 | 前 5% 回撤 ≤ 基线回撤 + 5pp | 集中度代价可接受 |
| J3 | 前 5% 年换手 ≤ 基线 + 2 | 换手不爆 |
| J4 | 前 5% 超额@s=40bp ≥ 基线 − 1.0pp | 真实成本下不减损过多 |

判定：J1~J4 全过 → **推荐前 5%（≈140 只）或前 2%**，按手数可行性给出最低 AUM；
若 J2/J4 不过 → 维持前 20%，如实说明"数量减少的代价是集中+成本"。
（本回是**实操建议**，不改 Round 7/8 已定稿的策略口径，只回答"能不能少买"）
