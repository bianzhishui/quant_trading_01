## 0. 实施结果归档（2026-09-09）

**判定：3/5 → 维持 R5，价格水平不并入。** 组合验证给出重要负面结论：
**单因子四层全过 + 低相关 ≠ 可并入组合**（等权三因子版本超额从 +4.2pp 崩塌到 −0.25pp）。

### 0.3 为什么单因子通过、组合崩塌（核心教训）

1. **分散 ≠ 增强**：Jaccard 44.8% 证明 B 与 A 真实不同（55% 新持仓），但新增部分贡献
   负超额——分散真实存在，却是"向差分散"；
2. **破坏两因子互补**：价格水平与中期动量 **IC 相关 +0.56（同向）**，三因子等权稀释了
   Amihud×动量 的负相关互补（Round 3：IC 相关 −0.43 是策略核心机制）——等权并入是
   **破坏性方式**（权重优化/行业内两阶段未测，超出本轮范围）；
3. **价值**：本轮保护了生产 R5 不被"看起来有效"的因子污染；筛选（Round 21）与组合
   （Round 22）两步验证的必要性再次实证。

### 0.4 结论

- **价格水平降级为"单因子参考"**（不并入 R5），候选池维持：Amihud✅ + 中期动量🟡；
- R5 冻结参数与生产账户不变（再次验证 R5 稳健）；
- 遗留：若未来想用价格水平，需权重/两阶段设计另开预注册（当前无计划）。

## 1. 背景

Round 21 发现：**价格水平（低价股效应）四层全过（4/4）**，单因子超额 +3.0pp@15bp、
换手仅 1.1、与 R5 的 Amihud 截面相关 **−0.19**、IC 序列相关 **−0.41**（互补）。
但**单因子层面低相关 ≠ 组合层面真实分散**——价格水平与 R5 小盘冷门风格可能纠缠。
本轮验证：把价格水平**并入 R5 打分**，看组合是否真实受益。

## 2. 组合设计（定死，3 个臂）

| 臂 | 打分（均为行业内百分位，前 20% 等权，全市场池） |
|---|---|
| **A 基线** | 现有 R5：`sc = (rank(Amihud) + rank(动量)) / 2` |
| **B 三因子** | `sc = (rank(Amihud) + rank(动量) + rank(价格水平)) / 3` |
| C 参考 | 价格水平单因子（Round 21 已测，+3.0pp，不再重跑，仅引用） |

- 池/因子/行业剔除/成本：与 `r5_rebalances` 完全一致（375日/非ST/主板/未涨停，MIN_IND=5，
  MIN_N=50，15bp/35bp 双成本）；
- 回放：300万 share 级全口径（与 R5 归档口径可比），141 期；
- 数据：现有 full_daily + adjust_factor（零新数据）。

## 3. 判定（定死：B vs A，5 项）

| # | 判据 | 阈值 |
|---|---|---|
| ① 超额 | B 的 15bp 超额 − A 的 15bp 超额 | **≥ +1pp** |
| ② 回撤 | B 最大回撤 − A 最大回撤 | **≤ +5pp**（不显著恶化） |
| ③ 换手 | B 年换手 / A 年换手 | **≤ 1.5** |
| ④ 分段 | B 三段（2014-17/18-21/22-26）超额 | **全部为正**（且不弱于 A） |
| ⑤ 分散 | B 与 A 的**月均持仓 Jaccard 重叠** | **< 0.75**（≥0.75 = 组合层无真实分散，只是 A 微调） |

- **≥4/5 通过** → B 为组合升级候选（还需单独预注册"是否替换 R5"决策）；
- 否则 → 维持 R5，价格水平降级为"单因子参考"（不并入）。

## 4. 诚实风险（预先声明）

1. **三因子等权稀释**：Round 3 证明 Amihud 与动量 IC 相关 −0.43 互补；价格水平与动量
   IC 相关 +0.56（同向）——加第三因子可能摊薄两因子互补、或只增强动量侧；
2. **风格重叠可能**：低价与小盘冷门高度相关（R5 本就小盘冷门）——⑤ 持仓重叠是核心检验，
   若 ≥0.75 说明"并入无意义"；
3. 等权打分是**最简单并入方式**（行业/权重优化留待后续）；不改变 R5 冻结参数；
4. 通过 ≠ 立即替换生产：需用户决策 + 另开"执行口径变更"流程（生产账户不动）。
