## 0. 研究问题与动机

**问题**：Round 41 子区间显示"2-3 元 + 质量筛选"年化 ~20%、回撤仅 -40%（显著优于
0-2 元重灾区与 3-5 元），且显著跑赢全市场。本 Round **预注册验证该区间策略是否
独立成立**（稳定超额、低回撤、可交易），并拆解"超额来自区间本身还是质量筛选"。

**动机数据**（Round 41 §0）：2-3 元月均样本 90 只；三口径（归零/最后价/剔除合并）
B 组年化 19.8~20.0%、回撤 -40.6% 完全一致——值得专项验证。

## 1. 预注册规则（定死，不可事后修改）

### 1.1 池与价格
- 池：主板（含退市），上市 ≥375 天（ipo 口径），tradestatus==1
- **价格 = 真实价**（口径同 Round 41：在市=前复权/复权因子 或 raw_close_fallback；
  退市=raw_close_delisted）
- **区间定义：2.00 ≤ 真实价 < 3.00**（左闭右开，含端点 2 元不含 3 元）

### 1.2 三组对照
| 组 | 构造 |
|---|---|
| **A23 无差别 2-3元** | 池中真实价∈[2,3) 且非ST，等权 |
| **B23 质量筛选 2-3元** | A23 + 质量条件（同 Round 41 B 组，见 1.3） |
| **C 全市场等权** | 池中在市等权 |

基准：沪深300。另对比 Round 41 的"全部 ≤5 元 B 组"（区间增益归因）。

### 1.3 质量筛选（B23，同 Round 41，全部已披露报告期防前视）
1. 非ST
2. 近 3 年报扣非均为正（披露滞后 120 天）
3. 最新报告期资产负债率 <70%
4. 近 20 日均成交额 ≥500 万
5. 近 3 年有分红记录（退市股以扣非为正近似）

### 1.4 组合与成本
- 等权、月频调仓（月末信号 → T+1 收盘）、15bp/45bp
- 退市处理：归零（主）；敏感性：最后价清算
- 窗口 2014-01 ~ 2026-09；分年代 2014-17/2018-21/2022-26

### 1.5 判定标准（预注册）
| # | 标准 | 通过条件 |
|---|---|---|
| ① | B23 vs C 年化超额 | **≥ +3pp**（区间策略整体有效） |
| ② | B23 最大回撤 vs C | **≤ C 的回撤**（低回撤特征成立） |
| ③ | 分年代稳定性 | 3 段中 ≥2 段 B23 年化 >0 且跑赢 C |
| ④ | 可交易性 | 45bp 下 B23 vs C 超额 ≥ +1pp |
| ⑤ | 归因拆解 | **B23 - A23 超额 < +2pp**（超额主要来自区间而非质量筛选） |
| ⑥ | 退市暴露 | B23 退市暴露 ≤ Round41 的 ≤5 元 B 组（避开面值区的价值） |

判定：①-④ 全过 = 通过；任一不过 = 未达标（如实归档）。⑤⑥ 为归因/解释指标，不参与判定。
**禁止调参重跑**。

## 2. 诚实风险与局限
1. **边界敏感**：2.00/3.00 端点人为，敏感性命中区间 [1.8,2.2)/[2.8,3.2) 对照（仅报告，不调参）
2. **样本规模**：月均 90 只，分组后单组 ~45 只，统计功效中等
3. **退市≠归零**：敏感性处理（同 Round 41）
4. **财务时点**：已披露报告期（防前视）
5. **幸存者偏差**：含退市股修正，但退市股财务为同花顺口径个别可能缺期
6. **结论边界**：即使通过，2-3 元策略是"高波动小盘低价"路线，回撤 -40% 仍需高回撤承受力

## §0 实施结果归档（2026-09-22 完成）

### 主结果（2014-01 ~ 2026-09，退市归零，15bp）

| 组 | 年化 | 夏普 | 最大回撤 |
|---|---|---|---|
| A23 无差别 2-3元 | +13.9% | 0.61 | -59.3% |
| **B23 质量筛选 2-3元** | **+19.8%** | **0.86** | **-40.6%** |
| C 全市场等权 | +9.6% | 0.49 | -61.3% |
| B23(45bp) | +17.5% | — | — |

分年代：B23 2014-17 +50.9% / 2018-21 +9.1% / 2022-26 +8.1%（3/3 跑赢 C）

### 判定（预注册 ①-④ 全过 = 通过）

| # | 标准 | 结果 | 达标 |
|---|---|---|---|
| ① | B23 vs C 超额 ≥3pp | **+10.2pp** | ✅ |
| ② | B23 回撤 ≤ C | -40.6% vs -61.3% | ✅ |
| ③ | 分年代 ≥2/3 跑赢 | **3/3** | ✅ |
| ④ | 45bp 超额 ≥1pp | **+7.9pp** | ✅ |
| ⑤ | 归因（不参与判定） | B23-A23 **+5.9pp**（>2pp：质量筛选贡献显著，非仅区间） | — |
| ⑥ | 退市暴露（不参与判定） | B23 8.5%（月均持仓 36 只） | — |

**判定：通过（①-④ 全过）** —— 预注册标准全部达标。

### 敏感性
- 最后价清算：B23 **20.0% / -40.6%**（与主口径一致）
- 边界对照：**1.8-2.2 元 10.3%/-54.7%**（明显变差，近面值区）｜ **2.8-3.2 元 19.4%/-37.3%**（同样优异）
  → 策略对"贴 2 元面值"敏感，**2.3-3.2 元区间稳健**；1.8-2.2 边界接近 0-2 元重灾区特征

### 诚实结论
1. **"2-3 元 + 质量筛选"通过预注册判定**：年化 19.8%、夏普 0.86、回撤 -40.6%（vs 全市场 -61.3%）、
   45bp 高成本仍 +7.9pp、3/3 分年代——**独立成立且可交易**。
2. **归因修正 Round 41 猜测**：该区间质量筛选增量 **+5.9pp**（非"区间主导"）——与 ≤5 元全区间
   （增量仅 1.5pp）形成对照：质量筛选的价值在 2-3 元区间被放大（排除的是临近退市的差股）。
   结论：**区间 + 质量筛选共同贡献，缺一不可**（A23 无差别仅 13.9%/夏普 0.61）。
3. **边界警告**：贴 2 元（1.8-2.2）明显变差（10.3%/-54.7%）——面值踩踏区仍是雷区，
   策略应取 **2.3-3.2 元**为主带。
4. 局限：月均持仓 36 只（中等分散）；-40% 回撤仍需高承受力（虽比全市场 -61% 好）；
   退市暴露 8.5% 仍高于 ≤5 元全区间 B 组（5.5%）——本区间退市密度本身更高，由质量筛选控制。
