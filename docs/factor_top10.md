## 逐个说明

### 1. 中期动量（6-12 月）—— 观察名单里唯一通过 ③ 的
- **计算**：`close(T−21) / close(T−250) − 1`（前复权收盘）
- **方向**：高动量 → 买（右尾有效）
- **数据**：现有 daily.parquet 即算
- **证据**：已测 部分通过(3/4)——超额 +3.6pp、换手仅 2.6 倍/年、三段全正、35bp 成本档仍 +2.4pp
- **关键坑**：全截面 IC 弱（0.013）但五分组严格单调 → **信号集中在右尾**，
  应只做高动量头部组，不要做全截面多空

### 2. 短期反转（1 个月）
- **计算**：`close(T) / close(T−21) − 1`，值低（超跌）→ 买
- **数据**：现有
- **证据**：已测 未通过——五分组完美单调（Spearman −1.00）、Q5 追高组年化仅 +3.2%，
  但月频完全轮换 8.4 倍换手 × 15bp 把超额吃到 +0.8pp
- **关键坑**：换手是它的生死线 → 必须配缓冲带（hysteresis）或与低换手因子组合，
  单独月频全轮换不可交易

### 3. 低换手率（21 日均换手）★ 行为源内与反转互补性最好
- **计算**：`mean(日换手率, 21d)`，低 → 买
- **数据**：需补日线 volume + 流通股本（baostock `query_history_k_data_plus`
  加 volume 字段；股本可一次取）
- **机制**：注意力驱动买入（Barber-Odean）——高换手 = 被关注 = 被买贵
- **关键坑**：与反转/低波动相关 0.4-0.6，组合时同源组只留代表；
  流通股本变化（解禁/增发）要处理

### 4. Amihud 非流动性
- **计算**：`mean(|日收益| / 日成交额, 21d) × 1e6`，高 → 买（流动性溢价）
- **数据**：需补 volume + amount
- **关键坑**：与低换手、小市值天然高相关——三者只留一个进组合；
  停牌日收益 0 会压低指标，需按交易口径处理

### 5. EP 盈利市值比（估值源的首选，BP 已测失败）
- **计算**：`TTM 归母净利润 / 总市值`（或 1/PE），高 → 买
- **数据**：需补盈利数据（akshare 东方财富财务指标一次调用）
- **证据**：本池 BP 已测未通过(0/4)；LSY(2019) 明确 A 股 EP 显著、BP 弱
  → 估值源应换 EP 而非 BP
- **关键坑**：公告时滞（只用已披露季度，防未来函数）、负盈利剔除、
  市值口径（总 vs 流通）与基准一致

### 6. 股息率（3 年滚动）/ 股息连续性
- **计算**：近 3 个完整日历年每股分红合计 ÷ 真实价（dividend_factor 已有实现）
- **数据**：现有 dividends.parquet
- **证据**：高股息筛选组合已测未通过（相对"不筛选傻拿"为负贡献），
  但作为**低相关防御成分**在组合框架内价值待重估
- **关键坑**：股息率与 BP 高相关；红利风格轮动强（2021-2024 顺风段已过）

### 7. 两融余额变化（杠杆情绪）
- **计算**：个股 `融资余额(T) / 融资余额(T−21) − 1`
- **方向**：高 → 警惕（杠杆资金追涨，情绪极值反转）；也可做市场级择时
- **数据**：需补融资融券个股接口（akshare 沪深两所逐日）
- **关键坑**：两融标的名单受限、2019 后两融余额口径变化；尾部极端值噪音大

### 8. 北向资金净买入（聪明钱，衰减中）
- **计算**：个股 20 日 `沪深港通持股数量变化 × 股价`
- **数据**：需补沪深港通持股接口（akshare 每日）
- **关键坑**：2021 年后外资流出/失效风险高 → 只能低权重；
  数据口径（持股数量/市值、深股通与沪股通分列）易出错

### 9. ROE 盈利质量
- **计算**：`ROE(TTM)` 或 稳定性（过去 5 年 ROE 标准差倒数，高且稳 → 买）
- **数据**：需补财务接口
- **关键坑**：与 EP 相关高（质量≈估值近亲），组合去重；2019-2021 拥挤后衰减明显

### 10. 小市值（高危，历史超额最大）
- **计算**：`ln(流通市值)` 取反，小 → 买
- **数据**：需补股本（baostock 基本信息 / akshare 市值）
- **证据**：A 股历史最强因子之一（壳价值+散户投机），但 2017 与 2024-02 两次崩溃
- **关键坑**：**必须做"剔除市值最小 30%"敏感性（LSY 口径）**；容量小、冲击成本高、
  幸存者偏差最大；注册制+退市常态化后逻辑永久弱化 → 只作风格暴露，不作 alpha

## 检验顺序建议

- **Step A（现有数据即可）**：中期动量（已过） + 反转（已测） → 直接开 **Round 3a
  两因子等权打分组合**，验证"组合能否把反转的毛超额从换手里捞回来"
- **Step B（补基础量价）**：低换手 + Amihud + 小市值，一批预注册
  （同源去重：三个里预期只留一个进组合）
- **Step C（补基本面）**：EP + ROE，一批预注册（估值/质量源补位）
- **Step D（补资金流）**：两融 + 北向，一批预注册（情绪/聪明钱源补位）

> 与全量候选池的关系：BP、低波动、距52周高点已在本池检验未通过，不在 Top 10；
> 若将来扩池（中证1000/全市场），部分淘汰因子应**重新入池复测**，而不是直接翻案。
