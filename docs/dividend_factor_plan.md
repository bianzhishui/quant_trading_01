# 高股息因子四组对照实验 — 研究方案（预注册版）

> 状态：**待实施** ｜ v1.0 ｜ 2026-09-02
> 目的：复现并归因聚宽帖《年化30%大市值高股息轮动策略》——重点不是复刻
> 322%，而是回答两个归因问题：**名称过滤贡献了多少？权重漂移贡献了多少？**
> 数据管线已就绪（data/fundamental/*.parquet，质检报告见会话记录 2026-09-02）。

---

## 1. 研究假设

| 编号 | 假设 | 检验方式 |
|---|---|---|
| H1 | 股息率因子在本样本(2014-2026)存在正向超额 | B 组 vs 沪深300 |
| H2 | "爱我中华"名称过滤的收益贡献 ≈ 央企/红利风格暴露，而非独立 alpha | A − B 的差值大小与稳定性 |
| H3 | 原帖"只给新标的分钱、旧仓不动"的漂移机制贡献了相当部分收益，代价是集中度 | D − B 的差值 + 最大单票权重统计 |

## 2. 数据与已知局限（诚实清单）

- **股票池**：当前沪深300+中证500 并集 800 只。**幸存者偏差**：用今天的成分
  回测历史，收益系统性偏高 → 本实验**只做 A/B/C/D 组间相对比较，不宣称绝对收益**
- **价格**：baostock 前复权日线。因子分母需要真实价格 → **补抓复权因子
  `query_adjust_factor`（每股1次调用）反推：真实价 = 前复权价 ÷ 当日因子**
  （若因子数据缺失的股票-日期对，剔除该股当期，记录剔除量）
- **无质量门槛**：帖子的"现金流>0、扣非>0、净利正增长"v1 未纳入（季度接口
  未抓），相当于筛选比原版更宽松 → 属于对所有组一致的影响
- **开盘涨跌停不可交易**：v1 不处理（月频+等权下影响有限，记录在案）

## 3. 策略规则（定死）

### 3.1 股票池与筛选（每月末 T 日计算）

可交易过滤（依序）：
1. 截至 T 日已有 ≥ 375 条日线记录（≈上市满375交易日）
2. T 日 `tradestatus == 1` 且 `isST == 0`
3. 非创业板/科创板/北交所（代码非 300/688/8 开头）
4. T 日 `PB < 1`

因子：`divyield3y = 近3个完整日历年每股分红合计 ÷ T日真实价`
（分红按**实施年**聚合；调仓时只用已完结年度，如 2024-06 调仓用
2021+2022+2023 实施年合计——无未来函数；某年无记录视为 0）

入选：可交易池内 divyield3y 排名 **前 50%**。

### 3.2 四组变体

| 组 | 选股 | 资金分配 | 回答的问题 |
|---|---|---|---|
| **A** | 筛选 ∩ 名称含{爱,我,中,华}任一字 | 月度完全等权 | 名称过滤选出的组合本身表现 |
| **B** | 仅筛选（A 去掉名称过滤） | 月度完全等权 | 基线：红利因子本身 |
| **C** | 同 B | 月度完全等权，成本 15/25/35/45bp 四档 | 执行摩擦敏感度 |
| **D** | 同 B | **漂移式**：卖出离开池的持仓；现金只等权分给新入选；旧仓不动、无单票上限 | 复现原帖机制 → 漂移贡献 |

**漂移算法精确定义（D 组）**：每月末 T 生成新目标集合 S；
- 持仓中 ∉ S 的：下一交易日**开盘全部卖出**；
- S 中未持有的：用现有现金**等权**买入（每只 = 现金/新标的数）；
- 已持有的：股数不变。
成本：每次交易按当日单边成本计。

### 3.3 调仓与成本

- 月度调仓：每月最后一个交易日收盘算因子，次月第一个交易日开盘执行
- 基础全成本 **15bp/单边**（佣金2.5 + 印花税5(卖出摊) + 滑点≈7.5）
- C 组压测档：+10/20/30bp 额外滑点（即 25/35/45bp 全成本）
- 基准：沪深300 指数 + "等权全池"（800 只可交易股日收益均值）

### 3.4 回测区间与分段

- **2014-01-02 ~ 2026-08-31**（首月建仓；2011-2013 分红用于首个三年窗口）
- 分年代：2014-2017 / 2018-2021 / 2022-2026（第三段含保留段性质）

## 4. 预注册判定标准（跑之前写死）

| 层 | 标准 | 对象 |
|---|---|---|
| ② 显著性 | 月收益−沪深300月收益：Welch t 与置换检验 p<0.05 | B 组 |
| ③ 稳定性 | 三段每段 夏普>0.3 且年化>沪深300 | B 组 |
| ④ 可交易 | 45bp 全成本档年超额(对沪深300) ≥ 3% | C 组 |

**归因读数（本次实验的核心产出，判定阈值预写死）**：
- **名称过滤贡献 = A 年化 − B 年化**
  - |差值| < 1pp/年 → 名称过滤是噪音，"中字头魔力"在等权框架下不成立
  - A − B > 3pp/年 且 A 回撤更小 → "央企代理"解释成立，但它只能代表
    2021-2024 红利风格的顺风（结合分年代表判断）
- **漂移贡献 = D 年化 − B 年化**
  - D − B > 3pp/年 → 原帖 322% 的主要来源是漂移式集中，不是轮动选股
  - 同时报告 D 组最大单票权重、前三大合计权重、以及 D 组最大回撤 vs B

**失败协议**：任一层失败 → 如实归档；禁止回头改筛选参数重跑。
若 B 组自身(②③)失败，四组对照仍然跑完（归因读数照出），但结论为
"红利因子在本样本不可交易"，两者不矛盾。

## 6. 预期管理

B 组的现实预期：年化超额 0~5 个点（红利因子样本内顺风大，但当前成分
回测有幸存者加成，数字会偏乐观——所以组间读数比绝对数字可信）。
如果 A 组年化跑出 25%+，解读方式只有一种：名称过滤≈央企红利暴露
撞上了 2021-2024 样本段，与原帖病因相同——此时 H2 验证为"成立"，
恰恰是给那个帖子定性，而不是给我们找到了圣杯。
