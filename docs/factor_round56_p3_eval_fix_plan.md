## §1 问题：一个**已知且已量化**的口径缺陷

**R48 已确立的正确口径**（生产已落地）：持仓估值必须用**前向填充价**，成交必须用**原始价**。

- 根因：`PaperPortfolio.value(prices)` 对**价格为 NaN 的持仓按市值 0 计**——停牌 → 净值凭空跌一截；
  退市 → 永久归零。
- 生产路径（`scripts/p3/paper_live_p3.py`：`init_ledger` / `step` / `mark` / `report`，8 处）
  **已全部接入** `eval_prices(raw) = raw.ffill()`：`pf.value(raw_e...)` 估值、`pf.rebalance(..., raw...)` 成交、
  `report` 用 `eval_prices` ✓。合规。
- **缺陷**：研究回放路径 `scripts/p3/scenario_ytd_p3.py` **从未接入**——`run_scenario_p3` 全程
  用 `prices = raw.iloc[i]` 同时做**估值**（`pre_nav`/`post_nav`/每日 `pf.value`）与**成交**。

**后果（R53 §0.1 已量化）**：全样本窗口（2014-02-10→2026-09-28）份额级结果**不可能**：
份额级回撤 −93%~−95%、**累计费用 117-165% 本金**，而同窗等权 P0 回撤仅 −45.54%。
机制自洽：NaN 估值 → 持仓市值归零 → 触发卖出/再平衡 → 换手与费用爆炸 → 净值死亡螺旋。
**该窗口已作废，且此后任何长样本份额级结论都不可信** → 本轮修复它。

## §2 改动（规则定死，最小化）

**唯一改动对象**：`scripts/p3/scenario_ytd_p3.py` 的 `run_scenario_p3`。

在函数内新增一次 `raw_e = raw.ffill()`，并把**估值**三处切到 `raw_e`：

| 位置 | 现在 | 改为 |
|---|---|---|
| 调仓前 `pre_nav` | `pf.value(prices)`（raw） | `pf.value(raw_e.iloc[i])` |
| 调仓后 `post_nav` | `pf.value(prices)`（raw） | `pf.value(raw_e.iloc[i])` |
| 每日净值 `navs.append(...)` | `pf.value(prices)`（raw） | `pf.value(raw_e.iloc[i])` |

**保持不变（成交口径）**：
- `prices = raw.iloc[i]` 仍用于 `pf.rebalance(target, prices, trad_row, ret_row)`（成交价、1 手取整）、
  `pf.corp_action_f(...)`（除权补缺）、`n_1lot_short` 的"1 手买不起"判断（必须用真实成交价）。

**禁止改动的部分**：`PaperPortfolio`（引擎）、`build_sets`、`config/*.yaml`、`block` 默认值、
`slip` 默认 15bp、CSV 列名列序、`target_fn`/`detail`/`low_vol_keep` 既有语义。
**生产账本不需要重建**（生产早已用 `eval_prices`）——这点由 §3-V4 验证。

## §4 诚实风险（预注册时已知）

1. **ffill 会永久保留退市股最后价**（= 运营手册 §2.3 的"退市按最后价清算"），而**等权口径对退市是
   归零**+敏感性 → 两口径在全样本**不可直接对比**，报告须分别标注；
2. **修复可能小幅改变主窗口数字** → R53/R54 报告中的绝对数字需注明"估值口径修正后为 X"；
3. V3a/V3b 的带宽是我定的（−35%~−55%、≤15%），若落在边界须如实讨论而非调整阈值；
4. 全样本 × 8 账户 × 2 变体 = 16 次份额级回放，运行时间长（预计 15-25 分钟）→ **后台单次跑完，
   不重复跑**；
5. 本轮**只修研究路径**，不改任何生产参数/账本；若 V3c 支持"改 A1 档位"等生产动作，须另行预注册。
