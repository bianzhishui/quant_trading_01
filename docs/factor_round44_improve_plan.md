## 0. 问题与改进假设

**问题**：B23 近年持仓收缩（64→24 只，分散不足）、2026 转负、牛市跑输。
诊断：①"近 3 年扣非为正"是池子劣化主因（通过率 49%→36%）；②回撤是小盘 beta
系统性回撤；③加条件会进一步压缩样本（股息率≥3% 只剩 28 只）。

**改进假设（预注册）**：
- H1 区间上移 2.3-3.2 元：样本更多、近 3 元亏损股少 → 收益↑
- H2 扣非放宽到"近 2 年为正"：持仓显著增加 → 分散↑波动↓
- H3 股息率加权（等权→按近 3 年股息率加权）：安全垫 → 回撤↓

## 1. 变体（预注册，规则定死）

| 变体 | 区间 | 质量条件 | 加权 |
|---|---|---|---|
| **V0 基准** | 2-3 元 | Round42 全套（3年扣非/负债/流动/分红） | 等权 |
| **V1** | **2.3-3.2** | 同 V0（3年扣非） | 等权 |

退市归零（敏感性：最后价清算）、窗口 2014-2026、验证段 2021-2026 主判。

## 2. 判定标准（预注册，主判验证段 2021-2026）

改进目标 = **收益↑ 且 回撤↓**（相对 V0 基准，同口径验证段）：

| # | 标准 | 通过条件 |
|---|---|---|
| ① | 验证段年化超额 | 变体 vs V0 **≥ +2pp**（收益提高） |
| ② | 验证段最大回撤 | 变体 **< V0**（回撤降低） |
| ③ | 样本/分散 | 变体月均持仓 **≥ V0** 且 ≥30 只 |
| ④ | 可交易性 | 45bp 下变体 vs 全市场 验证段超额 **≥ +1pp** |
| ⑤ | 稳定性 | 分年度 ≥ 一半跑赢 V0 |

每个变体独立判定；**最优变体若 V2/V3 满足 ①-⑤ 全过 → 定为改进候选策略**；
任一不过如实归档。**禁止在结果后调整条件重跑**。

## 3. 诚实风险
1. 改进目标"收益↑回撤↓"在回测上常伴随过拟合风险——预注册固定变体（不搜索）
2. 2.3-3.2 与 2-3 区间高度相关，V1/V2/V3 结果可能接近 V0，改进幅度可能有限
3. 股息率加权（V3）降低权重集中度，但可能偏离等权分散初衷
4. 沿用已知局限（涨跌停未建模、财务重述残余、退市≠归零敏感性处理）

### 复核：扣非口径（透明修正）
- **实现偏差披露**：Round 41/42/43 归档实际用"最近 1 年扣非>0"（非 plan 文字"近3年"）。
- 复核：V0（严格3年）验证段 12.9% vs R42口径（1年）11.8% → **差异 +1.1pp，归档结论基本稳健**
  （量级一致，1 年口径偏乐观方向但很小）。

### 诚实结论
1. **区间上移 2.3-3.2 元是最有效改进**（V1：验证段 12.9%→16.0%，+3.1pp；回撤 -25.4%；
   夏普 0.64→0.78；45bp 仍 +5.3pp；分年 5/6 跑赢 V0）——与诊断一致（近 3 元亏损股少）。
2. **扣非放宽到 2 年**（V2）扩样本到 37 只但年化略降（15.5% vs 16.0%）——扩样本换分散，
   收益接近，可用作稳健选择。
3. **股息率加权**（V3）回撤降幅最大（-26.9%→-23.0%，3.9pp）但收益提升不足（+1.9pp < 2pp）
   未达判定——**加权降回撤有效但牺牲收益**。
4. **最优候选 = V1（2.3-3.2 元 + 3 年扣非 + 等权 + 月频）**：验证段 16.0%/夏普 0.78/回撤 -25.4%。
5. 局限：改进幅度在 2-3pp 量级（非质变）；沿用涨跌停未建模等已知局限。
