### 相关矩阵读数

- **截面相关**：9 因子两两全部 < 0.6，无同源触发；最高 EP×ROE 0.42、动量×Amihud −0.22
- **IC 序列相关**：低换手×EP −0.82（强负动态互补，但两者均未通过，无从兑现）；
  Amihud×动量 −0.42（已通过的组合成分间负相关 = 极佳的动态互补，可预期组合化增益）；
  两融×反转 0.38、动量×ROE 0.37

### 归因读数

1. **Amihud 是项目首个全通过因子，且形态干净**：IC +0.048(t=3.70)、五分组严格单调
   （Q1 3.2% → Q5 18.2%）、超额 +7.3pp、换手仅 2.5、35bp 成本档仍 +6.1pp、三段全部为正。
   机制=流动性溢价：**成交清淡的股票长期跑赢**（A 股散户回避冷门股 → 冷门股被低估）。
   与"低换手率"看似同源但 IC 序列相关仅 −0.01——Amihud 度量的是"价格对成交额冲击"
   而非"换手水平"，是独立信号。
2. **低换手率方向性失败（与直觉相反）**：IC −0.047 显著、方向正确（低换手→高收益），
   但 Q1（最低换手）年化仅 8.6% < 基准——信号存在但**被中大票池的"低波动低迷股"污染**：
   本池的低换手股里大量是长期阴跌、无人问津的票（机构审美外的价值陷阱）。
   与"注意力驱动"文献在散户池的结论不同，中大票池里低换手≠被买贵，而是被冷落。
3. **两融变化：信号最"正统"但差临门一脚**：IC −0.033(t=−3.93) 显著、五分组完美单调
   （Q1 10.6 → Q5 4.1，追涨杠杆组垫底），但月频轮换 8.3 倍换手 × 15bp 把超额吃到 −0.4pp，
   分段 1/3。**杠杆情绪因子方向成立，成本是唯一障碍**——与反转是同一类病因。
4. **EP/ROE/北向/股息连续性全部未通过**：EP 分组乱序且 2018-2021 段 −10.2pp（成长牛杀
   估值重演）；ROE 与股息连续性 2022-2026 转负；北向 IC 接近 0（聪明钱代理彻底失效）。
   基本面/资金流源在本池均不可用——与 BP 失败的 Round 1 结论一致：
   **本池（中大票当前成分）对"价值类/机构审美类"因子普遍苛刻，对"流动性/行为类"相对友好**。
5. **组合化潜力**：唯一两个有实质信号的因子（Amihud + 中期动量）IC 序列相关 −0.42，
   动态互补理想；Amihud 换手仅 2.5 且 +7.3pp 超额，中期动量 +3.6pp，
   两者等权打分组合的预期（Round 3）值得单独预注册。

### 结论归档

- **进入组合候选池：Amihud（全通过）**
- **观察名单：反转、中期动量**（同 Round 1，未变）
- **淘汰：低换手率、EP、股息连续性、两融变化、北向、ROE**（本轮口径）
- **暂缓：小市值**（东财/雪球被阻断，无历史市值干净源；换数据环境后补测）
- Round 3 预注册建议：**Amihud + 中期动量**（IC 负相关互补）+ 可选反转（缓冲带降换手）

## 2. 数据与已知局限（诚实清单）

- 沿用既有全部口径：当前成分幸存者偏差、中大票池、涨跌停买入端近似、停牌价格延续
- **小市值 暂缓**：历史市值需东财/雪球接口，当前环境均被阻断（RemoteDisconnected/
  需鉴权），无干净免费历史市值源。**不作近似代理**（避免把"成交额"之类当市值），
  待换数据环境（tushare/聚宽）后补测，本文档不删条目、不改判定
- **ROE 公告时滞**：财务指标按报告期末对齐，用"报告期末 ≤ 调仓日 − 120 天"的最新
  一期（年报复核截止 4 月底，120 天保守无未来函数），偏保守
- **两融/北向覆盖不全**：两融仅覆盖两融标的，北向仅覆盖沪深港通标的 →
  这两因子的截面天然较小，**最小截面阈值降为 30**，其余因子仍为 50
- **两融口径**：仅用融资余额（融券占比小、2024 后收紧），月频足够
- 因子数据不足（<60% 调仓期有有效截面）→ 标"数据不足"，不作通过/未通过判定

## 3. 规则（定死，池/成本/调仓与 Round 1 完全一致）

### 3.1 股票池（每月末 T 日）
同 Round 1：≥375 日、tradestatus==1、isST==0、非创业/科创/北交、未涨停、因子值非 NaN。

### 3.2 因子定义（新抓取字段见 §5）

| 因子 | 计算 |
|---|---|
| 低换手率 | 过去 21 日平均换手率（baostock turn 字段），min_periods=15 |
| Amihud | mean(\|日收益\|/日成交额, 21d) × 1e6 |
| EP | 1 / peTTM（peTTM>0） |
| 股息连续性 | 近 5 个完整日历年（截至 T−1 年）中每股分红 > 0 的年数 |
| 两融变化 | 融资余额(T) / 融资余额(T−21) − 1（不足 21 期用最近可得，<10 期 NaN） |
| 北向净买入 | 近 21 日北向持股数量净增 × 区间均价（= 持股市值变化近似） |
| ROE | 最新可得 ROE(TTM/加权，报告期末 ≤ T−120 天) |
| 小市值 | 暂缓 |

### 3.3 组合与成本
同 Round 1：rank 等分 5 组，多头组按方向（+1→Q5，−1→Q1）等权月频轮换；
基准=同池等权；15bp/单边，多头另报 25/35bp；多空毛仅示意。

### 3.4 区间与分段
2014-01 ~ 2026-09；2014-2017 / 2018-2021 / 2022-2026。

## 4. 预注册判定标准（跑之前写死，与 Round 1 一致）

| 层 | 标准 |
|---|---|
| ① 显著性 | 月度 RankIC 方向与预注册一致，\|IC\| ≥ 0.03 且 \|t\| ≥ 2 |
| ② 单调性 | 预期多头组 5 组年化最高 且 预期空头组最低 |
| ③ 可交易 | 多头扣 15bp 年化超额（对同池等权）≥ +1pp；25/35bp 敏感性读数 |
| ④ 稳定性 | 三段中 ≥2 段多头超额 > 0 |

单因子判定 = 通过(4/4) 进组合候选池 / 部分通过(3/4) 观察名单 / 未通过(≤2) 淘汰。
同源判据：截面相关 > 0.6 → 组合阶段每组只留判定更优者。
失败协议：如实归档，禁止回头改定义/窗口/池口径重跑；数据不足按 §2 标注。
