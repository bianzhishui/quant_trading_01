| 因子 | 计算（与候选池定义一致） | 方向 |

## 3. 判定（定死，沿用 Round 1/2 四层）

- **① IC**：方向对 且 `|RankIC均值| ≥ 0.03` 且 `|t| ≥ 2`
- **② 分组单调**：五分组（扣 15bp）多头组年化最高 且 空头组最低
- **③ 超额**：多头组扣 15bp 年化 − 同池等权基准 ≥ **+1pp**
- **④ 分段**：ERAS 三段（2014-17 / 2018-21 / 2022-26）中 ≥2 段超额为正
- 4 项全过 = **通过**；3 项 = **部分通过**；否则未通过
- 有效截面期数 < 60% 期数 → 标"数据不足"不判定

**附加产出**：新 4 因子与 Amihud/中期动量/合成分的**截面相关矩阵**（月均 Spearman）
——相关 < 0.3 才具备组合补充价值。

## 4. 诚实风险（预先声明）

1. **长期反转数据窗口**：需 T−750 交易日（≈3 年），数据 2012-06 起 → 首个信号约
   2015-09，**2014-2017 段部分缺失**，c4 分段与 c1 期数会受影响（诚实标注，不硬判）；
2. 低 beta 用全池等权做基准收益，未做行业/市值中性——β 与规模可能纠缠（R5 已含小盘暴露）；
3. 价格水平的"低价股差"与 R5 小盘冷门风格可能高度重叠——相关矩阵会揭示；
4. 判定标准与 Round 1/2 完全一致，**横向可比**；通过 ≠ 立即入策略（需组合预注册）。
