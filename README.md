## 快速开始

本项目使用 **uv** 管理 Python 环境与依赖（锁文件 `uv.lock` 保证可复现）。

```bash
# 安装 uv（一次性；macOS）
brew install uv          # 或: curl -LsSf https://astral.sh/uv/install.sh | sh

# 创建/同步环境（按 uv.lock 精确还原依赖，自动建 .venv）
uv sync

# 运行
uv run run_backtest.py --synthetic                  # 离线演示（合成随机行情）
uv run run_backtest.py                              # 贵州茅台真实日线 双均线回测（带缓存）
uv run run_backtest.py --symbol 300750 --short 10 --long 120   # 换标的/参数

# 测试
uv run pytest                                       # 引擎正确性单元测试 (4项)
```

> 提示：`run_backtest.py` 的 shebang 已改为 `uv run`，也可直接 `./run_backtest.py --synthetic`。
>
> 数据源：首选 **baostock**（稳定、免费、含前复权），失败时自动兜底 **akshare**(东方财富源)。

## 引擎处理的 A 股关键约束

| 规则 | 处理方式 |
|---|---|
| **T+1** | 每日先卖后买，当日买入次日才能卖 |
| **信号延迟** | T 日收盘计算权重 → T+1 开盘价撮合，杜绝未来函数 |
| **涨跌停** | 开盘价触及 ±limit% 视为无法成交并计数（主板10%/创业科创20%自动判断）|
| **成本** | 佣金万2.5(最低5元) + 卖出印花税0.05% + 过户费 + 0.1%滑点 |
| **整手交易** | 按 100 股取整；调仓死区 2%，避免微量换手 |

引擎正确性已由单元测试验证：信号严格 T+1 开盘执行、清仓后买卖股数一致、NaN 权重安全。

## 已知简化（后续可自行扩展）

- 单标的支持；多股票组合需要改造为逐日循环多列权重矩阵
- 不支持做空、融资融券、分红送转再投资（前复权价已隐含分红收益）
- 分钟级回测需换数据源与撮合逻辑
- ETF 回测被多扣了卖出印花税（现实中 ETF 免印花税），结果略保守

## research/ — 市场规律研究

```bash
uv run python research/weekday_effect.py               # 沪深300 星期效应
uv run python research/weekday_effect.py --symbol 000905   # 中证500 交叉验证
```

四层验证框架：描述统计 → 显著性检验(Welch t + 置换检验, Bonferroni 校正) →
分年代稳定性 → 可交易性(扣成本)。任何"市场规律"都应过这四关再谈利用。

已完成的发现（2005~2026，三指数交叉验证）：
**周四负效应**在 2005-2018 显著存在（中证500 上 -15~-20bp/天），
但 2019 年后衰减至 ≈0 —— 与 2016 年新股信用申购改革（周四预缴款制度终结）的时间线吻合。
一个"曾被文献记录、后被制度变迁消灭"的活样本。

**短期反转因子月频实验**（2014-2026，800 只中大票池，[方案](docs/reversal_factor_plan.md)）：
五分组严格单调（Q5 追高组年化仅 +3.2%）、行为规律成立，但 IC 强度不足（-0.037）
且月频轮换 × 15bp 成本把超额吃到 +0.8pp，预注册判定=未通过——
"方向对、幅度不够、成本致命"是行为类因子在中大票池的典型画像。

**Round 1 因子批量筛选**（2014-2026，800 只中大票池，[方案](docs/factor_screen_round1_plan.md)）：
中期动量 部分通过（超额 +3.6pp、换手仅 2.6、三段全正、35bp 成本仍 +2.4pp，
但全截面 IC 弱——信号集中在右尾）进入组合观察名单；BP / 低波动 / 距52周高点 未通过。
候选池索引与后续检验顺序见 [docs/factor_candidates.md](docs/factor_candidates.md)。

**Round 2 因子批量筛选**（2014-2026，9 因子全量数据，[方案](docs/factor_screen_round2_plan.md)）：
**Amihud 非流动性 通过(4/4) —— 项目首个全通过因子**（超额 +7.3pp、换手 2.5、
35bp 成本仍 +6.1pp、三段全正），进入组合候选池；反转/中期动量 部分通过（观察名单不变）；
低换手率 / EP / 股息连续性 / 两融变化 / 北向 / ROE 未通过；小市值 暂缓（历史市值
数据源东财/雪球被阻断）。核心归因：本池对"流动性/行为类"因子友好、对"价值/机构审美类"
苛刻。

**Round 3 组合研究**（2014-2026，[方案](docs/factor_round3_combination_plan.md)）：
**Amihud + 中期动量 等权打分组合 通过(4/4)，确立为策略主体**——超额 +9.8pp（35bp 仍
+8.4pp）、夏普 0.91、年换手仅 2.9、三段全正（+7.7/+15.7/+8.5）；两因子 IC 序列相关
−0.43 兑现动态互补（2018-2021 段叠加出 +15.7pp）。+反转三臂未救活反转（换手拉到 6.6、
超额掉回单因子水平）→ 反转确认不可用。**遗留最大风险：C 臂最大回撤 −54%**。

**Round 4 风险加固·选股层**（2014-2026，[方案](docs/factor_round4_plan.md)）：
尝试剔除合成分最极端 5%（R4a）改善回撤——**未通过(2/4)**：回撤仅改善 1.4pp、超额反损
2.2pp，且两臂最大回撤区间同为 2015-06-12~09-15（股灾）。**结论：−54% 回撤是市场级 beta，
选股层改不动**。注：C 臂平均持股 ≈103 只（Round 3 归档误写 ≈40 只已在此更正）。

**Round 4b 风险加固·风控层**（2014-2026，[方案](docs/factor_round4b_drawdown_breaker_plan.md)）：
C 持仓叠加回撤熔断（−20% 半仓 / −30% 空仓，含迟滞）→ **部分通过(3/4)**：2015 股灾
回撤从 −53.9% 压到 −27.3%、夏普升到 0.98，但 2018 阴跌从不触发阈值、满仓扛单边反成
新低 −41.4%，超额代价 −4.1pp。**关键机制发现：固定阈值回撤熔断躲急跌、不躲阴跌**。

**Round 4c 风险加固·均线择时**（2014-2026，[方案](docs/factor_round4c_trend_breaker_plan.md)）：
C 持仓叠加沪深300<MA200 降半仓（2%迟滞）→ **部分通过(3/4)**：2018 阴跌 −22.3%
（补上 4b 的洞）、2022 −13.7%、2024 −12.4% 均大幅改善，但 2015 顶部急跌因趋势信号
滞后仍 −51.5%。**核心结论：4b 回撤熔断治急跌、4c 均线择时治阴跌，两者正交互补**。

**Round 4d 风险加固·双熔断叠加**（2014-2026，[方案](docs/factor_round4d_dual_breaker_plan.md)）：
C 持仓叠加 f=min(回撤熔断, 均线择时) → **未通过(2/4)**：2015 急跌治到 −27%、
2022/2024 阴跌治到 −14%/−12%，但**两套信号在股灾恢复期互相钳制**（净值未回前高 +
指数在均线下方 → 长期半仓 → 踏空 2017 大涨 → 2018/2019 反成新低 −37%），
超额 −6.1pp 属防守过度。**风控层四轮实验收束**：任何风控都无法把回撤压进 −30%
还保住 ≥4pp 超额——回撤管理本质是"用 beta 收益换 beta 风险"的定价。

**Round 5 行业中性化**（2014-2026，[方案](docs/factor_round5_industry_neutral_plan.md)）：
同一中性化池内，行业内百分位排名（R5）vs 全局排名（C_base）→ **R5 通过(4/4)**：
行业内 alpha 真实存在（+5.7pp、三段全正、35bp +4.1pp），行业 beta 贡献恰好 4.0pp
（C 的 +9.7pp 超额约 40% 来自行业暴露，60% 是行业内选股）。
**默认策略升级为 R5 行业中性化版**：Amihud+中期动量行业内百分位等权打分 → 前 20%
等权，月度调仓；回撤 −51.8%（略优于 C 的 −53.8%）。行业中性化用 4pp 超额换掉了
行业集中风险，是"去行业风险后的诚实 alpha"。

**Round 6 收尾：R5+均线择时叠加**（[方案](docs/factor_round6_r5_ma_plan.md)）：
**未通过(2/4)**——R5 超额已被行业中性化削薄（+5.7pp），再付 −2.8pp 买均线择时代价
占比过高，回撤仅改善 4.4pp、夏普持平（0.80→0.81）。**当前池最终默认 = R5（不叠加）**。

**Round 7 幸存者偏差验证：全市场扩池重跑 R5**（2014-2026，[方案](docs/factor_round7_fullmarket_validate_plan.md)）：
下载全市场 **3194 只**（主连+中小板，`data/fundamental/full_daily.parquet` 8.8M 行）→
扩池重跑默认策略 R5 → **通过(4/4)**：全市场 R5 超额 **+4.6pp**（35bp +2.9pp）、
三段全正（+8.0/+2.7/+3.9）、换手 3.7、回撤 −54.6%、夏普 0.58。
**幸存者偏差贡献仅 1.1pp（5.7→4.6）——此前担心的"超额大半是偏差造出来的"不成立，
行业内 alpha 真实存在、泛化成立。全市场 R5 定为最终策略。**
诚实记录：夏普 0.58 低于 800 池 0.80（全市场等权波动更大是去偏差代价）；
800 池 2018-2021 强段（+10.7）扩池后只剩 +2.7，说明该段超额含中大票池与行情交互。

**Round 8 实盘化验证**（[方案](docs/factor_round8_live_validation_plan.md)）：
**通过(4/4)，策略可执行**。流动性依赖成本模型（c=15bp+s×Amihud百分位）：
s=40bp（平均≈35bp）下超额 **+2.56pp**、flat70bp 极端成本贴线 +0.09pp；
可交易性极佳（575 只等权，AUM5000万 时单票占日成交 p95<1%，资金容量远超）；
T+1 涨跌停阻塞损失仅 0.18pp（每月约 8 买不进/3 卖不出，同组替代稀释）。
自检抓出并修正成本口径 bug（固定金额→比例成本）。**实盘三条红线**：控成本（限价/拆单）、
规模 5000万+ 无压力、39% 冷门股执行需 POV 拆分。模拟盘起点持仓
`output/factor_round8_holdings_2026-09-03.csv`（575 只）。
**研究闭环：因子筛选 → 组合 → 风控 → 行业中性化 → 扩池验证 → 实盘化验证。**

## 学习路线建议

1. 先 `--synthetic` 跑通，读懂 `backtest.py` 的逐日循环
2. 拉真实数据，观察策略 vs 买入持有 vs 沪深300
3. 改造策略：把 `strategies/dual_ma.py` 的权重逻辑换成你自己的想法（动量、轮动、多因子…）
4. 加参数扫描看过拟合：同一策略在不同 (short, long) 下表现差异越大越危险
5. 用聚宽/米筐模拟盘验证 3 个月后再考虑 QMT 实盘
