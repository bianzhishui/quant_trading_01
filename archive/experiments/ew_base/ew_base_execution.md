# 核心层构造方案 — 等权底仓（执行版）

> 状态：**现行有效** ｜ v1.0 ｜ 2026-09-02
> 定位：**构造方案，不是策略**——不预测市场，只规定"买什么、买多少、何时动"。
> 依据：docs/ew_base_plan.md（预注册研究档案：年频再平衡溢价 +2.2pp、
> 3/3 年代段跑赢中证500、机械判定成立）
>
> ⚠ 本文档是学习项目的研究结论整理，**不构成投资建议**；
> 比例与风险承受由执行者自定。

---

## 1. 规则（全部规则，共三条）

1. **买什么**：中证500 或中证1000 指数产品（ETF/指数基金，优先费率低、
   规模大、跟踪误差小者；有等权类产品则更贴合本方案）
2. **买多少**：核心层资金一次性或分批买入后**长期满仓持有**；
   核心层之外的资金不适用本方案
3. **何时动**：**每年固定一个日期**（如生日/元旦后首个交易日），
   把组合调回目标比例。其余时间任何行情下**不操作**

可选增强（默认不开）：偏离带宽——某资产占比偏离目标 ±5pp 以上时提前调，
否则严格年度。

## 2. 方案不做什么（与六次失败实验的对照）

| 禁止事项 | 依据 |
|---|---|
| 不做任何选股筛选 | PB<1+高股息筛选 = 负 alpha（同池 9.0% vs 等权 16.2%）|
| 不做择时/年线过滤/仓位择时 | 双均线、动量 V3、星期效应均未通过 |
| 不做"赢家多配"的漂移式集中 | 漂移 = −6.7pp/年，单票权重退化至 100% |
| 不因回撤/踏空临时改规则 | 见 §4 修订协议 |

## 3. 风险与预期管理（必须先读）

- **预期收益打折**：研究中年化 16.2% 含幸存者偏差，实盘锚定真实指数
  产品口径（长期 ~6-8% 量级），任何更高预期都视为幻象
- **回撤是常态**：等权口径历史最大回撤 −49%；指数产品口径更浅但仍远超
  多数人心理承受——**执行前先问自己腰斩时会不会卖**，会卖就减半执行
- **风格风险真实存在**：等权含小盘暴露，2017 型"大盘牛小盘平"年份会
  显著跑输沪深300；这是方案的一部分，不是故障
- **再平衡不是收益保证**：+2.2pp 是长期机械均值，单年可能为负贡献

## 4. 修订协议（延续预注册纪律）

- 本方案 v1.0 的三条规则**锁定**；任何改动 = 新版本另立文档并说明依据
- 允许触发修订的条件：新预注册实验（四层验证通过）证明更优构造；
  交易成本/产品结构发生实质变化
- **不允许**的修订理由：回撤难受、踏空难受、看到别人赚钱
