## 2. 引擎改造规则（定死）

### 2.1 `paper_trade.rebalance` 签名扩展

```python
def rebalance(self, target, prices, tradable, ret_exec=None):
    # ret_exec=None → 无阻塞（向后兼容）
    # ret_exec 传入 → S3-跟随 阻塞:
    #   买入端: ret_exec[code] >= +LIMIT_THR(0.098, 涨停) → 买不进, 钱留现金
    #   卖出端: ret_exec[code] <= -LIMIT_THR(跌停) → 卖不出, 保留持仓
    #   未成交递延到下月调仓再平衡(不强制补买)
```

- `LIMIT_THR` 从 `reversal_factor` 导入（paper_trade 已依赖 reversal_factor，单向无循环）；
- 涨跌停判定用**执行日涨幅**（`ret.loc[执行日]`），与 Round 23 同口径。
