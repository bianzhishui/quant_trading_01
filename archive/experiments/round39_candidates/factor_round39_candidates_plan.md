### 0.3 诚实归因（核心知识）

1. **"异法度"预筛的 Jaccard 16.9% 未能转化为组合增益**：C1/C2 与 w* 选股几乎不重叠
   （异法度极强），但单因子超额仅 +1.7%/+2.0%（<3pp 门槛）——**选股分歧大 ≠ 有增量**，
   与 R22（价格水平 44.8% Jaccard 向差分散）同构：异法度是必要不充分条件；
2. **C3 "同法风险"对照兑现**：单因子 4/4 通过（+9.4% 最强，小市值代理超额高），但并入后
   Jaccard **90.6%**（与 w* 几乎同一批股）→ 只是 Amihud/F4 的重复暴露，①超额 +0.24pp
   门禁失败——**"同法"因子单因子再强也不能并入**（R22 教训在此框架下重演）；
3. **C1/C2 的"信号存在但幅度不足"画像**：IC 显著（−0.08~−0.09）、单调完美、三段全正，
   但月频换手 2.8~4.4 下超额只有 ~2pp——与 R36 周频低换手（+1.3pp）结论一致：
   **低换手方向真实、量级始终不足以覆盖成本**；换手波动与低换手 Jaccard 100% 同源
   （同组因子，只留代表）；
4. **C4 方向确认**：短动量 5/21 在月频也是反转（高动量组大幅跑输），与 R36 周频短反转
   结论一致——短线反转在月/周频都不可交易；
5. **框架结论**："同向但异法"是**必要不充分**的候选发现器：预筛能高效排除同法冗余（C3
   的 90.6% 与 C4 的 4.5% 两极对照），但**最终裁判永远是组合验证的增量门禁**——本轮
   3 类结局（异法弱信号/同法强信号/方向错误）全部存档，框架判据得到实证校准。

## 1. 候选因子清单（定死，3 个主候选 + 1 个对照）

| # | 因子 | 定义（信号日 T） | 方向 | 同向对象 | 异法点 |

## 2. 两阶段流程（定死）

  和=1）——**小权重并入**（R22/R30 教训：等权并入破坏主源，小权重是保守路径）；
- 对照 A = 现 w*（0.40/0.10/0.50）；判定 5 项：① 超额 ≥ +1pp ② 回撤 ≤ +5pp ③ 换手 ≤1.5×
  ④ 三段全正 ⑤ Jaccard < 0.75。

## 3. 预注册判定标准（跑之前写死）

### P1 单因子层（4 项，R36 框架）

| # | 判据 | 阈值 |
|---|---|---|
| ① 显著性 | 月频 IC 方向符合假设 且 \|t\| ≥ 2 | ICIR/方向一致率辅助 |

- 判定 = 通过(4/4) / 部分通过(3/4) / 未通过(≤2/4)；通过者进 P2。

### P2 组合层（R37 协议，5 项，≥4/5 为"可并入候选"）

- ① 超额(B−A) ≥ +1pp（核心门禁）② 回撤 ≤ +5pp ③ 换手 ≤1.5× ④ 三段全正 ⑤ Jaccard < 0.75；
- **≥4/5 → "可并入候选"**（产出决策点：是否并入 w*、权重再扫描，须用户批准 + 预注册）；
- 否则 → 不并入，该因子降级"单因子参考"（R22/R30/R37 同待遇）。

## 4. 诚实风险（预先声明）

1. **C1/C2 的 Jaccard 16.9% 是双刃剑**：异法度极强意味着"新增选股与现有完全不同"——但
   R22 教训：分散 ≠ 增强，可能是"向差分散"。P2 组合验证是唯一裁判，Jaccard 低本身不构成
   通过理由；
2. **同源伪装**：C1/C2 与 F4 同向（相关 ~0.3-0.4），必须做正交残差 IC（对 F4 回归）——
   若正交后不显著 → "同向冗余"；显著 → 才谈得上异法增量；
3. **换手成本**：低换手因子天然低换手（好事），但并入后若与现有组合换手叠加需实测——
   ③ 换手门禁兜底；
4. **市值代理（C3）是"同法"对照**：与 Amihud 相关 −0.78，预期并入后与 Amihud 重复暴露
   （R22 价格水平前科）——纳入它是为了证明"异法度是增益来源"的对照实验，不是真候选；
5. **月频 vs 周频**：本批因子按 R5 生产月频测（并入的是月频打分）；周频优势（R36 框架）已
   归档，本轮不做周频；
6. **不改生产**：任何结果只产出候选 + 决策点；落地另开预注册 + 用户批准 + 账本重建。
