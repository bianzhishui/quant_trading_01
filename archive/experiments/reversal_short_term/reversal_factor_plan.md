## 0. 实施结果归档（2026-09-03）

| 指标 | 读数 |
|---|---|
| 调仓期数 / 月均可交易池 | 141 期 / 516 只（组均 103 只） |
| 分组年化 Q1→Q5（扣15bp） | **+11.7% / +9.1% / +8.8% / +7.5% / +3.2%**，基准（同池等权）+10.9% |
| 多空示意 Q1−Q5（毛，几何） | +8.2%/年 |
| 月度 RankIC | 均值 **−0.0373**，ICIR −0.21，t=−2.47，IC<0 占比 53% |
| Q1 年换手 | 8.4（单边）——15bp 下成本拖累 ≈ 1.26pp/年 |
| 分段 Q1 超额（对基准） | 2014-2017 **+2.6pp** ｜ 2018-2021 **+1.8pp** ｜ 2022-2026 **−1.3pp** |
| 成本压测（Q1 超额） | 15bp **+0.8pp** ｜ 25bp −1.1pp ｜ 35bp −2.9pp |

判定：**未通过（2/4）**。② 单调性完美过线（组序 Spearman −1.00）；④ 2/3 段为正过线；
① IC 均值 −0.037 未达预注册的 −0.05 线（t=−2.47 过线但 IC<0 占比仅 53%，信号不稳定）；
③ 扣 15bp 后超额 +0.8pp，远低于 3pp 门槛，25bp 档即转负。

**归因读数：**
- **行为规律真实存在，但强度不够**：五分组严格单调、Q5（追高组）年化仅 +3.2%
  显著垫底——"不追高"这条散户行为规律在本池 13 年样本内干净成立；
  但 IC 量级只有全市场文献口径的一半左右，且月度方向一致率仅 53%，
  与预期一致：本池是沪深300+中证500 中大票，反转在小盘更强，本池是下界估计。
- **收益被换手吃掉**：Q1 对基准毛超额约 +1.7pp/年，月频完全轮换 × 8.4 倍换手
  × 15bp 后只剩 +0.8pp。反转因子天然高换手，成本是它的主要敌人——25bp 即转负。
- **基准本身太强**：等权全池 10.9%/年（含幸存者偏差加成），打败"同池等权"
  本来就难；这正是相对口径诚实的代价，也是 dividend 实验同一发现的重演。
- **2022-2026 段转负**（−1.3pp）：与机构化+量化拥挤的时间线吻合，
  与 weekday 效应衰减属同一模式——"因子衰减"再次被独立记录。
- **多头端回撤不可忽视**：Q1 全样本最大回撤 −44.5%（2015-2016 段），
  超跌组天然带小票/高波动暴露，即使超额为正也未必拿得住。

**结论归档**：在本池（中大票、当前成分、月频、15bp 成本）短期反转**不可交易**。
方向与单调性成立说明信号有真实来源，改进方向留待另开预注册文档（不在本文档追改）：
周频缩短持仓错配、小盘池（中证1000/全市场）提高信号强度、
多头端加缓冲带（hysteresis）降换手、与低换手/低波动正交取纯行为分量。

## 1. 研究假设

| 编号 | 假设 | 检验方式 |
|---|---|---|
| H1 | 短期反转：过去 21 个交易日收益与未来 1 个月收益负相关（月度 RankIC 均值 ≤ -0.05 且 t ≤ -2） | 逐月截面 Spearman |
| H2 | 分组单调：按 rev21 五分组，Q1（超跌）年化最高、Q5（追高）最低 | 五组年化排序 |
| H3 | 可交易：Q1 等权月频组合扣 15bp/单边 后年化超额（对同池等权基准）≥ 3pp | 组合回测 |
| H4 | 稳定：三分段（2014-2017 / 2018-2021 / 2022-2026）中 ≥2 段 Q1 超额为正 | 分段归因 |

## 2. 数据与已知局限（诚实清单）

- **股票池**：当前沪深300+中证500 并集 800 只 → **幸存者偏差**，绝对收益系统性偏高；
  本实验主要读数为相对量（IC / 分组排序 / Q1−等权基准超额），基准用**同池等权**
  以隔离选股贡献
- **池内为中大市值**：文献与本项目 [《A股散户结构与因子有效性梳理》](../../docs/retail_investor_structure.md) 均指出反转在小盘
  更强，本池读数是**下界估计**——这点在归因时必须说明
- **涨跌停**：无逐日真实限价 → 用前复权日收益 ≥ 9.8% 近似主板涨停（只剔除买入端，
  卖出端跌停无法成交未建模），除权日近似有微小误差，记录在案
- **停牌**：持仓期内停牌按价格延续（收益 0）口径，与项目既有实验一致
- **close 为前复权**：跨期收益比较不受复权基准影响

## 3. 策略规则（定死）

### 3.1 股票池（每月末 T 日，与 dividend/ew 实验同口径）

依序过滤：
1. 截至 T 日已有 ≥ 375 条日线记录
2. T 日 `tradestatus == 1` 且 `isST == 0`
3. 非创业板/科创板/北交所（代码非 300/688/bj 开头）
4. T 日未涨停（前复权日收益 < 9.8%）

### 3.2 因子

`rev21 = close(T) / close(T−21) − 1`（前复权收盘，21 个交易日 ≈ 1 个月）。
方向约定：值越低越超跌，做多组 1。

### 3.3 组合

- 可交易池内按 rev21 **rank 等分 5 组**，Q1 = 最低 20%
- **多头** = Q1 等权，月频完全轮换
- **基准** = 当期全部可交易股等权（同池等权，隔离选股贡献）
- **多空** = Q1 − Q5（不计空头成本，仅作示意读数，A 股无法实际做空）

### 3.4 调仓与成本

- 月末 T 收盘算信号，次月首个交易日生效（沿用 `equal_weight_nav` 口径）
- 基础全成本 **15bp/单边**（佣金 2.5 + 印花税 5 卖摊 + 滑点 7.5），按权重变动计提
- Q1 另做 25/35bp 压测档（成本敏感度）

### 3.5 回测区间与分段

- 2014-01 首次调仓 ~ 2026-09（沿用 dividend 实验的数据起点约定）
- 分段：2014-2017 / 2018-2021 / 2022-2026

## 4. 预注册判定标准（跑之前写死）

| 层 | 标准 |
|---|---|
| ① 显著性 | 月度 RankIC 均值 ≤ −0.05 且 t ≤ −2（ICIR 与 IC<0 占比作辅助读数） |
| ② 单调性 | Q1 为 5 组年化最高且 Q5 为最低（组序 Spearman ≤ −0.9 作辅助读数） |
| ③ 可交易 | Q1 扣 15bp 年化超额 ≥ 3pp；35bp 档超额仍 > 0 作附加读数 |
| ④ 稳定性 | 三段中 ≥ 2 段 Q1 超额 > 0 |

判定 = **通过（4/4） / 部分通过（3/4） / 未通过（≤2/4）**。
失败协议：如实归档，禁止回头改回看期/分组数/池口径重跑；
若判定为"部分通过"，改进方向另开预注册文档，不在本文档内追改。

## 6. 预期管理

反转是 A 股文献与业界公认最强的量价因子之一，但本实验有两个先天折扣：
(a) 池子是中大市值股票，散户行为类信号强度打折；(b) 2017 年后机构化与量化
拥挤让月频纯反转持续衰减。合理预期：①② 在 13 年全样本大概率成立，
③ 是最难过线的一层（月频轮换 × 15bp ≈ 1.5pp/年成本起），
④ 大概率呈现"前段强、后段弱"。若 ④ 失败，结论按"样本内已衰减"如实归档——
与 weekday 效应衰减案例一样，这本身就是本项目要积累的核心知识。
