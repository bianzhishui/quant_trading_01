# Round 53 预注册：A1 低波60 在 P3 八账户的**份额级落地验证**（1 手约束 × 真实成本）

状态：**✅ 已实施（2026-09-29）**｜主窗口：**八账户全部通过**（门槛 3万）；全样本窗口因口径缺陷作废（§0.1）｜对象：P3 低价股策略｜上位结论：R51（A1 唯一通过预注册判据）

## §1 问题

R51/R52 的结论基于**等权净值回测**（无资金约束）。但 P3 是 **1 手 = 100 股**的真实模拟盘
（八账户 3万~600万），小账户天然退化（现冻结参数下 3万账户只能买少数标的）。

A1 把目标持仓从 **61 → 43 只**（近年 51→36）。这会**放大** 1 手约束的伤害：
标的越少，每只应分配的资金越多，但低价股（3-4 元）1 手仅 300-400 元，小账户反而可能
"每只都买得起 1 手但买不满"，或"部分标的连 1 手都不够"。

**本轮问**：A1 在**真实份额级 + 1 手约束 + 真实成本 + 涨跌停阻塞**下，八个账户各自
还能不能保住 R51 看到的改善？小账户是否应当维持 P0？

## §2 方法（规则定死）

**引擎**：复用生产同款 `PaperPortfolio`（`scripts/r5/paper_trade.py`）与
`scripts/p3/scenario_ytd_p3.py` 的份额级回放（含 1 手取整、佣金/印花/过户/滑点 15bp、
除权事件补缺、涨跌停阻塞）。**不重新实现回放逻辑**（避免除权/阻塞细节二次实现出错）。

**生产脚本最小扩展（向后兼容）**：给 `run_scenario_p3` 增加可选参数
`target_fn: Callable[[pd.Timestamp, set], set] | None = None`：
- `None`（默认）= 现行行为，逐位不变；
- 给定则 `target = target_fn(rb["T"], rb["target"])`。
仅新增一个分支，不改任何默认路径。

**变体**：
| 编号 | 目标集合 |
|---|---|
| S0（基准） | `target_fn=None`（现冻结 P3，不截断） |
| S1（A1） | 池内 `vol60 = close.pct_change().rolling(60).std()`（信号日 T 数值），**NaN 记最差**，升序取前 **70%**（同 R51 A1 口径：`ceil(0.70×n)`） |

**账户**：八账户全部（3万/10万/20万/30万/60万/100万/300万/600万，`p3.aum_list`）。

**窗口**：
- 主窗口 = **验证段 2021-01-04 → 2026-09-28**（与 R51/R52 验证段一致，便于对照）；
- 稳健性窗口 = **全样本 2014-02-10 → 2026-09-28**（仅 S0/S1，八账户）。

**每账户指标（必须全部报告）**：
1. 期末 NAV、年化、最大回撤（份额级真实口径）
2. **实际平均持仓只数**（月末快照均值）与**目标只数**之差的缺口
3. 平均现金占比（1 手约束导致的拖累）
4. 累计费用占初始资金比
5. **"买不起 1 手"事件数**：调仓时目标标的按理论等权分配额 < 1 手价（100×价 + 费用）的次数
6. 相对基准 S0 的 年化差 / 回撤差（**同账户对比**，消除账户规模差异）

## §3 判定标准（预注册）

对每个账户规模分别判定（不做跨账户平均）：

**"A1 在该规模可用"需同时满足**：
1. 年化 ≥ S0 年化 − 0.5pp（不牺牲超过 0.5pp 收益）
2. 最大回撤 ≤ S0 最大回撤（不更深）
3. 实际平均持仓 ≥ **30 只**（沿用 R52 的分散度下限），且 ≥ 目标只数的 70%

**输出结论形态（无论通过与否）**：
- 给出 **"A1 可用门槛规模"**：从哪个账户规模起 A1 满足上述三条；
- 明确小账户（3万/10万/20万/30万）的处置建议（维持 P0 / 换用更低截断比例）；
- 若**任何**规模段出现"A1 回撤反而更深"或"年化差 > 1pp"，须如实标注为风险。

## §5 诚实风险（预注册时已知）

1. **份额级与等权口径的差异是系统性的**：P0 本身也有 1 手退化，因此**只能同账户相对比较**，
   不能把份额级年化与 R51 的等权年化直接对比；
2. **A1 的"43 只"是目标而非实际**：小账户实际可能只持 10-25 只，集中度更高 → 回撤模型外风险；
3. **窗口含 2021-2026 单一风格段**：若 A1 的优势本就集中在近年，份额级结论也只在近年成立；
4. **不重建账本**：本轮是历史回放验证，不动 `output/p3/ledger_p3_*.json`（生产记录保持连续）；
5. **未计换手/流动性冲击**：低价股 1 手小单，冲击可忽略，但未建模；
6. 若结果显示"仅 300万+ 可用"，则 A1 的适用范围显著小于 R51 的表面结论 —— 这是本轮最可能的
   有价值发现之一。

### §3 判定（主窗口，逐账户）

**八个账户全部通过**（年化 ≥ S0−0.5pp、回撤不深于 S0、实际持仓 ≥30 只且 ≥目标 70%）：
→ **A1 可用门槛规模 = 3万（及以上）**；没有任何账户变差。

**分层解读（诚实，关键）**：

1. **10万-600万（7 个账户）：A1 是真实的正向改善**
   - 年化 **+0.63 ~ +1.86pp**（随规模递减：10万 +1.86 → 600万 +0.63）
   - 回撤改善 **+2.45 ~ +3.13pp**（稳定），夏普全线 +0.06~+0.10
   - 持仓率均 99.6%→99.8%，买不起 1 手 **0.0%** → 1 手约束在本轮**不是**主要矛盾
2. **3万账户：A1 的 +12.08pp 主要是"从不可执行到可执行"的修复，不是因子 alpha**
   - 现冻结 P3（66.5 只目标）在 3万账户上**执行失败**：实际只持 **35.0 只（52.6%）**、
     **47.3% 的目标连 1 手都买不起**、现金 **49.1%**、累计费用 **35.00%**、年化 **−3.99%**
     （对比 600万 +18.42%，差 22pp）——即"3万账户跑的不是 P3"
   - A1（47 只）把每只预算从 ~450 元提到 ~640 元 → 持仓率 99.7%、现金 22.0%、
     年化 **+8.09%**（仍低于 10万 的 +15.14%，因 22% 现金拖累未消除）
   - **这是独立于因子研究的生产告警：3万账户当前无法执行 P3（`config/default.yaml`
     `p3.aum_list` 里的 3万 档需要单独处置）**

### §0.1 **全样本窗口（2014-02-10→2026-09-28）判定为无效，不予采纳**

| 证据 | 数值 |
|---|---|
| 非等权口径（本轮份额级）S0 全样本最大回撤 | **−95.01% ~ −95.07%**（八账户几乎相同） |
| 等权口径 P0 全样本最大回撤（同数据同池，本轮复核） | **−45.54%** |
| 份额级累计费用占初始资金 | **117% ~ 165%**（主窗口仅 13%~48%） |
| 池内 645 只 code 尾部失效（退市/长期停牌）数 | **0 只** → 排除退市因素 |

**根因**：`scenario_ytd_p3` 直接把原始价 `raw.iloc[i]` 交给 `PaperPortfolio.value()`；而
`PaperPortfolio.value()` 对 NaN 价格的持仓**不计市值**（R48 plan §第 30-39 行已明确记录）。
R48 的修正 `eval_prices(raw) = raw.ffill()` 已接入生产 `paper_live`（8 处）与
`paper_live_p3`（7 处），**但这条回放路径没有接入**。2015 年 A 股千股停牌期间，
池内大量停牌股市值被记 0 → NAV 假崩塌 → 记录出 −95% 回撤与爆炸式换手/费用。
主窗口（2021-2026，无千股停牌）因此几乎不受影响（见上方可信性验证）。

**处置**：全样本份额级结论**作废**（含其"仅 3万可用"的判定，该判定源于伪影）；
**修正方案（须另行预注册）**：回放路径区分"估值用 ffill 价 / 成交用原始价"（与 R48 生产口径
一致）后重跑长样本。本轮**不改**生产脚本口径（属口径变更，需批准）。

### 结论与代价（诚实）

1. **A1 在八个账户上均不劣于现冻结 P3**（主窗口）：10万-600万 年化 +0.63~+1.86pp、
   回撤改善 +2.45~+3.13pp；3万 从"执行失败（−3.99%）"修复到 +8.09%
2. **最重要的操作性发现**：**3万账户当前无法执行 P3**（持仓率 52.6%、49% 现金、年化 −3.99%），
   这与是否采纳 A1 无关，是独立的账户配置问题
3. **A1 的真实增益小于等权回测的表现**：600万 份额级仅 +0.63pp（等权口径 +1.6pp），
   说明 1 手取整/阻塞/现金拖累会吃掉约 1pp
4. **口径缺陷已发现并留证**：份额级长样本回放不可用（R48 修正未接入该路径），
   已给出证据链与修正方案，待批准后另轮实施
5. **代价**：4 次份额级回放（1154s）+ 1 次冒烟（576s）+ 1 次等权对照探针；0 次生产策略改动、
   0 次账本改动（`output/p3/ledger_p3_*.json` 未触碰）
6. **局限**：主窗口只含 2021-2026 单一风格段；未建模停牌日的真实处置与流动性冲击；
   A1 的"可用门槛 3万"是基于目标只数与持仓率的判定，不代表 3万账户收益已达标
7. **生产采纳（改 P3 选股规则 / 重建八账户账本 / 处置 3万账户）须另行批准**
