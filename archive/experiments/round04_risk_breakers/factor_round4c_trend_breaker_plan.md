### 归因读数（核心发现：两种信号互补）

1. **均线择时擅长躲"阴跌/慢熊"，不擅长躲"牛市顶部急跌"**：
   2015-08-20 才跌破 MA200 降仓，而峰值在 06-12——2015 上半年暴涨远超均线，
   6-8 月从高位回落到均线附近，**等跌破均线时已跌掉 45%+**。趋势信号对"顶部急跌"
   有天然滞后（等信号确认，主跌已过大半）。
2. **与 4b 的回撤熔断形成完美互补**：
   - 4b 回撤熔断：急跌敏感（2015 → −27%）、阴跌无感（2018 → −41%）
   - 4c 均线择时：阴跌敏感（2018 → −22%）、急跌滞后（2015 → −51%）
   - **两者正交：4b 治急跌、4c 治阴跌，合起来理论上能同时覆盖 2015 与 2018**
3. **收益代价比 4b 更低**：R4c 超额 +6.5%（4b 是 +5.7%），35bp 仍 +5.3%，
   换手 2.7（均线切换频率低）。均线降仓错过反弹的代价小于回撤熔断的空仓代价。
4. **三段表现**：2014-2017 +8.5%（均线在牛市横盘段略进略出反而小赚）、
   2018-2021 +9.7%、2022-2026 +3.3%（最后段被降仓吃掉最多，但回撤也最受益）。

### 结论归档

- **R4c 部分通过：均线择时是 4b 的互补件，不是替代品**。单独用压不住 2015 深度；
  但它在 2018/2022/2024 阴跌段的表现显著优于 4b。
- **策略主体仍为满仓 C**（超额 +9.8pp、夏普 0.91、换手 2.9）。
- **下一步（预注册）Round 4d：双熔断叠加（回撤熔断 ∩ 均线择时）**——仓位 = min(4b 状态,
  4c 状态) 或乘积，目标同时覆盖 2015（回撤信号）与 2018（趋势信号）两类回撤源。
  单一改动 = 增加第二个触发信号，与 C/4b/4c 三臂对照，归因清晰。
  **注意**：双信号叠加后超额大概率进一步下降（两个风控都收钱），判定要关注
  "回撤压到 −30% 内" 与 "超额 ≥ +4pp" 的权衡而非绝对收益。
- 诚实边界：均线窗口 200、迟滞带 2% 均按预注册固定；改参数属参数挖掘需另立方案。

## 1. 机制（定死）

- **触发信号**：沪深300（000300）收盘价 vs 其 200 日均线（MA200）
- **仓位状态机**（两态 + 2% 迟滞带，防在均线附近来回抖动烧手续费）：
  | 状态 | 条件 |
  |---|---|
  | 满仓 f=1.0 | close > MA200 × (1 + 2%) |
  | 半仓 f=0.5 | close < MA200 × (1 − 2%)（降仓） |
  | （迟滞带）| 介于两者之间时保持上一状态不变 |
- **生效**：每日权重 = f(t) × C 目标权重；降仓/回补均按 15bp 单边计交易成本；现金收益 0（保守）
- 与 4b 的**唯一区别**：触发信号是市场趋势而非自身回撤；仓位只设 0.5/1.0 两档
  （不设空仓档，均线下方留一半仓位跟踪，避免完全踏空反弹）
