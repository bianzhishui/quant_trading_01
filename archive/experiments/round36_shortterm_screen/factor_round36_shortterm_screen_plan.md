### 0.2 F4 低成交额5 —— 通过但同源 Amihud（重点诚实归档）

**判定 4/4**：IC −0.077 (t=−10.79, 全因子最强)、组序 Spearman −1.0（完美单调）、
超额 15bp **+11.9pp** / 25bp +9.5pp / **35bp 仍 +7.1pp**、年换手仅 10.3（周频里异常低——
说明 Q1 冷门股组合高度稳定，成本没有吃掉信号）、三段全正（+13.5/+6.6/+16.5）。

**⚠️ 同源守卫触发**：与生产 Amihud21 截面相关 **−0.85**（>0.6 线）→ 正交残差 IC
**−0.0746（显著）**。按预注册规则：正交后仍显著 → 判定"**通过但需组合验证守门**
（R22/R30 教训：单因子通过≠可并入）"。

**补充诚实检查（tmp 脚本，2026-09-18）**：
1. **真实成本存活**：按 Round 35 B 口径（流动性分档滑点）F4 Q1 等权平均滑点 **31.7bp**
   （55.6% 交易落 40bp 档）→ 超额仍 **+7.9pp**（vs 15bp 口径 +11.9pp）——**不是成本假象**；
2. **非小市值马甲**：Q1 与市值代理（amount/turn，茅台核对量级正确）截面相关 +0.646；
   **控制（市值+Amihud21）后正交残差 IC 仍 −0.060**（n=114，显著）；Q1 按市值三分的子组
   年化 **+25.7/+17.0/+9.5% 全为正**；大市值段内低成交额 +8.4% vs 高成交额 −0.9%——
   **低成交额信号在控制市值后依然成立**；
3. **无幸存者污染**：Q1 已退市股占比 3.4%（低于池内全体 6.3%）；
4. **分位宽稳健**：Q1 换 10% 分位超额 +13.1pp、30% 分位 +10.4pp（20% 分位 +11.9pp）——非分位伪影；
5. **形态**：夏普 0.76、最大回撤 −57.7%（基准 −67.8%，相对 −11.4%）、周胜率 51%、单周最深 −9.7%。

**诚实的本质判断**：F4 与 Amihud 截面相关 −0.85、月度口径两者 IC 序列相关 −0.90，
经济机制同为"流动性溢价/冷门低估"——F4 大概率是 Amihud 的**短频实现**而非独立新 alpha；
但正交残差 IC 显著 + 控制市值后仍成立，说明它确实携带 Amihud21 之外的短频增量信息
（5 日均成交额 vs 21 日 Amihud 窗口不同）。**结论：有真实信号、非成本/市值假象，但不可
直接并入生产——须走组合验证守门（与 R22/R30 相同协议），验证它相对 R5 是否贡献增量。**

### 0.3 其他因子归因（诚实解读）

- **F1/F2 短反转：周频反转 Q1 反而大幅跑输（−12.6/−8.1pp）**——与月频反转（+0.8pp 超额、
  方向真实）形成**关键对照**：周频 + 全市场池下，Q1 极端超跌组是"接飞刀"（高换手 34 倍/年、
  极端负动量、ST 边缘），反转信号集中在 Q1 vs Q5 的相对差异，但**极端尾部整体跑输大盘**。
  **结论：短线反转"方向真实、幅度被尾部污染、成本致命"三重否定，不可交易**；
- **F3 低换手5：部分通过(3/4)**——IC 显著（−0.064, t=−9.4）、组序完美单调（−1.0）、
  三段 2/3 正（+5.6/+0.2），但超额仅 **+1.3pp**（<3pp 门槛），25bp 即转负；与 Amihud 无同源
  （−0.12）。方向真实但**量级不足以覆盖成本**——"低关注度"行为规律在主板全市场成立但偏弱；
- **F5 低波动21：未通过**——IC 显著但 Q1 超额 −0.9pp，方向与组合端背离（与月频低波动同病）；
- **F6 短动量5（方向对照）：高动量组 Q1 大幅跑输 −20pp**——确证**周频是反转不是延续**；
- **F7 换手突变：未通过**——换手率突降无边际优势，且高换手（34 倍/年）成本致命。

## 1. 背景与动机

- 现有生产策略 R5 等权575 是**月频** Amihud(0.85)×中期动量(0.15) 行业内百分位打分。
  用户提出探索**短线交易选股策略**（方向已确认：批量短因子筛选 / 周频 5 日 / 全市场非ST池）。
- 历史数据探测（2026-09-18，tmp 临时脚本，仅做 IC 粗探）：
  - 短反转 5/10 日 → 未来 5 日 RankIC **−0.042 / −0.050**（ICIR −4.3 / −5.2），显著但偏弱；
  - 低换手 5 日均 → 未来 5 日 IC **−0.087**（ICIR −7.2）；
  - 低成交额 5 日均 → 未来 5 日 IC **−0.097**（ICIR −8.9）——短线最强信号；
  - ⚠️ **同源风险**：低成交额因子与生产因子 Amihud21 截面相关 **−0.83**，疑似 Amihud 的"短频马甲"；
  - 涨停近似日（close 收益 ≥9.8%）后 1/5 日收益 ≈ +0.02%/+0.04%——追涨停无边际优势；
  - 成本现实：周频满仓轮换 ≈ **15.6pp/年**成本，日频 ≈ **73pp/年**（短线成本是生死线）。
- 本项目已测相关月频因子（均为"方向真实、成本致命"画像）：短期反转（未通过，8.4 换手吃光）、
  低换手（未通过，中大票池价值陷阱污染）、低波动（未通过）、两融变化（未通过，换手成本致命）。
  本轮换到**周频 + 全市场（主板含小盘）池**重测：短线信号在小盘更强，成本更致命——
  预注册即声明 **③可交易是最高门槛**。

## 3. 策略规则（定死）

### 3.1 股票池（每信号日 T，与生产 R5 同口径的"主板全市场"）
1. 截至 T 已有 ≥ 375 条日线（seasoning，同生产）；
2. T 日 `tradestatus == 1` 且 `isST == 0`；
3. T 日未涨停（前复权日收益 < 9.8%，买入端阻塞）；
4. 全市场池 = full_daily 全部主板（当前 2787 只，**含退市股 → 免幸存者偏差**）。
   （注：本数据无创业板/科创板/北交所——就是生产用的"全市场"定义。）

### 3.2 调仓频率与未来收益窗口（周频，5 日持有）
- **信号日 T**：每 5 个交易日取一个（对应当周最后交易日，覆盖全样本 2013-06 起）；
- **执行**：T+1 收盘买入（与生产"信号 T → 执行 T+1 收盘"口径一致，杜绝未来函数）；
- **持有**：5 个交易日，T+6 收盘卖出（完全轮换，无缓冲带——先测原始信号上限；
  若判定为"方向真实但成本致命"，改进方向另开预注册，不追改）。
- **未来收益口径**：`ret_5d = close(T+6)/close(T+1) − 1`（IC/分组用），
  组合净值按 T+1 买、T+6 卖逐期串联。

### 3.3 组合与基准
- 池内按因子 rank **等分 5 组**，多头 Q1 = 方向端 20%（F1-F5/F7 取最低组，F6 取最高组）；
- **基准** = 当期全部可交易股等权（同池等权，隔离选股贡献）；
- 全成本 **15bp/单边**（佣金万1.5+印花税万5卖出+过户费万0.1+滑点15bp，按权重变动计提）；
- Q1 另做 **25 / 35bp** 压测档（成本敏感度，短线尤其关键）。

### 3.4 回测区间与分段
- 首次调仓 2014-01 ~ 2026-09（数据 2013-06 起，预热 30 周）；
- 分段：2014-2017 / 2018-2021 / 2022-2026（沿用项目三段框架）。

## 4. 预注册判定标准（跑之前写死）

| 层 | 标准 |
|---|---|
| ① 显著性 | 周频截面 RankIC 均值方向符合假设 且 \|t\| ≥ 2（ICIR 与 IC 方向一致率作辅助） |
| ② 单调性 | Q1 为 5 组年化最高（或最低，按方向）且 Q5 为另一端（组序 Spearman ≥ 0.9 辅助） |
| ③ 可交易 | Q1 扣 **15bp** 年化超额（对同池等权）**≥ 3pp**；35bp 档超额仍 > 0 作附加读数 |
| ④ 稳定性 | 三段中 ≥ 2 段 Q1 超额 > 0 |

- 判定 = **通过(4/4) / 部分通过(3/4) / 未通过(≤2/4)**；失败协议：如实归档，禁止回头改因子/窗口/池口径重跑。
- **同源守卫**：F3/F4 与 Amihud21 截面相关 \|ρ\| > 0.6 时，必须另报**正交残差 IC**
  （对 Amihud21 回归取残差再算 IC）——若正交后不显著，判"**同源不新增 alpha**"，不进入组合验证；
  若显著，也须注明"与生产 Amihud 存在短频/长频共生，需组合验证守门（R22/R30 教训）"。

## 5. 诚实风险（预注册声明）

1. **成本是生死线**：周频满仓轮换 15.6pp/年成本起（日频 73pp 更无望）——③ 大概率是最难过线的层；
   即使 ①② 通过、③ 失败，本实验的**知识价值**是确认"周频反转/冷门效应在主板全市场的信号强度
   是否足以覆盖换手成本"——与月频反转结论（方向真实、成本致命）形成对照。
2. **同源伪装**：探测显示低成交额与 Amihud21 相关 −0.83——大概率只是生产因子的短频版；
   若因此 ③ 也过线，仍不构成新信息源（§4 同源守卫兜底）。
3. **价值陷阱污染**（月频低换手前科）：全市场池含大量长期阴跌、无人问津的主板小票，
   低换手/低成交额 Q1 可能买进"价值陷阱"而非"被错杀"——F3/F4 分组单调需特别警惕非线性的 U 型。
4. **池与成本口径**：full_daily 仅主板（无 300/688/bj），结论不推广到创业/科创；
   涨跌停仅用收盘近似（≥9.8%），未建模盘中触及——短线口径下比月频更粗糙，记录在案。
5. **衰减检查**：行为类信号近年衰减（周四效应、反转 2022- 前科）——④ 分段是必选项；
   若前段强后段弱，结论按"样本内衰减"如实归档。
6. **不改生产**：R5 冻结参数区（strategy.r5 / costs / accounts）零改动；本实验为独立探索轨道，
   即使全部通过也需另行组合验证 + 预注册才能触碰生产。
