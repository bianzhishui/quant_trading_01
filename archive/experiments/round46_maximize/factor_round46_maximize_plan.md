# Round 46 收益更大化扩散探索 —— 预注册计划 v1.0

日期：2026-09-22 ｜ 状态：**待批准** ｜ 基于：V1（2.3-3.2+质量+月频，验证段 16.0%/夏普0.78）

## 0. 目标与过拟合防线

**目标**：在 V1 基础上探索"收益更大化"（严格选股 / 价位变化 / 组合结构）。
**过拟合防线（预注册）**：
1. 候选变体**固定清单**（9 个，各有逻辑依据，非参数网格搜索）
2. 判定标准**预先定死**（验证段 2021-2026 为准，全样本参考）
3. **禁止结果后调参**；多个通过时取**最优一个**报告，其余如实归档
4. 若全部未通过 → 结论"V1 已接近局部最优"，**如实收尾不硬凑**

## 1. 候选变体（固定，全部在 V1 基础上单点改动）

| # | 变体 | 改动（vs V1 = 2.3-3.2+3年扣非+负债<70%+流动性+分红+等权+月频） |
|---|---|---|
| 0 | **V1 基准** | — |
| Q1 | 5年扣非 | 扣非年限 3→5 |
| Q2 | +ROE>5% | 加最新年报 ROE >5% |
| Q3 | +股息率≥2% | 加近3年股息率 ≥2% |

| P3 | 3.0-4.0元 | 区间上移更多（对照低价溢价边界） |
| C1 | 固定30只 | 通过者按最近年报扣非金额取 top30 等权 |
| C3 | 质量加权 | 权重 ∝ ROE×股息率（综合质量） |

统一：真实价口径、非ST、上市≥375天、月频 T+1、15bp/45bp、退市归零（敏感性最后价）、2014-2026。

## 2. 判定（预注册，验证段 2021-2026 主判）

| # | 标准 | 通过条件 |
|---|---|---|
| ① | 年化 > V1 | 收益更大化核心 |
| ② | 最大回撤 ≤ V1 + 3pp | 不显著恶化 |
| ③ | 夏普 ≥ V1 | 风险调整后更优 |
| ④ | 45bp 超额 vs 全市场 ≥ +3pp | 可交易 |
| ⑤ | 分段（2014-17/18-21/22-26）全正 | 稳定性 |

**判定**：①-⑤ 全过 = 通过（收益更大化成立）；取**最优通过者**为候选；
0 个通过 = V1 已近局部最优，收尾；多通过取最优，其余归档。
**附加**：报告各变体全样本年化/回撤（参考，不判定）。

## 3. 诚实风险
1. 收益更大化探索天然有过拟合引力——预注册 9 变体 + 固定判定 + 验证段主判 = 防线
2. 变体间高度相关（都源自 V1），改进幅度可能边际递减
3. 更严条件（Q1/Q2/Q3）可能压缩样本（持仓<30 时标注）
4. 沿用已知局限（涨跌停未建模等）

### 诚实结论
1. **价位上移是收益更大化的主旋律**：2.3-3.2 → 3.0-4.0，验证段 16.0% → 18.6%（+2.6pp）、
   夏普 0.78 → 0.93——低价带内"越高越好"（2.3 元以下雷区剔除后，接近 4 元质量更佳）。
2. **ROE>5% 门槛是回撤最优解**（-22.8%，比 V1 低 2.6pp）且收益 18.3%——质量严选降波动有效。
3. **边际递减**：P3 vs V1 仅 +2.6pp（vs R44 区间上移的 +4pp）——收益更大化空间在收窄，
   过拟合引力上升；P3/Q2 是在预注册 9 变体防线内的最优，**组合 P3+ROE 等新组合
   超出本清单，需新预注册**（如实声明，不越界试）。
4. **全样本对照**：P3 全样本 20.5%/-46% 略低于 V1（24.7%/-45%），验证段更优——P3 优势
   集中在近年（2022-26 +13.1% 段）；早期（2014-17）3-4 元不及 2-3 元。
5. 局限：Q2 持仓仅 19 只（分散度下降）；P3 持仓 61 只（分散好）；沿用已知局限。
