**⚠️ 判据设计缺陷（记录）**：程序按"≥4/5"字面判为"升级候选"，但 ① 超额是**核心门禁**
（其余 4 项是约束）——① 崩塌即实质否决。**本结论以 ① 为准：不并入**。

**根因（与 Round 22 价格水平同构）**：股东户数 IC 弱（−0.02），等权给 1/3 权重，

**最终结论：股东户数降级为"单因子参考"（不并入 R5）**。若要利用，需"小权重补充"设计
（如 Amihud 0.7 + 动量 0.15 + 股东户数 0.15）——但那是权重调参（过拟合风险），
当前**无计划**；R5 保持 0.85/0.15 不变。

## 1. 背景

候选池梯队三最可行因子：**股东户数变化（筹码集中度）**——股东户数持续下降 =
筹码从散户集中到机构（机构悄悄吸筹），未来上涨概率高。机制与 Amihud（冷门低流动性）
**天然互补**：既冷门又筹码集中 = "价值发现前夜"。

数据可行性已探测：`akshare.stock_zh_a_gdhs(报告期)` 按报告期批量返回全市场
（2013-03 ~ 2026-06 完整，含**股东户数-本次/增减比例/公告日期/统计截止日**）——
约 54 次调用即可覆盖全历史，分钟级。

## 2. 因子定义（定死）

- **数据**：`stock_zh_a_gdhs(报告期)`，历次季度报告期（2013-03-31 ~ 2026-06-30，~54 期）；
- **因子值**：月末 T 取该股**最近一次已公告**（`公告日期` ≤ T）的 **`股东户数-增减比例`（环比%）**；
  无公告 → 该股本月无因子值（dropna）；
- **方向**：−1（增减比例为**负** = 户数减少 = 筹码集中 → 看多）；
- **池/回测**：与 R5 同（`build_pool` 全市场），月频，141 期，15bp/35bp 双成本，同池等权基准。

## 3. 判定（定死，沿用四层）

- **① IC**：方向对 且 `|RankIC均值| ≥ 0.03` 且 `|t| ≥ 2`
- **② 分组单调**：五分组（扣 15bp）多头组年化最高 且 空头组最低
- **③ 超额**：多头扣 15bp 年化 − 同池等权 ≥ **+1pp**
- **④ 分段**：ERAS 三段 ≥2 段超额为正
- 4 通过 / 3 部分通过 / 否则未通过；有效截面 <60% 期数 → 数据不足不判
- **附加**：与 Amihud/中期动量截面相关（<0.3 才有组合补充价值）

**组合验证（若单因子通过）**：R5 打分加第 3 因子 vs 现 R5（Round 22 方法），
持仓 Jaccard + 超额对比——单因子通过 ≠ 可并入（Round 22/28 教训）。

## 4. 诚实风险（预先声明）

1. **披露频率低（季度）**：股东户数每季度披露，因子值更新慢、有滞后性——月末截面
   用"最近公告"，信息新鲜度弱于日频因子；
2. **与 Amihud 冷门可能相关**：户数少 = 关注度低，可能与 Amihud（低流动性冷门）高度
   重叠——相关矩阵会揭示（若相关 >0.3，组合补充价值存疑）；
3. **2013 早期覆盖**：2013-2014 报告期数据完整性需验证（早期股东户数披露规则不同）；
4. **公告日准确性**：用公告日期字段避免未来函数，但需处理盘后公告/修正；
5. 判定通过 ≠ 立即入策略（组合验证通过后才考虑）。
