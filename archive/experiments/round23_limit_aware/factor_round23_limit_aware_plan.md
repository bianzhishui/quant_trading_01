## 1. 背景

R5 主引擎执行端当前**不建模涨跌停阻塞**（`rebalance` 只挡停牌，假设非停牌股按收盘价全成交），
Round 8 专项评估阻塞损失仅 0.18pp。用户决定：**把阻塞内置建模（S3-跟随 语义），并制定实盘
执行 SOP**，使回测-实盘在"涨停买不进/跌停卖不出"上口径一致。

## 2. 阻塞建模规则（定死，S3-跟随）

**执行日 T+1 收盘撮合时**（引擎口径，`LIMIT_THR = 0.098`）：

| 端 | 规则 |
|---|---|
| 买入端 | 目标股当日 `pct_change ≥ +9.8%`（涨停）→ **买不进**（跳过该股，钱留现金） |
| 卖出端 | 需卖出的持仓股当日 `pct_change ≤ −9.8%`（跌停）→ **卖不出**（保留持仓） |
| 递延 | **S3-跟随**：未成交现金/持仓自然进入下月调仓再平衡；下月该股仍在目标且已开板 → 正常买；已跌出目标 → 不买（跟随最新信号，不强制补买） |
| 成交价 | 仍按收盘价 + 滑点模型（阻塞只影响"能否成交"，不影响价格） |

**实现方式**：Round 23 脚本**复制** `rebalance` 逻辑加阻塞判定（**不动生产引擎**），
对比 A=现状 / B=S3-跟随 两臂，300万 share 级全口径，141 期。生产引擎是否并入阻塞，
**待本轮结论后另行决策**（默认不动，除非用户要求）。

## 4. 实盘执行 SOP（草案，入运营手册 §8）

| 实盘情况 | 动作 |
|---|---|
| 目标股**涨停**买不进 | 不追（排队成功率极低）→ 不买，钱留现金，下月调仓再平衡 |
| 持仓股**跌停**卖不出 | 挂跌停价单排队（开板可能成交）→ 当日不成交则保留持仓，下月再卖 |
| 持仓股涨停/目标股跌停 | 无特殊动作（持有/正常买入） |
| 与回测对齐 | SOP 与 S3-跟随 语义一致 → 回测-实盘偏差最小化 |

## 5. 诚实风险（预先声明）

4. 不改 R5 选股/打分/参数；生产引擎不动（④ 保障）。
