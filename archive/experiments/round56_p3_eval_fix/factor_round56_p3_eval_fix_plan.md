## §1 问题：一个**已知且已量化**的口径缺陷

**R48 已确立的正确口径**（生产已落地）：持仓估值必须用**前向填充价**，成交必须用**原始价**。

- 根因：`PaperPortfolio.value(prices)` 对**价格为 NaN 的持仓按市值 0 计**——停牌 → 净值凭空跌一截；
  退市 → 永久归零。
- 生产路径（`scripts/p3/paper_live_p3.py`：`init_ledger` / `step` / `mark` / `report`，8 处）
  **已全部接入** `eval_prices(raw) = raw.ffill()`：`pf.value(raw_e...)` 估值、`pf.rebalance(..., raw...)` 成交、
  `report` 用 `eval_prices` ✓。合规。
- **缺陷**：研究回放路径 `scripts/p3/scenario_ytd_p3.py` **从未接入**——`run_scenario_p3` 全程
  用 `prices = raw.iloc[i]` 同时做**估值**（`pre_nav`/`post_nav`/每日 `pf.value`）与**成交**。

**后果（R53 §0.1 已量化）**：全样本窗口（2014-02-10→2026-09-28）份额级结果**不可能**：
份额级回撤 −93%~−95%、**累计费用 117-165% 本金**，而同窗等权 P0 回撤仅 −45.54%。
机制自洽：NaN 估值 → 持仓市值归零 → 触发卖出/再平衡 → 换手与费用爆炸 → 净值死亡螺旋。
**该窗口已作废，且此后任何长样本份额级结论都不可信** → 本轮修复它。

## §2 改动（规则定死，最小化）

**唯一改动对象**：`scripts/p3/scenario_ytd_p3.py` 的 `run_scenario_p3`。

在函数内新增一次 `raw_e = raw.ffill()`，并把**估值**三处切到 `raw_e`：

| 位置 | 现在 | 改为 |
|---|---|---|
| 调仓前 `pre_nav` | `pf.value(prices)`（raw） | `pf.value(raw_e.iloc[i])` |
| 调仓后 `post_nav` | `pf.value(prices)`（raw） | `pf.value(raw_e.iloc[i])` |
| 每日净值 `navs.append(...)` | `pf.value(prices)`（raw） | `pf.value(raw_e.iloc[i])` |

**保持不变（成交口径）**：
- `prices = raw.iloc[i]` 仍用于 `pf.rebalance(target, prices, trad_row, ret_row)`（成交价、1 手取整）、
  `pf.corp_action_f(...)`（除权补缺）、`n_1lot_short` 的"1 手买不起"判断（必须用真实成交价）。

**禁止改动的部分**：`PaperPortfolio`（引擎）、`build_sets`、`config/*.yaml`、`block` 默认值、
`slip` 默认 15bp、CSV 列名列序、`target_fn`/`detail`/`low_vol_keep` 既有语义。
**生产账本不需要重建**（生产早已用 `eval_prices`）——这点由 §3-V4 验证。

### §0.2 根因（已定位到代码行）：**`真实价` 构造 bug**

`scripts/factor_round41_low_price.py:84`：

```python
fac_ser = s.reindex(close.index).ffill().fillna(1.0)  # ← bug
```

`close.index` 是 `cfg.r5.start = 2013-06-01` 起的交易日索引。**因子表的记录日先被 reindex 丢掉，
之后才 ffill** → 索引起点之前的因子记录无法向前填充 → **因子回落为 1.0** → `real = close`
（前复权价，**不是**真实价），直到该股**窗口内**第一条因子记录出现才切换。

**实测证据**（`tmp/r56_diag2.py`，2014-06-17）：

| 标的 | `close`(前复权) 收益 | `raw`(真实价) 收益 | 同日两价 |
|---|---|---|---|
| `sh.601199` | −0.44% | **+386.26%** | 3.21 vs **15.69** |
| `sh.601377` | −1.81% | **+169.48%** | 2.97 vs **8.16** |
| `sh.600438` | −2.80% | **+142.51%** | 3.62 vs 9.04 |
| `sz.002107`（2014-08-21 切换日） | +0.57% | **+334.72%** | 3.66 vs **15.81** |

切换日恰为该股窗口内首条因子记录日（如 601377 = 2014-06-17、002107 = 2014-08-21）；
2014 年池内等权累计：`close` 口径 **+102.7%** vs `raw` 口径 **+631.4%**（差 +528.8pp）。
**+169%~+386% 的单日"收益"远超 ±10% 涨跌停 → 不可能是真行情，是数据口径突变。**

**传导链**：份额级回放用这个面板**成交与估值** → 2014 幻影 +491.56%（等权 +89.00%）、
2015 年内回撤 −62.90%（等权 −10.67%）、全样本 DD −75.93%（等权 −45.54%）。
等权口径用 `close` 收益所以**收益序列本身不受影响**，但它与本轮同样使用被污染的 `real` 做**入池筛选**。

| 年份 | 份额级 | 等权 | 差 |

**入池污染量化**（近似口径：以 `close` ∈[3,4) 模拟池；`first[code]` = 该股因子表首条记录日）：
2014-2015 共 24 个信号月，每月池内"因子未生效"标的占比 **4.0%~17.1%**（早期 10-15%），
**合计 430 个标的人次**。因子表 3123 只中 **1563 只首条记录晚于 2014-01-01** → 该 bug 对
2013-06 起点后的早期年份影响面较大。

**受影响的既往结论（必须加注）**：
- R41-R47 的 **P3 全样本（2014-2026 年化 +20.5%）与分年代 2014-17（+44.5%）**、R51 的
  **2014-17（+48.1% vs +44.5%）**、R55 §0.3/R51 的**三段 2014-17 数字** → 入池成员被污染，

  R51/R53/R54/R55 的**主窗口结论与生产采纳（A1 = 0.70）依然成立**。

### §0.4 我自己的判据设计错误（如实记录，不修改判据）

**V3b「累计费用 ≤15% 本金」是错误判据**：`Σ费用/初始本金` 是**随持有期与复利增长的量**，
不是缺陷特征。粗算：若费率 ≈1.3%/年（按 NAV 计），在 ~25% 年化复利下
`Σ_t NAV_t/初始 ≈ 75` → 期望累计费用 ≈ **98%**，实测 133% 同量级 ✓。
→ **R53 把"累计费用 117-165%"当作缺陷特征也是错的**（同一算术原因）；R53 真正的红旗是
**回撤 −93~−95%**（本轮修复后降到 −75.9%，但仍不合理）。
