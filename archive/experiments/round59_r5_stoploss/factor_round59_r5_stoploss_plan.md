# Round 59 R5 个股止损叠加 —— 预注册计划 v1.0

> 状态：**已预注册 2026-10-03 / 实施中**（判定标准跑前写死，跑后不得回头改阈值或加档位）
> 问题（用户原话）：*针对当前 R5 策略，增加止损阈值（无论到哪一天达到止损位都卖出，
> 卖出资金等下个月调仓用），能不影响收益的情况下降低回撤吗？*
> 代码：`archive/experiments/round59_r5_stoploss/factor_round59_r5_stoploss.py` ｜ 输出：`output/factor_round59_*.csv`

---

## 1. 假设

- **H1（止损截断左尾）**：个股在持仓期内跌到 −thr 就卖掉，能截断继续下跌的尾部，
  从而降低组合最大回撤。
- **H0（回撤是市场级 beta）**：R5 的最大回撤主要来自市场级普跌。此点已被
  **R4a 实测**：把合成分最极端档剔除后回撤几乎没变（−52.5% vs −53.9%，改善仅 1.4pp），
  且最大回撤区间两臂完全相同（2015-06-12 ~ 09-15 股灾）→ *"−54% 回撤是市场级 beta 造成的，
  不是持仓中个别冷门股的踩踏"*。若 H0 成立，个股止损在普跌日会**同时**清掉全部持仓，
  等价于一个**被动触发的熔断**，而不是"个股风控"。

对照先例 —— **R4b 回撤熔断实测**（同一 R5 主体，风控层唯一改动）：

| 臂 | 超额15bp | 夏普 | 最大回撤 |
|---|---|---|---|
| C 基线 | +9.8% | 0.91 | −53.9% |
| R4b（回撤熔断） | **+5.7%** | 0.98 | **−41.4%** |

R4b 结论：*"对急跌有效（2015 段 −53.9% → −27.3%），对阴跌完全失效
（2018 段 −31.4% → −41.1%，反成新低）"*，代价 **4.1pp/年 超额换 12.5pp 回撤**，
最终**不设为默认**。本轮止损是同一"风控层"思路的**个股化版本**，因此这个先例
既是机制参考，也是"收益代价"的预期锚。

## 2. 口径（除止损层外与 R5 生产完全一致，零改动）

| 项 | 值 |
|---|---|
| 池 | `build_pool`：seasoning 375 交易日、非 ST、非创业/科创/北交、T 日未涨停 |
| 因子 | Amihud 21d×1e6 · 中期动量 21/250 · F4 5 日均成交额（**冻结**） |
| 打分 | 行业内百分位，权重 **Amihud 0.40 : 动量 0.10 : F4 0.50**（冻结，Round 38 采纳） |
| 组合 | 合成分前 1/5（≈575 只）等权，月频调仓 |
| 执行 | 信号 = 月末 T 收盘 → 执行 = **T+1 收盘** |
| 收益 | 前复权 close 的 pct_change；停牌 NaN = 0（价格延续） |
| 成本 | **15bp / 单边**（含止损卖出、调仓买卖），现金收益 0 |
| 基准 | **同池等权 + 15bp**（与 R5 各轮一致） |
| 研究口径 | **ew_nav 等权权重模型**（无 1 手约束、无涨跌停阻塞、无分红税、权重不漂移） |

> 研究口径说明：ew_nav 是 R5 全部因子轮的**标准筛选口径**（R3/R4/R5/R26-R28/R38 均用它
> 做第一层判断），份额级（`paper_trade.replay_w`）只在 Z 判据通过后才做复核。
> 止损触发用**前复权**累计收益计算，避免除权造成假触发（R56/R57 在 P3 侧踩过
> "真实价 vs 复权价"口径坑，R5 侧用 `close.pct_change()` 无此问题）。

## 3. 规则（定死）

**唯一改动 = 止损层**；选股、打分、权重、调仓时点、成本全部沿用 R5 生产口径。

| 项 | 定义 |
|---|---|
| 成本基准 | 该股**本次调仓执行日收盘价**（前复权） |
| 触发 | 持仓期内任一交易日**收盘**，累计收益 ≤ **−thr** |
| 执行 | **次一交易日收盘卖出**（T+1，与 R5"执行 = T+1 收盘"一致；**不是**当日收盘） |
| 卖出后 | 该仓位转现金（收益 0），**等下个调仓日**按原规则重新配置 |
| 再买入 | 若该股下月仍在目标集合中，正常买回（不豁免），成本照计 |
| 调仓日 | 调仓日不做止损判定（调仓优先），持仓期从执行日次一日起算 |
| thr | 主扫描 **{10%, 15%, 20%, 25%, 30%, 40%}**（6 档，一次性跑完） |
| thr = ∞ | **基线臂**（无止损），用于逐位自检 |

## 4. 预注册判定标准（全部 vs 基线臂，15bp 口径）

| 判据 | 标准 | 含义 |
|---|---|---|
| **Z1 回撤改善** | maxDD(止损) ≤ maxDD(基线) + 5pp（即改善 ≥ 5pp） | 主目标 |
| **Z2 收益不损** | 年化(止损) ≥ 年化(基线) − **1.0pp** | 直接量化用户的"不影响收益" |
| Z3 稳健 | 三段超额（2014-2017 / 2018-2021 / 2022-2026）**全为正** | 非单段侥幸 |
| Z4 高原 | 相邻 thr 的**回撤改善差 ≤ 3pp**（非尖峰） | 防数据挖掘 |
| Z5 成本可控 | 年换手 ≤ 基线 × **1.5** | 成本不失控 |

**判定规则（跑前写死）**：

- **Z1 + Z2 全过 → 通过**，即"能在不影响收益的前提下降低回撤" = **成立**；
- Z1 过 / Z2 不过 → **"以降收益为代价降回撤"**（如实写明代价 pp）；
- Z1 不过 → **止损降不了 R5 回撤**；
- Z4 不过 → 该阈值点的通过**不采纳**（视为数据挖掘产物），只看高原区间。

**补充诊断（不参与判定，仅解释机制）**：
止损后到下次调仓日的**反事实收益**（若为正 = 卖错了/踏空反弹；为负 = 躲对了）、
平均现金仓位、年触发次数、平均触发阈值分布。

## 6. 诚实风险与预期（预注册，跑前写下）

1. **我预期 Z2 不过（押"降回撤但损收益"）**，理由四条：
   - ① R4a 已证 R5 回撤是市场级 beta → 个股止损在普跌中 ≈ 全组合同时清仓 = 被动熔断，
     而 R4b 实测该机制代价 4.1pp/年；
   - ② R5 池是小盘高波动股，−15/−20% 触发极频繁 → 大量**噪声触发**，且 T+1 执行
     意味着卖在坑里再吃一天跌；
   - ③ **A 股月频短反转**（R39 C4：短动量 5/21 高动量组 **−10.5%**，即"近期跌的下月倾向反弹"）
     → 卖出近期下跌股，方向与短反转**相反**，主动损失 alpha；
   - ④ 换手放大直接吃 15bp × 双边成本。
2. **Z1 有可能过**：2015/2018 型急跌中全组合触发止损确实能把回撤压浅（与 R4b 同机制），
   但 Z3（三段为正）与 Z5（换手）会同时暴露代价。
3. **局限（本轮范围）**：无 1 手约束、无涨跌停/停牌阻塞、无分红税、权重不漂移、
   止损按**收盘判定**（非盘中触及阈值）→ 结果偏乐观（真实盘可能更差）；
   若 Z 判据通过，才做份额级复核（`paper_trade.replay_w`）。
4. **防挖掘纪律**：6 档阈值**一次性跑完**；跑完**不得回头加档位、改判定标准、按最好看的点下结论**；
   Z4 高原是硬判据。

### 0.2 机制诊断（本轮最有价值的部分）

1. **止损系统性卖在坑底**：止损卖出后到下次调仓日的**反事实收益均值 +2.6% ~ +13.4%**；
   **扣掉同池基准同期收益后仍为正（+1.0pp ~ +5.7pp）**，躲对占比仅 **24% ~ 42%**。
   即被止损的股票在卖出后**跑赢同池** —— 卖出方向与 A 股月频短反转相反，
   与 R39 C4 的记录（短动量 5/21 高动量组 −10.5%，即"近期跌的下月倾向反弹"）一致。
2. **触发率极高（噪声触发）**：thr=10% 下 **1,119 次/年**，≈ 每只持仓每年触发 1.9 次
   —— 小盘高波动池里 −10%/−15% 基本是噪声级别，止损变成了随机换手。
3. **回撤降不动，因为它是市场级 beta**：分年最大回撤显示 2018 年**完全没变**（−34.2%），
   2024 年在 thr=10/15% **反而更深**（−36.2% / −35.7%）；只有 2015/2016 在激进阈值下改善
   （−52.6% → −48.5%；−25.1% → −13.8%）。这与 **R4b 的"急跌有效、阴跌失效"** 完全同源，
   也再次印证 R4a 的结论（回撤主因是市场级普跌，个股层动不了）。
4. **代价集中在近期**：2022-2026 段超额随阈值收紧从 **+13.6% 掉到 +2.0%**（−11.6pp）。

### 0.3 自检

- **自检① ✅**：`simulate(thr=None)` vs 生产 `ew_nav` 最大绝对差 **3.553e-15**（浮点舍入级，数值等价）。
- **自检② ✅**：调仓次数 **141**、首执行 **2015-01-05**，与运营手册 §1 记载逐项一致。
- **自检③ ❌ 判据作废（设计错误，如实记录）**：预注册引用的 Round 38 锚点
  （全区间 +10.40% / 训练 +9.80% / 验证 +12.62%）取自 R38 的 **159 期研究面板**，
  而本轮是生产 **141 期**面板（`r5.start=2013-06-01` 预热窗口），**周期不可比**。
  量级核对（不作判据）：w\*(0.40/0.10/0.50) 141 期 +10.87% vs 159 期 +10.40%；
  A(0.85/0.15/0) 141 期 +8.36% vs 159 期 +8.03% —— 两者同向偏高 0.3~0.5pp，
  差异可由面板期数解释，且**相对序（w\* > A）保持**，非管线 bug。
  **教训：预注册引用其他轮次的锚点，必须先核对该轮的面板期数与起止日。**

### 0.4 诚实局限

1. 研究口径（ew_nav）无 1 手约束、无涨跌停/停牌阻塞、无分红税、权重不漂移，
   止损按**收盘判定**（非盘中触及阈值）→ 真实盘只会**更差**（方向性结论不依赖这些细节）。
2. **绝对回撤数字（−52.6%）不可当承受力依据**（R58 教训：权威口径是份额级）。
3. 只测了用户指定的这一种形态（固定阈值 + 卖出后持现金到下月调仓）；
   **未测**：移动止损/回撤止损、波动率自适应阈值、止损后立即补票（不等下月）、
   止损与调仓解耦。若要试，属新的一轮（须另开预注册）。
4. 6 档阈值一次性跑完、未回头加档、未按最好看的点下结论（符合 §6.4 防挖掘纪律）。

### 0.5 对用户问题的最终回答

**不能。** 给当前 R5 加个股止损（卖出资金等下月调仓用）**无法在不影响收益的前提下降低回撤**：

- 想压回撤，阈值必须收到 **10%**：回撤才改善 **4.1pp**（连 5pp 判据都不到），
  代价是收益 **−5.18pp/年**、换手 ×1.41、费用 1.21% → 1.71%/年；
- 阈值放宽到 **20% 以上**：回撤**反而更深 2.0~6.0pp**，收益同时仍降 0.4~2.2pp/年；
- 机制清楚：R5 超额来自小盘冷门股，止损卖掉的正是"近期跌"的票，而这类票在 A 股
  月频上倾向反弹 → 止损系统性卖在坑底（反事实超额 +1.0~5.7pp），再叠加换手成本；
- 与既有证据链一致：**R4a**（回撤是市场级 beta，选股层动不了）+ **R4b**（熔断急跌有效/
  阴跌失效，代价 4.1pp/年）+ **风控五轮收束**（压不住回撤且牺牲超额）。
