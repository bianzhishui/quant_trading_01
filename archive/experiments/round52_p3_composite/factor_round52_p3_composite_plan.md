# Round 52 预注册：P3 池内多因子合成打分（低波 × 低PB × 低MAX）

状态：**✅ 已实施（2026-09-29）｜5 个合成变体全部未达标**（绑定判据：不劣于 A1）｜对象：P3 低价股策略｜基准：P3 现冻结参数（P0）

## §1 问题

R51 证明 **A1 低波60 是唯一通过预注册判据的变体**（回撤 −25.0%→−21.6%、年化 +18.2%→+19.8%、
夏普 0.91→1.03），并超过 X0 集中度对照；同时 B1 低PB（年化 +1.9pp、夏普 +0.099）与
A3 低MAX20（年化 +20.1%、全样本 +23.1%）各自只差一丝或只缺一个维度。

本轮问**新问题**：把 R51 中最优/近失因子做**池内百分位等权合成**后取前 N%，
能否**同时**（a）超过 P0 的收益与回撤，（b）**超过单因子 A1**？——即"合成"是否比"单因子低波"更强。

**P3 至今没有任何打分/排序机制**（只有过滤 + 全取等权），本轮首次引入池内打分。

### §1.1 探查（只读，2026-09-29；131 个有效信号期的池内平均秩相关）

- **低波与低IVOL 秩相关 0.917 → 在 P3 池内实质是同一因子**（该池对中证1000 的 R² 仅约 0.18），
  因此"低波+低IVOL"合成预期≈低波单因子，合成增量只能来自**独立性更高的低PB（0.26-0.31）**
  与部分独立的低MAX（0.57-0.58）
- 非对角平均秩相关 0.474 → 合成空间存在但有限

## §2 变体定义（规则定死，不试参）

**基底**：`build_sets(data, None, sub_price=(3.0,4.0), n_years=3)` → 各信号日 T 的 P3 合格池 B[T]；
信号月末 T 收盘 → T+1 收盘执行；窗口 2014-01 起；成本 15/45/60bp；全部因子用 T 及之前数据。

**合成规则（冻结）**：
1. 池内对每个因子取**百分位排名**（0–1，**越大越好**，方向已统一为"低值优先"）；
2. **等权平均**（不设差异化权重，避免权重过拟合）；
3. 缺失值记最差（百分位 0）；
4. 按合成分降序取**前 KEEP 比例**（默认 70%，与 R51 截断口径一致）；
5. 选中者**等权**持有（权重方式不变）。

| 编号 | 定义 | 说明 |
|---|---|---|
| Z0 | P0 基准（3.0-4.0 等权月频，无截断） | 自校验：须复现 +18.2%/0.91/−25.0% |
| **Z1** | **低波60 + 低PB（2 因子）取 70%** | 最优先验（两维度独立） |
| Z2 | 低波60 + 低IVOL60 + 低PB（3 因子）取 70% | 原提案；预期≈Z1（vol/ivol 相关 0.917） |
| Z3 | 低波60 + 低MAX20 + 低PB（3 因子）取 70% | 用 MAX 补收益维度 |
| Z4 | 低波60 + 低IVOL60 + 低MAX20 + 低PB（4 因子）取 70% | 全上 |
| Z5 | Z1 取 **50%**（≈30 只） | 集中度敏感度（只作参考，不作采纳） |
| A1 | 低波60 单因子取 70%（R51 通过者） | **必须超越的门槛** |
| X0 | 中性截断取 70%（按 code 序） | 集中度对照 |

## §3 判定标准（预注册）

**主判对象 = Z1**（最优先验）；Z2-Z4 用同一判据，若多个通过则取"相对 A1 更优"者。

通过需**全部满足**：

1. 验证段（2021-2026）最大回撤改善 **≥ 3pp**（相对 P0）
2. 年化 ≥ P0 + 2pp **或** 夏普 ≥ P0 + 0.10
3. 45bp 年化 ≥ P0₄₅
4. **不劣于单因子 A1**：年化 ≥ A1 − 0.5pp **且** 回撤不深于 A1 1pp 以上
5. 分年度 ≥ 半数年份不差于 P0
6. 若改善幅度 ≤ X0 的改善幅度 → 判"不可区分于纯集中度效应"，不采纳

Z5 额外要求：报告持仓数，若近年持仓 < 30 只则直接判失败（分散度下限）。
统一直报：60bp 极端成本、Calmar、月均/近年持仓、三段（2014-17/2018-21/2022-26）年化与回撤。

## §5 诚实风险（预注册时已知）

1. **vol/ivol 相关 0.917** → Z2/Z4 很可能≈Z1，合成的真实增量可能只来自 PB 一个维度
   （即"低波+低PB"的两因子效果可能被 PB 单因子部分解释——但 R51 的 B1 低PB 单因子未达标，
   说明 PB 单独不够、低波单独够，两者合成仍需实测）
2. **A1 的近年依赖会传导**：R51 显示低波增益集中在 2022-26、2014-17 跑输 1.7pp/年
   （2015 单年差 26pp）；合成版大概率继承该特征
3. **首次引入打分机制** = 策略复杂度与过拟合面上升：百分位、等权、70% 均为固定选择，
   但仍是为同一 2014-2026 样本第 12 轮挖掘
4. **持仓数下降**（61→43，近年 51→36）：单票风险上升，小账户 1 手退化加重；50% 档（Z5）
   持仓≈30 只接近下限
5. **PB 的价值陷阱**：破净股常伴基本面瑕疵（P3 已有扣非为正+低负债部分缓解）
6. **合成可能两头不到**：低波提"稳定性"、低PB提"估值修复"，但两者可能在不同年份兑现，
   导致回撤或收益被中和

### 核心结论：**多因子合成不优于单因子低波（A1）**

- 合成**确实抬高了收益**：Z4 年化 +20.2%（A1 +19.8%，+0.4pp）、夏普 1.04（A1 1.03）；
  Z2/Z4 的 45bp 年化 +17.4% 也为全场最高
- **但回撤同时恶化**：Z1-Z4 回撤 −23.1~−23.4%，比 A1 的 −21.6% **深 1.5-1.8pp**；
  Calmar 0.85-0.87 全面低于 A1 的 0.92
- 即：**合成的净效应是"用回撤换一点收益"**，方向与用户目标（提收益+降回撤）相反；
  A1 仍是风险调整最优（也仍是全样本最优 +22.2%）
- **与 §1.1 探查预测一致**：vol/ivol 相关 0.917（Z2≈Z1 已实测：19.9% vs 20.1%），
  合成增量只来自低PB；而低PB 自身的回撤表现（B1 −24.6%）不如低波（A1 −21.6%），
  混入后稀释了低波的降回撤红利
- **50% 档（Z5）给出一个有趣但不可用的点**：回撤 **−19.3%**（比 P0 改善 **5.7pp**，全场最佳）、
  Calmar 0.96，但年化仅 +18.5%（+0.3pp）、45bp 与 P0 持平（+0.0pp）、持仓掉到 **26 只**
  （低于 §3 的 30 只分散度下限）→ 与其说"降回撤"，不如说"降低风险暴露、同比例压低收益"

### §0.1 确定性修正记录（与 R51 §0.1 同源）

- 池 `B[T]` 是 `set`，迭代顺序由 `PYTHONHASHSEED` 决定；百分位排序遇平局（NaN 记 0 后并列）
  会被稳定排序继承为哈希顺序 → 跨进程抖动。**本脚本从一开始就用 `sorted(S)` +
  `kind="stable"`**，故 Z1-Z5 数值可复现。
- 该缺陷由本轮排查 R51 与 R52 的 A1 全样本差异（+22.2% vs +20.9%）时发现：
  R51 归档 `rank_keep` 已打补丁（`reindex(sorted(S))`）并重跑，其 §0 分段/分年度与
  "牛市跑输"判断已更正（详见 R51 plan §0.1，含撤回声明）。
- 教训（已记入两轮 plan）：**任何对 set 排序/截断的因子选择必须先 `sorted()` 固定输入顺序**；
  验证段指标在本样本中稳定，但全样本年化可被平局影响达 ~1.3pp。

### 结论与代价（诚实）

1. **本轮回答"合成是否强于单因子低波"= 否**（判据④对 5 个合成变体全部不通过）；
   首次引入池内打分机制的净增量是**负的**（回撤恶化 > 收益改善）
2. **收益端与降回撤端在 P3 池内是此消彼长**：R50（现金流质量/双周频）与 R51（PB/PE/换手/
   MAX/应计）已证；本轮进一步证明**连"最优单因子 + 独立估值维度"的合成也无法同时改善两者**
3. **A1 低波60 仍然是唯一可用候选**（单因子、无需合成、Calmar 最高），是否落地生产仍须另行批准
4. **代价**：8 变体 × 2 次全量回测（含确定性重跑，232s×2）+ 4 次诊断/复跑；0 次生产改动、
   0 次账本改动
5. **局限**：等权百分位、70%/50% 保留比例均为固定选择（未试 IC 加权、未试分因子差异化权重，
   以免过拟合）；同一 2014-2026 样本第 12 轮挖掘；Z5 的低回撤可能部分来自"持仓更少=暴露更低"，
   不能当作降回撤能力
6. **生产采纳**：本轮无任何可采纳项；A1 的采纳路径仍待用户批准（见 R51 §0 第 7 条）
