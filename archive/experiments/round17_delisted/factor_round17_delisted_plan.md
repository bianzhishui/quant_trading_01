# Round 17 退市股纳入 · 幸存者偏差修正（预注册）

> 状态：**已实施（2026-09-08），结果归档见 §0** ｜ v1.0 ｜ 2026-09-08
> 动机：当前 `full_daily.parquet` 宇宙 = "抓取时点(2026-09)在市"的 3194 只——**2014-2026
> 回测期间退市的股票全部缺席**（退市=典型输家），回测收益可能高估。Round 7 的 1.1pp
> 偏差估计对比的两个池都含同样的"在市"过滤，未单独量出退市偏差。本实验纳入退市股，
> 量化真实幸存者偏差，检验策略结论稳健性。

## 规则（定死，实施前不再改动）

### 数据宇宙
- 代码清单来源：`data/fundamental/stock_basic.parquet`（baostock 权威），
  过滤 `type=="1"` + 前缀 `sh.60/sz.00`，**status 不限（在市+退市都收）**；
- 宇宙规模：3,194 在市 + 主板退市股（stock_basic 共 337 只退市，含全部板块，
  主板子集以实际清单为准）；
- 退市股数据：baostock 保留其上市至退市日全部历史，`fetch_one` 无需改动。

### 存储（基建，随本轮一并落地）
- `full_daily.parquet` 单文件 → **`full_daily/` 按年分区**（`2012.parquet`…`2026.parquet`）；
- 数值列 **float64**、压缩 **snappy**（用户指定）、`index=False`（去除垃圾索引列）、原子写；
- 退市元数据：`stock_basic.parquet`（含 outDate）升级为正式数据源。

### 引擎退市语义（核心规则，方案 A——用户已批准）
- **强制清仓**：持仓股到达其 `outDate`（退市日）时，以**退市前最后可得收盘价**在该日
  强制卖出全部持仓（保守建模退市整理期卖出）；
- 实现：回放循环每日检查持仓 ∩ 当日已退市 → 强制 `_order(sell)`；
- 禁止依赖 `ffill` 价格（那会制造"僵尸持仓"失真）。

### 判定（对照基线）
- 基线：R5 等权575 @300万 全口径 = **超额 +4.43pp / 回撤 −49.2% / 净值 4.43×**；
- 本实验：同口径但宇宙含退市股 → 报告 超额/回撤/净值/年度分布 的变化量；
- **诚实预期**：超额大概率下降（退市股是输家）——下降幅度即"真实幸存者偏差"，
  这不是策略失败，是**基线数字的修正**；
- 附带产出：退市股清单与各年度退市数量统计。

## 风险与局限（预先声明）

1. baostock 对退市股的数据质量未验证（停牌段/退市整理期 tradestatus 取值需抽查）；
2. `outDate` 与最后交易日的对应关系需抽查（退市整理期交易规则变化）；
3. 引擎清仓规则是建模选择（真实操作可在退市整理期择机卖出），保守口径会略压低收益；
4. 3194 在市股中 2500 只已抓，续传与退市股新增抓取共用同一断点续传机制。

## 实施顺序

1. 基建：`data_io.py` 统一读取层 + 年分区迁移 + 全部读取方替换 + 回归断言
   （r5_rebalances 迁移前后目标集合一致）；
2. `fetch_full_market` 改造：stock_basic 清单（含退市）+ 分区写 + snappy/float64；
3. 续传跑完 → 全量验证；
4. 重跑 R5 回测（replay @300万）→ §0 归档判定 → 同步三份运维文档。
