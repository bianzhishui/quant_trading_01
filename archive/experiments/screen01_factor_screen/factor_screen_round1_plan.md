### 相关性矩阵读数

- **截面相关**：全部因子对 < 0.6，预注册同源判据未触发；最大为 动量×距52周高点 0.44
  （与预期一致的部分同源）、BP×低波动 −0.44（便宜的票波动更大）
- **IC 序列相关**：BP×低波动 **−0.75**（动态互补性极佳——但两者本轮均未通过，
  互补性无从兑现）；动量×距52周高点 0.52

### 归因读数

1. **中期动量是本轮唯一亮点，且"性价比"结构最好**：唯一 ③ 过线（+3.6pp），
   换手最低（2.6 倍/年），成本压测最稳（35bp 档仍 +2.4pp），三段全部为正。
   ① 未过的形态很有信息量：全截面 IC 弱（0.013）但五分组严格单调、头部组
   大幅领先 → **信号集中在右尾（前 20% 强动量），不是均匀线性效应**。
   这与"A 股月频动量失效"的文献共识不矛盾：失效的是 Jegadeesh-Titman 式
   全截面多空，右尾仍然有效。
2. **BP 方向性失败，且是"乱序失败"**：Q1（最便宜）年化最高但多头（最贵 Q5）
   与基准无序，无单调结构可言；2018-2021 段 −7.5pp 是成长牛杀估值。
   与 LSY"A 股 BP 弱于 EP"一致——本池价值源仍缺代表，**EP（盈利市值比）
   需要盈利数据，列入下一轮数据抓取清单**。
3. **低波动：IC 显著但组合端背离**——全截面弱负相关是真的（t=−2.41），
   但极端组不单调且换手 4.6 倍放大成本。低波异象在本池不是尾部效应，
   波动源暂不可用。
4. **距 52 周高点：无信号**（IC 0.001），锚定效应在本池月频不成立，直接淘汰。
5. **成本再次成为分水岭**：四个因子里仅有的两个低换手者（BP 0.9、动量 2.6）
   中只有动量的毛超额足以覆盖成本——再次验证"换手率决定行为类因子的生死"。

### 结论归档

- **进入组合观察名单：中期动量**（部分通过，③④扎实、①形态特殊）；
- **淘汰：BP、低波动、距52周高点**（本轮口径下）；
- 组合路径更新：现有可用源 = 反转（上轮，未通过但方向真实）+ 中期动量，
  两源 IC 序列相关 −0.10 ~ +0.3 区间（动态互补可用）；估值源缺 EP，
  行为-关注度源缺低换手——**两者都是 Round 2 补数据的目标**；
- Round 3（组合）在 Round 2 之前提前开的话，先做"反转 + 中期动量"两因子
  等权打分的预注册。

## 1. 本轮目的与假设

对候选池梯队一的 4 个因子做**同一流水线批量初筛**，回答两件事：
1. 哪些因子在"中大票池 + 月频 + 15bp 成本"口径下自身成立；
2. 因子之间相关性如何（**相关性矩阵是 Round 3 组合工作的地基**）。

| 因子 | 预注册方向（谁被看好） | 机制假设 |
|---|---|---|
| BP 账面市值比 | 高 BP（便宜）未来收益更高 | 估值均值回归 + 机构审美资金流；A 股文献 BP 弱于 EP，预期中等 |
| 低波动 | 低 σ 未来收益更高 | 彩票偏好：散户把高波动票买贵 |
| 中期动量 | 高动量（T−250~T−21）未来收益更高 | 与短线散户行为正交的慢变量；A 股月频动量弱，预期弱正 |
| 距 52 周高点 | 越接近前高未来收益越高 | 锚定效应：接近前高的票散户不敢买（George & Hwang 2004） |

## 2. 数据与已知局限（诚实清单）

- 沿用 reversal 实验全部口径与局限：当前成分幸存者偏差、中大票池
  （行为类因子强度下界估计）、涨跌停买入端近似（日收益 ≥9.8% 剔除）、
  停牌价格延续口径
- **停牌对波动类因子的口径**：停牌日收益记 0 → 低波动因子在长期停牌股上被
  低估波动（变相利好该组），记录在案
- BP 分母为 pbMRQ：pb ≤ 0（净资产为负）的股票当期剔除
- 250 日窗口因子（动量/距52周高点）在池内天然满足历史长度（池已要求 ≥375 日）
- BP 与"距52周高点/动量"分属估值与行为锚定源；**距52周高点与中期动量预期
  部分同源**（锚定 vs 动量），相关矩阵会给读数——若截面相关 >0.6，二者组合
  只取其一，此规则预注册如下

## 3. 规则（定死，与 reversal 实验同口径）

### 3.1 股票池（每月末 T 日）

1. 截至 T 日 ≥ 375 条日线记录
2. T 日 `tradestatus == 1` 且 `isST == 0`
3. 非创业板/科创板/北交所
4. T 日未涨停（前复权日收益 < 9.8%）
5. 各因子当期值非 NaN

### 3.2 因子定义（全部用前复权收盘价）

| 因子 | 计算 |
|---|---|
| BP | 1 / pbMRQ（pb ≤ 0 剔除） |
| 低波动 | 过去 21 个交易日日收益标准差（min_periods=15） |
| 中期动量 | close(T−21) / close(T−250) − 1 |
| 距 52 周高点 | close(T) / 过去 250 日最高收盘 − 1 |

### 3.3 组合与成本

- 每因子可交易池内 **rank 等分 5 组**，Q1 = 因子值最低组
- **多头组**：方向为 +1 的因子（BP/动量/距52周高点）= Q5；
  方向为 −1 的因子（低波动）= Q1；等权，月频完全轮换
- **基准** = 当期全部可交易股等权（各因子共用同一基准序列）
- 成本 15bp/单边按权重变动计提；多头组另报 25/35bp 敏感性
- 多空 = 多头组 − 空头组（毛，无空头成本，仅示意）

### 3.4 区间与分段

2014-01 首次调仓 ~ 2026-09；分段 2014-2017 / 2018-2021 / 2022-2026。

## 4. 预注册判定标准（跑之前写死，四因子统一）

| 层 | 标准 |
|---|---|
| ① 显著性 | 月度 RankIC 均值**方向与预注册一致**，且 \|IC\| ≥ 0.03 且 \|t\| ≥ 2 |
| ② 单调性 | 预期多头组为 5 组年化最高**且**预期空头组最低（组序 Spearman 符号正确作辅助读数） |
| ③ 可交易 | 多头组扣 15bp 年化超额（对同池等权基准）≥ +1pp；25/35bp 档作敏感性读数 |
| ④ 稳定性 | 三段中 ≥ 2 段多头超额 > 0 |

单因子判定 = **通过（4/4，进入 Round 3 组合候选池） / 部分通过（3/4，观察名单） /
未通过（≤2，淘汰）**。

**相关性判据（预注册）**：两因子月度截面 Spearman 均值 > 0.6 → 视为同源，
组合阶段只保留本轮判定更优者；IC 序列相关一并报告作动态互补读数。

失败协议：如实归档，禁止回头改因子定义/窗口/池口径重跑；
被淘汰因子不删除本清单条目，在 factor_candidates.md 中标记状态。

## 6. 预期管理

- 低波动类预期最强（彩票偏好 + 与反转同属行为源但换手更低）；
- BP 预期中等偏弱（A 股 BP 弱于 EP 的文献共识）；
- 中期动量预期最弱（A 股动量失效共识），本轮主要价值是确认"动量源可用性"；
- 距 52 周高点介于两者之间；
- 全部读数仍受"中大票池 = 行为因子下界"约束，若全批 ③ 未过线，
  正确结论是"该池对行为/估值因子普遍苛刻"，而不是逐个因子枪毙——
  池子扩展（Round 2 补数据）才是提升信号强度的主路径。
