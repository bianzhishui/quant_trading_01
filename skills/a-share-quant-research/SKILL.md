# A 股量化研究纪律（可移植）

**This skill is guidance, not a checklist.** 它沉淀自一个长期运营的 A 股量化项目
（R5 等权575 + 四账户模拟盘），提炼出**与具体代码无关**的研究/运营纪律。
仓库专属细节（脚本名、路径、数据布局、配置系统）**不属于本 skill**——以各仓库 AGENTS.md 为准。

## 预注册（先定死，再回测）

1. 任何新变体/参数/架构改动，先写预注册方案：假设、规则、**判定标准**、诚实风险，用户批准后再实施；
2. 方案文档遵循命名 `docs/factor_roundNN_xxx_plan.md`；判定标准写死，实施后不可事后调参；
3. 实施后把结果（含失败）写回同一文档 `§0 实施结果归档`，再提交 commit。

## 判定与诚实

- 对照预注册标准给结论：**通过 / 未达标 / 否决**，诚实写代价与局限；
- 同一条件未达标持续 ≥3 轮才算 blocked（不因一轮失败就放弃，也不因一轮通过就定论）；
- **用数据说话**：不编造数字；关键结论必须引用回测输出或账本数据；拿不到就如实写"数据未出/需跑"。

## 回测与验证

- **不反复重跑"试"**：回测很慢（10-20 分钟级），先预注册、后台跑、不重复；
- "默认行为不变"的验证用**快照对拍**：改造前后各跑一次，目标集/关键输出逐字节一致；
- 运营对账不变量：① 期末净值=现金+持仓；② 期末≈期初−费用(<1%)；③ 月涨幅连乘=累计。

## 归档（探索结束必须归档，不手删）

- 已结束探索 → `archive/experiments/<unit>/`（脚本 + plan + 结论输出自包含），索引登记结论；
- 生产链脚本**留位** research/，其 plan/结论照常归档；
- 归档一律 `git mv` 保留历史，**禁止 rm/cp 搬移**；归档后须 import/编译校验通过。

## A 股执行规则（回测/撮合必须全口径）

- **T+1**（当日买入次日才可卖）、**1 手 = 100 股**、涨跌停阻塞（涨停买不进/跌停卖不出）；
- 费率全口径：佣金万1.5（单笔最低5元）、印花税万5（仅卖出）、过户费万0.1（双边）、红利税10%、现金无息；
- 信号=月末 T → 执行=T+1 收盘；前复权价格 + 复权因子事件补除权缺口（价值精确）。

## 代码卫生

- 改代码后 `ruff format` + `ruff check`（0 错误）；pytest 全过；全部模块 import 通过；
- 临时/验证脚本放项目内 `tmp/`（不入库）；**测试/验证代码绝不直接读写真实数据文件**（先在副本上测，测完恢复再碰真实文件）。

## 边界

本 skill 只含**可移植方法论**；落地到某仓库时，具体命令/路径/配置系统以该仓库 AGENTS.md 为准。
